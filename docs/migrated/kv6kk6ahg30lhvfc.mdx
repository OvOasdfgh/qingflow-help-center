## 场景/问题描述

有时候客户需要对于表格中的数据按照分类进行重组分类显示

​

## 思路逻辑

使用代码块按照分类分别取出对应表格行数据后，形成新的数组再放到不同的表格中

​

### 代码与测试

#### 代码注释

table：表单中需要带拆解的表格变量

data：定义data对象，其中有3个数组，目的是为了接收表格子字段分类的甲乙丙，如果还有分类，需要继续加list数组

field\_162089837代表表格子字段分类的表格ID

获取方式：[https://exiao.yuque.com/enzu8l/oy1eh8/bhfdnqmx67wfox04?singleDoc#](https://exiao.yuque.com/enzu8l/oy1eh8/bhfdnqmx67wfox04?singleDoc#) 《如何在代码块中分辨表格的不同列》

```javascript
const table = qf_field.{表格$$174346C19$$};

const data = {
    "list1": [],
    "list2": [],
    "list3": []
};

for (const item of table) {
    if (item.field_162089837 === "甲类") {
        data.list1.push(item);
    } else if (item.field_162089837 === "乙类") {
        data.list2.push(item);
    }else if (item.field_162089837 === "丙类") {
        data.list3.push(item);
    }
}
qf_output={data}

```
