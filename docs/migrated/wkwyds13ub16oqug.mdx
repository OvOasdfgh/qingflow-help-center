## 无代码

### 1.1【表单】引用支持默认值

通过支持引用字段设置默认值，解决引用无法参与关联数据、提交重计算等问题。
1、新增「默认内容」配置项，默认配置为「自定义」，可支持选择「自定义」和「关联已有数据」。
2、设置默认内容后，默认值会显示在该模块的输入框中，填写者若不做修改，默认值将会作为填写者的数据提交。「关联已有数据」需要开启新版关联引擎后使用。

### 1.2【电子签章】支持标准接口

此次更新，专有云版电子签章新增审批及对应状态展示。

#### 1.2.1 功能入口

轻商城-插件中心-签章管理-上传签章

![文档图片](https://cdn.nlark.com/yuque/0/2024/png/43099917/1726109241747-d45ee671-59b2-4979-bedd-1e6a85b37774.png)

#### 1.2.2 功能表现

更新前：点击“上传签章”后，上传签章图片，设置签章名称，并且将签章授权给已实名的成员使用，印章即可生效，无需审核。

1. 审核通过时：签章上有“已启用”标签。
2. 审核不通过时：签章上有“已驳回”标签，且管理员可以点击“重新上传”按钮，进入签章编辑页面进行重新编辑和保存。

### 2.2「OpenAPI」新增支持上传单个文件接口

该接口用于向存储服务上传文件。

注：仅支持上传单个且大小限制 50M 以内的单个文件。

#### **2.2.1 权限说明**

仅专有轻流可调用。「超管accessToken」和「权限组accessToken」都可调用，其中「权限组accessToken」须具有数据权限。

#### **2.2.2 请求**

1. **请求方式：**POST（**HTTPS**）
2. **请求地址：**http(s)://xxx.xx(自有域名)/openApi/upload/file
3. **请求头（header）**

| 参数 | 是否必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| `**accessToken**` | 是 | string | 调用接口凭证 |

1. **请求体（body）**

| **参数** | **是否必须** | **类型** | **说明** |
| --- | --- | --- | --- |
| `file` | 是 | file | 上传文件，单个文件、50MB以内。大于50MB文件，将会返回错误码<br /> |
| `fileNname` | 是 | string | 文件名称，带后缀，和上传时的文件名称一致 |

#### **2.2.3 返回**

1. **返回体**

| **参数** | **是否必含** | **类型** | **说明** |
| --- | --- | --- | --- |
| `**errCode**` | 是 | int | 错误码，非 0 代表失败 |
| `**errMsg**` | 是 | string | 错误码说明 |
| `**result**` | ​<br /> | ​<br /> | ​<br /> |
| `**fileName**` | 是 | string | 文件名称 |
| `fileUri` | 是 | string | 文件地址，uri 为带匿名签名的uri，地址过期时间为 24 小时 |

1. **返回体示例**

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "result":{
    "fileName": "FILE_NAME",
    "fileUri": "FILE_URL"
  }
}

```

## QMC

### 3.1 支持QMC重置密码

QMC管理后台新增【重置密码】的操作，支持在忘记密码的情况下，通过QMC执行密码重置的操作。

### **3.2 轻舟版本支持开通外部用户功能**

轻舟伙伴可通过QMC开通拓展服务的方式，将外部用户配额分配到对应工作区，为对应工作区开通外部用户功能。

#### **3.2.1 开通方式**

1. 在【开通拓展服务】的页面，勾选“外部用户”后，通过填写下方的订单信息，配置当前工作区确认开通的外部用户数量和时长。
2. 点击【确认订单】按钮后，系统会扣除当前环境的外部用户配额，并为所选工作区开通对应数量和有效期的外部用户名额。

## 安全

### 4.1 上传文件接口统一添加登录鉴权

### 4.2 嵌入第三方url安全校验配置

为提升平台内容安全，防止恶意内容通过嵌入字段和门户链接传播，降低平台及用户面临的法律风险，现对平台的外链管理功能进行了全面升级，并制定相关外链管理协议，确保用户在合法合规的前提下使用外链功能。具体升级内容如下：

#### 4.2.1 功能权限调整

1. **实名认证要求**：公开分享、文件上传、嵌入URL及代码块将仅对实名认证用户开放。未完成实名认证的用户将无法使用上述功能。
2. **试用用户与免费用户限制**：试用用户和免费用户无法使用公开分享、文件上传、嵌入URL及代码块功能，也无法进行“所有人分享”操作。

#### 4.2.2 新增工作区管理后台白名单校验功能

1. **白名单配置管理**：在管理后台新增“白名单配置”菜单，管理员可在此添加、删除及管理白名单URL。管理员可实时查看白名单列表并进行管理。
2. **白名单校验机制**：开启白名单校验后，工作区内嵌入字段及门户链接组件的URL必须在白名单内才可生效。若用户配置的URL不在白名单中，系统将提示：“工作区已开启URL白名单，请联系工作区管理员添加。”
3. **白名单数量限制与安全校验**：单个工作区白名单添加数量限制为10000条。同时，平台对接口入参进行URL格式校验及鉴权处理。

#### 4.3.3 嵌入字段及门户链接组件配置优化

用户在配置URL时，若输入的URL未在白名单中，系统将不再展示该链接，并返回提示：“工作区已开启URL白名单，请联系工作区管理员添加。”用户在使用嵌入字段及门户链接组件时，需确保所配置的URL已添加至工作区白名单。如需添加新的URL，请及时联系管理员进行操作。
