## 一、功能简介

流程内Q-Robot是指在业务流程中添加Q-Robot节点，通过该节点在流程中自动执行操作，帮助企业减少重复性操作、提高效率、降低出错率。它能够自动添加或更新数据，也能在关键时刻发送邮件或短信提醒，确保信息传递及时、准确。

## 二、Q-Robot节点类型及介绍

### 2.1 Q-Robot自动添加数据

**节点介绍**：
当前应用的流程流传到该节点时，Q-Robot会自动在其他应用或本应用中新增一条数据，不需要人工重复录入。避免多次填表的重复劳动，实现“一次填写，自动多处生成”。

**适用场景**：

- 新增一个客户时，自动在CRM和售后系统中同时新增一条客户信息
- 用户注册后，自动创建一条用户档案
- 新员工入职后，自动录入一条新员工信息

### 2.2 Q-Robot自动更新数据

**节点介绍**：
当前应用的流程流传到该节点时，自动修改其他应用或本应用里的字段，保持不同系统里的数据保持一致，避免人工逐一修改导致低效或出错。

**适用场景**：

- 员工调岗后，自动更新考勤表和生产排班表里的部门信息
- 产品质检信息更新后，自动同步到生产记录和出库单
- 客户联系方式更新后，自动修改CRM、订单系统和服务工单里的对应字段
- 商品价格调整后，自动同步到库存表

### 2.3 Q-Robot发送邮件

**节点介绍**：
当流程到达该节点时，Q-Robot 会自动发邮件，邮件内容可从表单中提取或自定义。确保关键节点信息传递及时，减少人工通知。

**适用场景**：

- 面试申请提交后，自动向候选人发送面试时间和地点
- 采购申请审批完成后，自动邮件通知财务付款
- 用户预约在线上课程后，自动发送课程提醒邮件

### 2.4 Q-Robot发送短信

**节点介绍**：
数据到达节点时，Q-Robot会自动向目标手机发送短信，与邮件类似，但信息以短信形式快速直达手机，适合需要即时触达的场景。

**适用场景**：

- 面试/活动前一天，自动短信通知候选人和参与者
- 设备维修工单下发以后，自动短信通知维修人员
- 订单生产完成后，短信通知客户提货
