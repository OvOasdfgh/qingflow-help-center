### 介绍

百度营销开放账户管理、广告投放管理、数据洞察、资产管理、转化追踪等接口。对接可以实现系统数据深度打通，广告智能投放等场景。

### 鉴权信息

百度营销[**商业开发者中心**](https://dev2.baidu.com/content?sceneType=0&pageId=100369&nodeId=16&subhead=)可以申请调用API权限的token。这里也和百度营销的帮助文档一样，以普通API权限申请为例子。

a.首先有一个生效的百度推广账户。然后点击「商业开发者中心」右下角的E秘。

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/60F3ulqzCLBWWD6RzCOh7K13SRcb6-py_.png)

b.输入发送“申请API”自助开通权限。然后点击「查看Token」查看Token（API权限代码）

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/eQQNAXrV6LJKX3TbTn-IagK2iFP3WXPl_.png)

c.复制token

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/Amko_Ot2hff8dikooJZKGBvfWr_e8G_P_.png)

d.在「连接器」百度营销对应的事件中填入token

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/lglJQsMQUKPlCp69TU_GbIAiZ2U11LlB_.png)

### 事件信息

（这里只展示一下有哪些事件）

| 事件 | 描述 |
| --- | --- |
| 【搜索广告投放】查询账户 | 可以返回搜索广告投放的账户的相关信息 |
| 【搜索广告投放】更新账户 | 更新username对应的账户信息 |
| 【搜索广告投放】查询计划 | 根据指定的计划id获取推广计划(id可批量) |
| 【信息流广告投放】查询账户信息 | 可查询信息流账户信息 |
| 【线索管理】获取线索信息 | 拉取基木鱼营销通-线索数据（包括广告线索组件和基木鱼落地页里的线索信息） |
