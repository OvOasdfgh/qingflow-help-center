调用本接口，催办指定数据

---

### **权限说明**

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有对应应用的权限。

### 请求

**请求方式：**POST

**请求地址：**https://api.qingflow.com/\{appKey\}/apply/\{applyId\}/urge（公有云版本）

> 请求地址中:applyId为需要替换的变量，根据实际获取值更新，示例如下：

```javascript
POST https://api.qingflow.com/123456/apply/123456/urge
```

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/\{appKey\}/apply/\{applyId\}/urge](https://api.ding.qingflow.com/apply/:applyId/urge)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/\{appKey\}/apply/\{applyId\}/urge

#### **参数说明(路径参数)：**

| **参数** | **必须** | **说明****​** |
| --- | --- | --- |
| **appKey** | **是** | **应用 id，获取方式详见：**[基本概念介绍](https://exiao.yuque.com/ixwxsb/bgzs0e/cl59vxilcqdkmq1h) |
| applyId | 是 | 数据的id，可在轻流的URL中获取，或通过调用【获取应用的数据】文档接口获取 |

#### **请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |
| userId | 是 | 需要传入该条数据申请人的用户id，获取方式参考：基本概念介绍 |

### 返回

#### 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations |  |  | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| applyId |  | int | 数据的id |

#### 返回体示例

```json
{
    "errCode": 0,
    "errMsg": null,
    "questionRelations": [],
    "result": {
        "applyId": 56810319
    }
}
```
