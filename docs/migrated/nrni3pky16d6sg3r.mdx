调用本接口，获取个人在当前工作区全部待办或已办信息

---

### **权限说明**

仅专有轻流可用，「超管accessToken」可调用。

### 请求

**请求方式：GET**

**请求地址：**http(s)://xxx.xx(自有域名)/openApi/env/dynamic/tasks

#### **参数说明（查询参数 )**

| **参数** | **必填** | **说明** |
| --- | --- | --- |
| status | - | 流程状态筛选 |
| type | 是 | 类型 1待办 2我发起的 3抄送 5已办 |
| pageSize | - | 页容量，默认10 |
| pageNum | 是 | 页码 |
| userId | 是 | 用户的id |

#### **请求头（Header）**

| **参数** | **必填** | **说明** |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看基本概念介绍 |
