## 1 功能介绍

### 1.1 功能简介

添加字段后，如需变更字段类型，可以通过切换字段类型快速调整，切换后仍保留已经设置好的字段标题、提示、占比等设置，根据实际需要灵活调整字段类型，能够提高使用效率。

适用于需要更换字段类型同时保留已有数据的场景。例如「单项选择」不支持选择多个选项，可以使用字段切换功能将「单项选择」切换为「多项选择」，同时保留已有数据。

## 2 设置步骤

### 2.1 功能入口

进入应用编辑界面，在表单设计页面，点击字段，可在右侧的字段配置面板，看到功能入口。

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21683170/1699005940534-036df36c-ee51-4c94-ab04-3c3f3a06ceba.png)![image.png](https://cdn.nlark.com/yuque/0/2023/png/21683170/1699007314915-abc7c247-4bca-4481-9085-904f05ab466a.png)

### 2.2 配置方式

点击已添加的字段，即可在右上角选择切换的字段类型。

### 2.3 配置演示

添加单行文字字段，收集「商机编号」的信息。切换字段类型为数字字段。

![iShot\_2023-11-03\_18.32.08.gif](https://cdn.nlark.com/yuque/0/2023/gif/21683170/1699007603660-794d702d-2b71-42df-98a6-c681908fd868.gif)

## 3 注意事项

1、以下字段可相互切换：

| **原字段** | **可切换字段** |
| --- | --- |
| 单行文字 | 多行文字、数据关联 |
| 电话 | 单行文字 |
| 单项选择 | 下拉选择、多项选择 |
| 下拉选择 | 单项选择、多项选择 |
| 数据关联 | 单行文字 |

2、切换字段类型的操作可能导致已设置的公式、数据关联、分支判定条件、提交验证、关联已有数据、Q-Robot数据新增和更新、报表展示、查询报表、关联报表、数据来源标记等功能失效。
