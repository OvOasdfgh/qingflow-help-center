新增委托

---

### **权限说明**

仅支持专有轻流；

仅「超管accessToken」可以调用。

### 请求

**请求方式：**POST

**请求地址：**[https://xxx.xxx.com/openApi/delegate](https://xxx.xxx.com/openApi/delegate)

##### **2.1 参数说明(路径参数)：**

无

##### **2.2 参数说明(查询参数)：**

无

##### **2.3 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

##### **2.4 请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| delegatesUserIds | 是 | \[array\] | 所有委托人的userId |
| delegatedTagIds | 是 | \[array\] | 委托的应用包id数组 |
| delegatedAppKeys | 是 | \[array\] | 委托的应用appkey数组 |
| startTime | 是 | \[datetime\] | 委托开始时间 |
| endTime | 是 | \[datetime\] | 委托结束时间 |
| userId | 是 | string | 发起委托的用户id |

##### **2.5 请求体示例**

```json
{
    "delegatesUserIds": [],
    "delegatedTagIds": [],
    "delegatedAppKeys": [],
    "startTime": "1994-05-23 05:03:31",
    "endTime": "2015-07-13 12:36:54",
    "userId": "l0GN"
}
```

### 返回

##### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| result | 是 | object | 返回结果 |
| delegateId | 是 | int | 任务委托id |

##### 3.2 返回体示例

```json
{
	"errCode": 0,
	"errMsg": "ok",
	"result": {
			"delegateId": 10
		  }
}
```
