## 功能介绍

目前系统间的数据传输大多通过rest API接口完成。轻流强大的连接相关功能，支持和三方系统完成复杂业务的集成。

Q-Source被动可以理解为轻流每个应用有个“自定义接口”，可以将三方系统发送的数据（*JSON/XML/正则表达式*）接收，并解析到应用的字段中。完成对应数据的新增和更新。

*轻流被动接收三方系统数据（轻流开放的接口）：Q-Source被动、*[***OpenAPI添加数据***](https://qingflow.com/help/docs/6114c2d6d601550046421ddc)

*轻流主动拉取三方系统数据（对接三方系统的接口）：*[***Q-Source主动***](https://qingflow.com/help/docs/6114c2d5d601550046421dcc)*、*[***Q-linker***](https://qingflow.com/help/docs/6114c2d5d601550046421dcb)*、*[***Webhook***](https://qingflow.com/help/docs/6116117d9024630046929289)*、*[***提醒推送***](https://qingflow.com/help/docs/6116117d902463004692928a)

## 设置步骤

因为Q-Source被动是接收三方系统发送的数据到轻流，所以需要：

「1」三方系统配置发送的请求

「2」轻流Q-Source被动配置数据接收

### 一、赋值规则（详细见下表）

1. 左边是单值类型，右边返回数组类型，默认选择数组中第一个值作为结果。
2. 左边是多值类型，右边是数组类型，按照赋值规则进行匹配
3. 申请人、成员以邮箱匹配；部门以文本直接匹配。

### 三、更新数据

功能效果：设置判断条件后，当识别接收到的数据和已在轻流中的某条数据是同一条时，更新这条数据。

位置：「接收数据解析」下方，有个「更新数据」开关，默认关闭。

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-09/ACq53wIG1dTz5BZITGVN6Azb0H03Wj9g_.png)

除使用表单字段做筛选外，也可以使用数据ID（applyId）进行筛选。但是未设置applyId的path、path读取出的数据为空、读出的applyId值不是数字、读出的applyId不存在或对应数据已被删除、读出的对应数据不是当前应用的。都依旧为添加数据。

成员与部门匹配最新规则：

| ​<br /> | 字段映射 | 更新筛选 |  |  |
| --- | --- | --- | --- | --- |
| 字段类型 | 匹配规则 | 历史数据 | 匹配规则 | 历史数据 |
| 成员 | 成员（绑定邮箱） | 成员（绑定邮箱） | 成员（绑定邮箱） | - |
| 部门 | 部门名称 | 部门名称 | 部门名称 | - |

![1732245913876.png](https://cdn.nlark.com/yuque/0/2024/png/2056184/1732245920028-e2b30b63-8fc9-40c9-ac8e-7aa8d481cd9c.png)请注意：

1. 本「成员与部门匹配最新规则」功能仅限700版本。600版本用户在更新筛选时，成员和部门的匹配规则仍将基于内部ID。
2. 对于历史配置中使用的内部ID配置，任务执行不受影响，但不再支持配置的修改。
3. 对于更新筛选中用户和部门字段的内部ID关联，在浏览器端做隐藏处理，历史数据不处理。
4. 系统不支持基于内部ID的配置修改，未来考虑增加使用外部ID进行数据交互。

### 四、白名单设置

点击插件中心->\[Q-Source\]的配置按钮可以配置「Q-Source被动模式」的白名单：

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-09/ZG7ZUr8fmQD7_t5GcZKlcPTqJUymZDCg_.png)

当没有设置任何白名单ip的时候，「Q-Source被动模式」不校验来源ip(只校验源公网ip)，当添加白名单ip之后，来自非白名单ip的Q-Source请求将被拒绝。

IP格式为标准点分十进制格式 最大为255.255.255.255最小为1.1.1.1

### 五、注意事项

1、如果表单某个字段设置了必填，则Q-Source被动收到的数据，必须设置该必填字段的解析，且确实有值。否则会添加失败。

（1）公有云用户：如果数据添加不成功，可通过「查询操作结果」接口，根据requestId查询操作结果，返回错误码40500表示Q-Source被动有必填字段未解析

（2）专有轻流用户：可自主选择Q\_Source被动是否走消息队列，如果选择不走消息队列，在出现上述由于必填字段未解析导致添加数据失败的情况时，会直接返回错误信息。

2、Q-Source被动模式新增数据时：只有勾选「进入流程」才会触发流程外Q-Robot，否则不触发流程外Q-Robot。

3、专有轻流用户：Q-Source被动模式更新数据时，会触发流程外Q-Robot。
