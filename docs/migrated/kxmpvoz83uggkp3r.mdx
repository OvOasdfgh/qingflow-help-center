可以获取当前工作区所有应用包的信息

---

### **权限说明**

仅「超管accessToken」拥有调用权限（权限组accessToken无法调用）。

### 请求

**请求方式**：GET

**请求地址**： https://api.qingflow.com/tags（公有云版本）

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/tags](https://api.ding.qingflow.com/tags)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/tags

##### **2.1 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

##### **2.2 参数说明(查询参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| userId | 是 | 成员ID |
| favourite | 否 | 可查询指定成员的可见且收藏的应用列表，userId不传时无效int型，枚举值如下： 1-获取当前用户可见中收藏的应用0-获取当前用户所有的可见应用（默认值） |

### 返回

##### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| result | 是 | object | 返回结果 |
| appList | 是 | \[array\] | 应用列表 |
| appKey | 是 | string | 应用key |
| appName | 是 | string | 应用名称 |
| tagList | 是 | \[array\] | 应用包列表 |
| tagName | 是 | string | 应用包名称 |
| tagId | 是 | string | 应用包id |
| tagIcon | 是 | string | 应用包icon |
| dashList | 是 | \[array\] | 门户列表 |
| dashKey | 是 | string | 门户key |
| dashName | 是 | string | 门户名称 |

##### 3.2 返回体示例

```json
{
    "errCode": 0,
    "errMsg": "OK",
    "result": {
        "tagList": [{
            "tagName": "应用包名称",
            "tagId": "应用包id",
            "tagIcon": "应用包图标",
            "appList": [{
                "appKey": "应用key",
                "appName": "应用名称"
            }],
            "dashList": [{
                "dashKey": "门户key",
                "dashName": "门户名称"
            }]
        }]
    }
}
```
