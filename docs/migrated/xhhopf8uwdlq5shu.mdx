## 场景/功能描述

我希望可以在发起表单的时候，表格可以自动生成多行，方便我进行填写

## 思路逻辑

![原文画板](https://cdn.nlark.com/yuque/0/2022/jpeg/27174367/1669717765853-23d7c831-11eb-4739-8e16-b969c22da44d.jpeg)

## 配置过程

代码块配置

```javascript
var len = qf_field.{表格行$$98376B89$$};
var arr = new Array(len);
qf_output = {arr :arr}
```

注：qf\_field.\{表格行$$98376B89$$\}请手动替换为应用内字段。
