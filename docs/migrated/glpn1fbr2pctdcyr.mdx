#### 场景

对于客户有满赠活动，若满赠件数计入下单总量，客户填写下单总量自动计算需要付款的件数、满赠件数和付款总额；若满赠件数不计入下单总量，自动计算所需付款总额、满赠件数、实际订单总量。

销售满赠件数计入库存流水

【销售明细·规格】：数据关联

关联「商品信息」应用中的字段【规格】，筛选条件：当前表格行中填写的商品和关联应用中的商品名称相同

为什么设置数据关联而非关联已有数据：可能同一商品名称有多种规格的情况，下单时需要再进一步选择规格

![image.png](https://cdn.nlark.com/yuque/0/2021/png/21388903/1636512626855-a954abdc-daf9-4b8f-82b2-5a951fd1d602.png)

【销售明细·商品编号】：单行文字-关联已有数据

关联「商品信息」应用中的字段【商品编号】，筛选条件：当前表格行中填写的商品名称和规格与关联应用中相同

选择了具体某个商品后，商品编号肯定是一一对应的，所以设置关联已有数据

关联「商品信息」应用中的字段【标准价】，筛选条件：当前表格行中填写的商品名称、编号和关联应用中的相同

![image.png](https://cdn.nlark.com/yuque/0/2021/png/21388903/1636513007974-f4d772d0-956f-4f8e-b9a9-9bf48c8053ff.png)

【销售明细·下单数量】：数字

【销售明细·满赠数量】：数字-设置公式

*INT：将数字向下取整*

设置含义：

如满赠规则为满10赠2，某个客户下单数量为20，当满赠计入下单数量时，在20中计算有多少个12，取整后乘以赠送数量；当满赠不计入下单数量时，在20中计算有多少个10，取整后乘以赠送数量

![image.png](https://cdn.nlark.com/yuque/0/2021/png/21388903/1636513555425-7aecdd2b-5b4a-4c74-8d56-1b24c30422a1.png)
