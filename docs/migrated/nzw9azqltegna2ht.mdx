## 场景/问题描述

通过webhook功能，实现流程自动回退、小循环。**【仅限企业版本】**

## 思路逻辑

使用webhook+审批，实现流程的自动回退和小循环，无需人为审批操作。

仅当满足条件1时，流程自动通过；满足条件2时，自动退回至填写人1重新填写。

### 流程回退-Webhook设置

[查询API文档：单条数据流程回退 ](https://help.qingflow.com/help-docs?type=qingCode&docId=fc8e64656428e08a06fdf030002e2a74&parentId=)

#### URL

根据API文档描述，调用URL：https://api.qingflow.com/xxx，单条数据流程回退：/\{applyId\}/audit/rollback

URL: https://api.qingflow.com/\{数据ID$$-U1P8$$\}/audit/rollback （绿色部分请替换为应用内数据ID）

每条数据申请时会自动生成唯一的数据ID, 可获取到当前申请数据的唯一ID。
