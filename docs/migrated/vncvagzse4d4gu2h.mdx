调用本接口，获取单条数据的数据日志

---

### **权限说明**

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有对应应用的权限。

### 请求

**请求方式：**POST

**请求地址：**https://api.qingflow.com/\{appKey\}/\{applyId\}/rowrecord/log（公有云版本）

请求地址中:applyId为需要替换的变量，根据实际获取值更新，示例如下：

```javascript
POST https://api.qingflow.com/123456/123456/rowrecord/log
```

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/openApi/\{appKey\}/\{applyId\}/rowrecord/log](https://api.ding.qingflow.com/apply/:applyId/urge)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/\{appKey\}/apply/\{applyId\}/rowrecord/log

#### **参数说明(路径参数）**

| **参数** | **必填** | **说明** |
| --- | --- | --- |
| **appKey** | **是** | **应用 id，获取方式详见：**[基本概念介绍](https://exiao.yuque.com/ixwxsb/bgzs0e/cl59vxilcqdkmq1h) |
| applyId | 是 | 数据的id，可在轻流的URL中获取，或通过调用【获取应用的数据】文档接口获取 |

#### **请求头（Header）**

| **参数** | **必填** | **说明** |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看基本概念介绍 |

#### 请求体

| **参数** | **必填** | **说明** |
| --- | --- | --- |
| fieldId |  | 字段ID，如果查询某个字段的修改记录，需要填写该ID |
| pageSize | 是 | 页码大小，最大1000 |
| pageNum | 是 | 当前页码，从1开始 |

#### 请求体示例

```json
{
    "fieldId": 0,
    "pageSize": 0,
    "pageNum": 0
}
```
