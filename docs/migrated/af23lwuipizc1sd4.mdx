### 工作区环境

选择当前工作区的使用环境。 公有云微信/飞书/企业微信、公有云钉钉 、专有云

​

如何判断：根据访问工作区的域名判断即可。如果访问域名是[https://qingflow.com](https://qingflow.com)，即为公有云，如果访问域名是：[https://app4355.eapps.dingtalkcloud.com](https://app4355.eapps.dingtalkcloud.com)，即为钉钉。专有云为私有化部署http(s)://xxxx.com。

当选择专有云时，需要手动填写访问域名。

### 代码块

```javascript
const axios = require('axios');
new_url=qf_field.{URL$$3364BDDAA$$}+"/dashes?pageSize=2000&pageNum=1"

let config = {
  method: 'get',
  maxBodyLength: Infinity,
  url: new_url,
  headers: { 
    'accessToken':qf_field.{Access Token$$3364BDD98$$},

}
};

let res = []

axios.request(config)
  .then((response) => {
    var result = response.data.result.result;
    for (let i = 0; i < result.length; i++) {
      elem = result[i];
      if(elem.dashAuth==1){
        res.push(elem)
      }
    }
    console.log("res:"+res)
    qf_output={res} ;
  })
  .catch((error) => {
    console.log(error);

  });
```
