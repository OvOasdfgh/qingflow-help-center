可以获取当前工作区所有应用的信息

---

### **权限说明**

仅「超管accessToken」拥有调用权限（权限组accessToken无法调用）。

### 请求

**请求方式**：GET

**请求地址**： https://api.qingflow.com/app（公有云版本）

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/app](https://api.ding.qingflow.com/app)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/app

##### **2.1 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

#### **2.2 参数说明(查询参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| userId |  | 成员外部id，可查询指定成员的可见应用。userId为空时，返回工作区全部应用。 |
| favourite |  | userId不传时无效。枚举值如下： 1-获取当前用户可见中收藏的应用 0-获取当前用户所有的可见应用（默认值） |

### 返回

##### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations |  |  |  |
| result | 是 | object | 返回结果 |
| appList | 是 | \[array\] | 应用列表 |
| appKey | 是 | string | 应用key |
| appName | 是 | string | 应用名称 |

##### 3.2 返回体示例

```json
{
	"errCode": 0,
	"errMsg": null,
  "questionRelations": [],
	"result": {
			"appList": [
					{
							"appKey": "APPKEY",
							"appName": "APPNAME"
					}
			]
	}
}
```
