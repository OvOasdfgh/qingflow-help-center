## 1.设置步骤

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-10-13/nA1vJHWBUt75EqtBJ7Q6OzI2TjKawvIF_.png)

### 1.1 筛选条件

- 操作用户：支持模糊搜索
- 事件类型：枚举“登录、登出**”，** 支持筛选

能够显示操作用户姓名、事件类型、操作方式、时间（精确到秒，支持正序/倒序切换排列）、ip地址

### 1.2 操作类型及方式如下
![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-10-13/eFBs3QKsdbUtuwQOGJn4DkmJWC_7ExQH_.png)

若点击某条日志，则会显示该条日志的详情
![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-10-13/5xWZYqMD55U8bvFqLyrxEQQKZrMjyAuf_.png)

列表日志可以导出

- 导出上限：100w条日志
- 文件命名："日志类型"+导出时间。如：登录日志2024-11-14
- 文件格式：xlsx文件
- 导出的文件包括：日志详情中所有的字段，包括工作区名称、邮箱、手机号、姓名、操作详情、操作时间、操作ID。
- 注意，文件生成后保留72小时，也可在相应操作记录下载
