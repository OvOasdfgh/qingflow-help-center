## 无代码

### 一、视图支持设置查询条件

为了解决多客户共用同一视图时容易看到彼此数据、以及业务数据量大时难以快速定位的问题，我们推出了**视图查询条件**功能。它允许管理员在视图中配置查询字段，让使用者必须输入查询内容后才能看到相关数据，并支持精确匹配、模糊匹配以及多字段组合查询，从而实现既精准又安全的数据检索。

**使用步骤**

1. 在视图编辑页开启查询条件
2. 根据需要选择是否要在查询前隐藏全部视图数据
3. 添加要作为查询条件的字段
4. 配置查询条件

![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1764732270459-e9a17490-1726-4ab8-bc8d-c6e9183a8b89.png)

保存设置后，用户可以在视图顶部输入内容进行查询，实现只看到与自己有关的数据。

### 二、高级权限

为了解决传统权限体系无法满足企业复杂角色分工、数据安全要求不断提升的问题，我们上线了全新的**高级权限**功能。它以应用包为单位重新构建权限体系，将企业常见的“授权者、搭建者、使用者、游客”等角色拆分成独立的权限组，不同角色拥有不同的操作边界，从而实现真正的职责分离和精细化管控。

**使用步骤**

1. 编辑应用包并点击高级权限
2. 根据业务需求将成员加入具体的权限组
3. 为各权限组设置可见、可编辑、数据范围、字段权限等具体权限项目

![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1764732297771-95b78bbe-6a4b-4135-ae0f-d255af3bfd06.png)

通过高级权限，企业可以灵活构建适合自身结构的权限体系，确保数据使用更加安全、管理更加清晰
