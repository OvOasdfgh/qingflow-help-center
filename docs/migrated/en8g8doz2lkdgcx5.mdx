## 一、功能简介

统计报表用于将数据以图表的方式直观呈现，通过灵活的数据分析和可视化设置帮助用户快速发现数据价值。

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/EszNDKKloVBDvZIkHPwaH5lEGFdz4sZ8_.png)

## 二、图表类型

| **图表类型** | **功能介绍** | **使用场景示例** |
| --- | --- | --- |
| [汇总表](https://exiao.yuque.com/ixwxsb/bgzs0e/nrl0xi33qgo4y05p) | 按照指定的维度对数据进行**分类汇总**，直观展示数据整体概况 | 按部门汇总工单数量按月份统计销售额 |
| [明细表](https://exiao.yuque.com/ixwxsb/bgzs0e/cc5swi9se9y0e18h) | 以表格形式展示**字段明细**，便于查看和导出数据详情 | 查看订单明细、客户记录等原始数据 |
| [条形图](https://exiao.yuque.com/ixwxsb/bgzs0e/vmg6gxfpa2m4v4f3) | 用横向条形的长度展示数据大小，适合展示分类较多的对比数据 | 各地区销售对比产品满意度评分排名 |
| [柱状图](https://exiao.yuque.com/ixwxsb/bgzs0e/mtfgehgimngbpw33) | 用纵向柱形高度展示数据大小，适合展示分类较多的对比数据 | 月度销售额对比各类商品销售额对比 |
| [折线图](https://exiao.yuque.com/ixwxsb/bgzs0e/aznkqn07s5iqg0dz) | 展示数据在连续维度上的变化趋势，适合时间序列分析 | 用户活跃趋势月营收变化 |
| [雷达图](https://exiao.yuque.com/ixwxsb/bgzs0e/dt9f0yafc9ftkmh2) | 将多个维度的数据同时在同一坐标轴显示，适合做综合评分或多维度对比 | 员工能力评估产品性能对比 |
| [饼状图](https://exiao.yuque.com/ixwxsb/bgzs0e/llxvned1ns5xxfi1) | 以圆形扇形表示各指标在整体中的占比，便于看出相对关系 | 市场份额占比预算分布 |
| [环形图](https://exiao.yuque.com/ixwxsb/bgzs0e/dznvg35gtntg9ssh) | 与饼状图类似，但中间为空心，支持添加注释信息，更能突出关键数据 | 展示各渠道收入比例成本结构说明 |
| [散点图](https://exiao.yuque.com/ixwxsb/bgzs0e/qhbpdtpism4nt0hz) | 通过点的坐标展示自变量和因变量的统计关系，分析变量之间的相关性 | 销售额与客单价的相关性异常数据检测 |
| [漏斗图](https://exiao.yuque.com/ixwxsb/bgzs0e/ehz12cgebu77sow5) | 展示流程中各阶段数据变化和转化率，便于分析转化效果和发现瓶颈 | 销售转化流程分析注册转化率 |
| [组合图](https://exiao.yuque.com/ixwxsb/bgzs0e/ovpgoi61az5m0emp) | 将柱状图和折线图结合展示，同时分析两组存在一定关联性的数据，以便清晰的展示他们之间的趋势和关联 | 成本与利润分析用户数量与活跃数量分析 |
| [指标看板](https://exiao.yuque.com/ixwxsb/bgzs0e/nb1l2d4bkzeh8ysa) | 以卡片的形式展示核心指标的当前值，帮助实时掌握关键业务数据 | 展示商品库存数量任务完成量 |
| [地图](https://exiao.yuque.com/ixwxsb/bgzs0e/bnqf4ohseip6av6g) | 根据地理位置信息对数据打点或热力展示，体现数据的空间分布 | 销售区域分布门店分布 |
| [时间轴图表](https://exiao.yuque.com/ixwxsb/bgzs0e/iur60tggm63nhqhw) | 以时间线方式呈现事件或数据节点，展示随时间推移的变化或进展 | 项目进度展示重要事件记录 |
