调用本接口，获取部门成员列表

---

### **权限说明**

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有通讯录权限。

### 请求

**请求方式：GE**T

**请求地址：**https://api.qingflow.com/department/:deptId/user（公有云版本）

> 请求地址中:deptId为需要替换的变量，根据实际获取值更新，示例如下：

```javascript
GET https://api.qingflow.com/department/12345/user?fetchChild=true
```

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/department/:deptId/user](https://api.ding.qingflow.com/department/:deptId/user)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/department/:deptId/user

#### **2.1 参数说明(路径参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| deptId | 是 | 部门id，可通过文档接口获取 |

#### **2.2 参数说明(查询参数)：**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| fetchChild | 是 | boolean | 是否递归获取子部门成员，true or false |

#### **2.3 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

### 返回

#### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations |  |  | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| leaderIds | 是 |  |  |
| userList | 是 | array |  |
| userId |  | string | 用户的userId |
| name |  | string | 用户名 |
| areaCode |  | string |  |
| mobileNum |  | string | 手机号 |
| email |  | string | 邮箱 |
| headImg |  | string | 头像 |
| department |  | array | 同步部门id列表 |
| role |  | array | 同步角色id列表 |
| customRole |  | array | 自建角色id列表（仅企业微信/钉钉/飞书等特殊工作区适用） |
| customDepartment |  | array | 自建部门id列表（仅企业微信/钉钉/飞书等特殊工作区适用） |
| beingDisabled |  | boolean | 是否禁用成员 |
| beingActive |  | boolean | 用户的激活状态 |
