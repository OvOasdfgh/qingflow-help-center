调用本接口，可对指定单条数据重新指派当前审批/填写节点的负责人。

---

### **权限说明**

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有对应数据所在应用的数据权限。

### 请求

**请求方式：**POST

**请求地址：**[https://api.qingflow.com](https://api.qingflow.com/apply/:applyId/reassign)/\{appKey\}/apply/\{applyId\}/reassign

> 请求地址中:applyId为需要替换的变量，根据实际获取值更新，示例如下：

```javascript
POST https://api.qingflow.com/123456/apply/123456/reassign
```

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com](https://api.ding.qingflow.com/apply/:applyId/reassign)/\{appKey\}/apply/\{applyId\}/reassign

专有轻流：http(s)://xxx.xx(自有域名)/openApi/\{appKey\}/apply/\{applyId\}/reassign

#### **参数说明(路径参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| appKey | 是 | 应用 id，获取方式详见：[基本概念介绍](https://exiao.yuque.com/ixwxsb/bgzs0e/cl59vxilcqdkmq1h) |
| applyId | 是 | 操作重新指派的数据id |

#### **参数说明(查询参数)：**

#### **请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

#### **请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| reassignmentInfo | 是 | \[array\] |  |
| auditNodeId | 是 | int | 需修改负责人的节点id：需为当前数据的处理中审批/填写节点 |
| userIdList | 是 | \[array\] | 修改后的节点负责人，不可传空值 |

#### **请求体示例**

```json
{
    "reassignmentInfo":[
        {
        "auditNodeId":140587,
        "userIdList":[3488,89066]
        },
        {
        "auditNodeId":143045,
        "userIdList":[8406]
        }
    ]
}
```

### 返回

#### 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations |  |  | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| applyId | 是 | long | 成功指派的数据id |

#### 返回体示例

```json
{
	"errCode": 0,
	"errMsg": "ok",
	"questionRelations": [],
	"result": {
			"applyId": 167823054
			}
}
```

### 注意事项

1、回收站中数据、或「申请人完善中」、及草稿状态的数据无法操作重新指派。

2、指定的节点负责人不可传禁用状态或未注册的工作区成员。
