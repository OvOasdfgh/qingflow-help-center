Microsoft Graph 一种是可让用户访问 Microsoft 云服务资源的 REST 风格的 Web API。在[注册应用](https://docs.microsoft.com/zh-cn/graph/auth-register-app-v2)并[获取身份验证令牌以用于用户](https://docs.microsoft.com/zh-cn/graph/auth-v2-user)或[服务](https://docs.microsoft.com/zh-cn/graph/auth-v2-service)后，可以向 Microsoft Graph API 发送请求。

[https://docs.microsoft.com/zh-cn/graph/overview-major-services?view=graph-rest-1.0](https://docs.microsoft.com/zh-cn/graph/overview-major-services?view=graph-rest-1.0)
