## **权限说明**

仅专有轻流支持。

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有通讯录权限。

## 请求

**请求方式：**POST

**请求地址：**http(s)://xxxxx(自有域名)/openApi/role

请求地址中自有域名xxx.xx为需要替换的变量，根据实际获取值更新，示例请求如下：

```plain
POST http(s)://xxxx.qingflow.com/openApi/role
```

#### **2.1 请求头（Header）**

|  |  |  |
| --- | --- | --- |
| 参数 | 必须 | 说明 |
| accessToken | 是 | 调用接口凭证。获取方法请查看“获取OpenAPI accessToken” |

#### **2.2 请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| roleName | 是 | string | 角色名称 |
| roleId | 是 | int | 角色id |

#### **2.3 请求体示例**

```plain
{
    "roleName":  "json",
    "roleId": 638489
}
```

## 返回

#### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations |  |  | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| roleId |  | int | 角色id |

#### 3.2 返回体示例

```plain
{
    "errCode": 0,
    "errMsg": null,
    "questionRelations": [],
    "result": {
        "roleId": 638489
    }
}
```
