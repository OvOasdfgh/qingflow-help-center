## 场景/问题描述

有时候调用外部接口时，会出现需要分别传省、市、区、位置这些参数，但是轻流地址字段传入webhook格式为：北京市 北京市 东城区 \*\*\*，中间是以空格隔开的，并不能分别传入到对应参数中。

### 代码与测试

#### 代码注释

- address：替换成表单中完整地址字段

```javascript
function processData(address) {
  let result;

  // 检查address是否为null
  if (address === null) {
    result = "";
  } else {
    // 拆分地址
    let [省, 市, 区, 位置] = address.split(",");

    // 构建data对象
    let data = {
      "省": 省,
      "市": 市,
      "区": 区,
      "位置": 位置
    };

    result = data;
  }

  return result;
}
```
