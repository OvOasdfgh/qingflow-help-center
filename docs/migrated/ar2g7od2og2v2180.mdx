## 场景/问题描述

设备巡检时，希望可以实现单行文字开启扫码录入功能，可以实现扫码一次自动填充到表格行中

## 思路逻辑

每次扫码录入之后，通过代码块进行将录入内容汇总至表格中

### 代码与测试

#### 代码注释

qf\_field.\{编号$$177A4DCB2$$\}：表单中的编号字段

qf\_field.\{表格$$177A4DCC9$$\}：表单中的表格字段

field\_165708652：表格中的编号字段的ID

field\_id获取方式[https://exiao.yuque.com/rlf3k1/oanb79/ml0u7lgb3wa0vhiz?singleDoc#](https://exiao.yuque.com/rlf3k1/oanb79/ml0u7lgb3wa0vhiz?singleDoc#) 《如何在代码块中分辨表格的不同列》

```javascript
function colNum(num,data){
    if(data==null||data.length==0||data[0].field_165708652==null){
        data = [
            {
                "field_165708652": num
            },
        ]
    }else{
        data.push({"field_165708652":num})
    }
    return data
}

let num = qf_field.{编号$$177A4DCB2$$}

data = qf_field.{表格$$177A4DCC9$$}

data = colNum(num,data)
qf_output = {"allData":data,key:null}
```
