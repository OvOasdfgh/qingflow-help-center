## 1.1. 使用说明

轻流进销存主要分为四类使用人员：采购人员、销售人员、仓库人员、财务人员

| **使用人员** | **使用内容** |
| --- | --- |
| [采购人员](https://exiao.yuque.com/tch4i5/dgucry/dwlqbeo4iw6vvdpe?singleDoc#%20《采购人员》) | 支持创建采购订单，申请采购发票确认、采购付款、采购入库、采购退货、采购订单完结，录入与维护供应商信息、产品信息，查看采购数据 |
| [销售人员](https://exiao.yuque.com/tch4i5/dgucry/zpupgh?singleDoc#%20《销售人员》) | 支持创建销售订单，申请销售开票、销售回款确认、销售出库、销售退回、销售订单完结，录入与维护客户信息，查看销售数据 |
| [仓库人员](https://exiao.yuque.com/tch4i5/dgucry/mm64pm9q18az75k9?singleDoc#%20《仓库人员》) | 支持处理出入库、调拨、盘点、库存费用分摊，录入与维护仓库信息与状态，查看库存数据 |
| [财务人员](https://exiao.yuque.com/tch4i5/dgucry/nn2levbghu7eygvi?singleDoc#%20《财务人员》) | 支持处理采购发票确认、采购付款、销售开票、销售回款确认，查看财务数据 |
