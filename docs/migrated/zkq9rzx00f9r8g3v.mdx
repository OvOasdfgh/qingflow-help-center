## 文档说明

该连接器函数接口目的是在目前轻流函数基础上，继续扩展的部分能力。调用方式则通过配置连接器进行使用即可。

注意：

- 由于接口有频率限制，为400次/分钟。
- 目前仅公有云轻流环境可配置调用。

---

该文档会逐一介绍对应的连接器事件，具体在轻流中如何进行配置调用，并附上实现录屏方便用户更直观了解效果。

---

## 配置操作

由于配置连接器的操作路径都是相同的，即：

1. 表单添加【Q-Linker】
2. 配置模式选择为【连接中心模版】
3. 选择对应连接器【函数扩展工具】
4. 选择对应连接器事件
5. 配置【绑定变量】
6. 配置接收字段默认内容为Q-Linker输出变量

所以该文档只会详细说明一个连接器事件【随机数生成】的具体配置过程，供用户参考进行配置。

---

## 连接器事件

### 随机数生成

- 连接器事件说明：生成count数量的随机数，仅在\[min,max\]区间范围内。可控制生成的随机数是否允许重复。
- **演示链接**：[随机数生成](https://qingflow.com/f/amt4aabjic01?exWsId=hLBxMjdXeT6OjR46vgH-og)

#### 变量说明

| 变量名称 | 是否必填 | 说明 |
| --- | --- | --- |
| min | 是 | 随机数下限(含) |
| max | 是 | 随机数上限(含) |
| count | 是 | 生成数量 |
| allow\_duplicates | 否 | 是否允许重复，选填true/false；默认为true |

注意：若需要allow\_duplicates为true，表单中配置时，就无需绑定变量设置allow\_duplicates，或者可默认自定义值为true。

#### 输出说明

| 输出名称 | 类型 | 说明 |
| --- | --- | --- |
| 随机数 | int | 只会输出1个随机数 |
| 随机数列表 | array | 会输出对应count数量的随机数列表 |
| 随机数 | int | 具体随机数 |

### 字符串分割

- 连接器事件说明：将输入字符串按照指定分隔符进行分割，可选择返回普通列表或键值对映射

- 普通列表格式示例为：

```plain
[
  "a=1",
  "b=2",
  "c=3"
]
```

- 键值对映射示例为：

```plain
{
  "a": "1",
  "b": "2",
  "c": "3"
}
```

- **演示链接**：[字符串分隔](https://qingflow.com/f/amu6776rms01?exWsId=hLBxMjdXeT6OjR46vgH-og)

#### 变量说明

| 变量名称 | 是否必填 | 说明 |
| --- | --- | --- |
| input | 是 | 输入待处理字符串 |
| delimiter | 是 | 分隔符 |
| map\_format | 是 | 是否返回键值对映射；选填true/false |
| key\_value\_delimiter | 是 | 键值对分隔符 |

#### 输出说明

- 若map\_format为true时

| 输出名称 | 类型 | 说明 |
| --- | --- | --- |
| result | object | 输出处理的结果为对象 |

- 由于处理的字符串不固定，所以返回的对象中数量也不固定，所以需要额外做处理，下文会说明具体操作方式。

- 若map\_format为false时

| 输出名称 | 类型 | 说明 |
| --- | --- | --- |
| result | array | 输出处理的结果为普通数组 |
| value | string | 具体处理值 |

### 字符串替换

- 连接器事件说明：替换字符串中的指定内容，支持普通替换和正则表达式替换。

- 示例1：普通替换

- 比如输入："hello world"，将字符中的"o"替换为"0",即最后输出为："hell0 w0rld"

- 示例2:正则表达式替换

- 比如输入"我的电话是12345，你的QQ是67890",需要将数字替换成"#"

- 使用正则表达式："\\\\d" ;在JSON中，反斜杠需要转义，所以正则表达式中的`\\`要写成`\\\\`

### 字符命名法

- 连接器事件说明：根据传入的type类型，输出对应的类型字符命名法处理结果。

- type可选值包括：

- camel: 转换为驼峰命名(首字母小写)

- 如”hello world” -> “helloWorld”

- pascal: 转换为帕斯卡命名(首字母大写)

- 如”hello world” -> “HelloWorld”

- snake: 转换为蛇形命名(下划线分隔)

- 如”Hello World” -> “hello\_world”

- kebab: 转换为kebab命名(连字符分隔)

- 如”Hello World” -> “hello-world”

- **演示链接**：[字符命名法](https://qingflow.com/f/amuds9rjlg02?exWsId=hLBxMjdXeT6OjR46vgH-og)

#### 变量说明

| 变量名称 | 是否必填 | 说明 |
| --- | --- | --- |
| type | 是 | 命名法类型，type可选值：camel、pascal、snake、kebab |
| text | 是 | 待处理内容 |

#### 输出说明

| 输出名称 | 类型 | 说明 |
