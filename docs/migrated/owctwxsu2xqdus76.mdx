## 场景/问题描述

一、如果判断第一个文本框内的值为“外购”返回“1.”，值为“自制”返回“2.”，值为“外协”返回“3.”，值为“组件”返回“4.”.
二、判断第二个文本框内的值为“压铸”返回“01.”，值为“冲压”返回“02.”，值为“型材”返回“03.”，值为“注塑”返回“04.”，值为“线缆”返回“05.”，值为“辅料”返回“05.”.
三、流水号（当一个全新码出现时，流水号是从0001开始的）

例如：如果是外购压铸，返回的编号就是1010001，自制型材，返回编号就是2030001

## 思路逻辑

方式1:主要使用数据关联功能来进行编号的递增处理，辅助字段过多

方式2:直接使用代码块来进行数据的处理

针对方式2由于是跟自身应用数据进行对比，所以如果数据并发的话，可能会出现编号重复的情况，后续代码块节点上线可以解决

const axios = require('axios');

function getNextSerialNumber(value1, value2, res_list) {
    if (value1 === null || value2 === null) {
      return ''; // 如果 value1 或 value2 为空，则返回空字符串
    }
  
    const value1Map = {
      '外购': '1',
      '自制': '2',
      '外协': '3',
      '组件': '4'
    };
  
    const value2Map = {
      '压铸': '01',
      '冲压': '02',
      '型材': '03',
      '注塑': '04',
      '线缆': '05',
      '辅料': '06'
    };
  
    const matchingItems = res_list.filter(item => item.value1 === value1 && item.value2 === value2);
  
    if (matchingItems.length > 0) {
      // 根据已存在的流水号进行排序取最大值
      const previousSerialNumbers = matchingItems.map(item => parseInt(item['流水号'], 10));
      const maxPreviousSerialNumber = Math.max(...previousSerialNumbers);
      const nextSerialNumber = (maxPreviousSerialNumber + 1).toString().padStart(7, '0');
  
      return nextSerialNumber;
    } else {
      const defaultSerialNumber = `${value1Map[value1]}${value2Map[value2]}0001`;
  
      return defaultSerialNumber;
    }
  }
  

// 调用接口获取应用数据并处理
