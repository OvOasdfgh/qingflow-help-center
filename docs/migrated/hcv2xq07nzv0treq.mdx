## 1.无代码

### 1.1「新增功能」

#### 1.1.1 申请人节点支持关闭重新申请

本次更新后，可以在「申请人」节点的基础设置处，关闭或开启「允许重新申请」。关闭「允许重新申请」后，申请人在「我发起的」视图中，打开数据详情时无法重新申请

### 1.2「优化功能」

#### 1.2.1 移动端流程状态筛选优化

本次更新后，在移动端中，可以根据数据所在的流程节点进行筛选
![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/%E5%AD%A6%E4%B9%A0%E4%B8%AD%E5%BF%83%E6%A3%80%E6%9F%A5/5.12/5.12/%E7%BC%96%E7%BB%84%206.png?sign=90c92a32284a6e2c1816f82d6e2a7ebe&t=1683873203)

#### 1.2.2 新增下级包含（反向从属）判断符

本次更新后，对「部门」字段进行筛选时，新增「下级包含」「下级不包含」判断符

- 下级包含：目标应用的部门完全包含当前应用中勾选的子部门
- 下级不包含：指目标应用的部门不完全包含当前应用中勾选的子部门

示例：A部门下有子部门B、C，B部门下有子部门D，则A、B部门下级包含D，C部门下级不包含D

## 2. 轻代码

### 2.1「新增功能」

#### 2.1.1 OPEN API 部门排序

本次更新后，调用创建/更新部门接口时，可自定义部门顺序，同时支持获取部门的顺序值信息

#### 2.1.2 OPEN API 登录accesstoken 可以选择全部成员

本次更新后，「登录接口专用」可用code登陆成员支持选择「工作区可用」，动态包含工作区全部成员
