### 介绍

腾讯的办公协同应用。

### 鉴权信息

获取access\_token是调用企业微信API接口的第一步，相当于创建了一个登录凭证，其它的业务API接口，都需要依赖于access\_token来鉴权调用者身份。

操作步骤：

1、【企业微信管理员操作】在企业微信的管理后台获取[**企业ID**](https://work.weixin.qq.com/api/doc/90000/90135/91039#14953/corpid)和[**应用Secret**](https://work.weixin.qq.com/api/doc/90000/90135/91039#14953/secret)；

2、【轻流系统工作区的管理员操作】在轻流连接中心-企业微信连接器-鉴权配置中输入上一步获取的企业ID和应用Secret，点击保存按钮便配置完成。

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/oPSERBAtEMlAxfD38xsHoMmPqbCF4A0p_.png)

#### 注意事项

**企业微信中每个应用都有独立的secret。由于目前连接中心各事件无法为每个事件都配置独立的鉴权，所以使用不同的事件时需要配置不同的Secret。**

为了可以同时使用不同的企业微信事件，当前的解决方案如下：

管理员在企业微信管理后台自建一个应用，然后在所需要用的标准应用中（如日程应用）给自建应用开通调用权限，便可使用该自建应用的secret来调用日程接口。如果还需要调用其他标准应用，则继续在相应的标 准应用下给该自建应用开通调用权限。而后在轻流系统中鉴权配置时输入自建应用的secret，即可同时使用多个事件。

### 事件信息

| 事件 | 描述 |
| --- | --- |
| 获取部门成员详情 | 获取指定部门所有成员的详细信息，包括姓名、手机号、邮箱、职位、用户ID、地址等等。详情可见获取部门成员详情 |
| 创建日程 | 通过企业微信的用户ID为指定成员创建日程。详情可见创建日程 |
| 创建群聊 | 通过企业微信群成员用户ID列表创建群聊。详情可见创建群聊会话 |
| 发送消息到群聊 | 向指定的企业微信群聊中发送指定格式的消息。详情可见应用推送消息 |

#### 发送文本消息到群聊

**前置条件：**

首先明确该接口只允许企业自建应用调用，即鉴权配置中的应用secret（corpsecret）必须为企业自建应用的，且该应用的可见范围必须是根部门。

其次，需要指定所要推送到的群聊的ID（chatid），该群聊必须是该应用所创建的，chatid可以通过创建群聊接口的返回值获取。

目前仅支持发送文本类型的消息。

> 限制说明

> 1、每企业消息发送量不可超过2万人次/分，不可超过30万人次/小时（若群有100人，每发一次消息算100人次）；

> 2、每个成员在群中收到的应用消息不可超过200条/分，1万条/天，超过会被丢弃（接口不会报错）。

> 摘自企业微信应用推送消息接口
