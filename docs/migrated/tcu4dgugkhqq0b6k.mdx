## 使用须知

**自2023年4月6日起，「在线支付」插件于「轻商城」中下架**

- **在此日期前，已安装过「在线支付」插件的工作区，依旧可以正常使用该插件**
- **在此日期后，未安装过「在线支付」插件的工作区内无法安装使用该插件**

**由此可能会给您带来不便，敬请谅解**

### **1.功能简介**

可以在填写表单时直接对填写者发起收款

### 2.设置步骤

#### 2.1申请开通在线支付

在线支付为基础版增购功能，基础版用户可在连接中心申请试用

#### 2.2 配置支付参数和微信支付

安装在线支付插件后，需要配置相关参数。目前仅支持微信支付

#### 2.3 在流程节点中配置在线支付

##### 2.3.1 功能入口

成功开通在线支付后，进入目标应用，点击「添加流程」，即可在需要的节点的「高级设置」中开启在线支付。目前支持「申请人节点」、「审批节点」以及「填写节点」开通在线支付

![文档图片](https://cdn.nlark.com/yuque/0/2024/png/43099917/1721292207631-a748d3b8-3145-4258-ab84-7ece0dd5d808.png)

- 审批节点为会签时，每个节点负责人都需要进行支付
- 需要该节点人员看到支付信息时，可在该节点中开启「支付信息」

##### 2.3.2 配置支付内容

点击开启在线支付后，需要配置支付内容和支付金额才可正式开启在线支付

![文档图片](https://cdn.nlark.com/yuque/0/2024/png/43099917/1721292256164-38abbb31-05a5-4350-a6a8-57b5cfb75ed2.png)

- 支付内容需设置为文本字段，支付金额需设置为数字字段

##### 2.3.3 支付状态

配置好支付内容后，会有三种支付状态

- 已支付：支付节点负责人已完成支付
- 未支付：支付节点负责人发起支付后，未完成支付，会在发起支付的2小时内展示「未支付」状态，此时节点负责人可以重新进行支付过程
- 支付关闭：支付节点负责人发起支付后，2小时内未完成支付，支付过程会关闭并展示「支付关闭」状态

##### 2.3.4 重新支付

开启在线支付的节点无论是否支付都会流转到下一步。需要重新支付时可以点击「我发起的」找到未支付的数据

![文档图片](https://cdn.nlark.com/yuque/0/2024/png/43099917/1721292350243-c597af3a-afec-4edc-a4f3-6e229a0643e2.png)

点击该条申请，并点击「重新支付」按钮即可重新进入支付界面，扫描二维码付款即可

![文档图片](https://cdn.nlark.com/yuque/0/2024/png/43099917/1721292365051-18e3ddbb-d005-480a-8bac-6d613e5fc061.png)

### 3.注意事项

- 每次进行提交/通过数据时，都会发起新的订单。支付后提交，又回退至原支付节点时，再次提交/通过数据会重新发起新的订单，请注意勿重复支付
- 批量导入、Q-robot添加、批量处理数据时，不会发起支付
- 受到微信支付平台的支付方式限制，在PC端生成的订单，只能在PC端扫码支付；在手机端生成的订单只能在手机进行支付
- 按步骤配置后无法正常支付并弹出「未知错误」时，请联系与贵司对接的客户成功经理提供必要的协助

### 4.常见错误原因及解决方案

常见轻流系统提示的错误如下表，可以根据具体的原因找到配置该功能的相关人员解决

| 轻流系统提示 | 原因 | 解决方案 |
| --- | --- | --- |
| 商户无接口权限，请联系管理员前往微信支付平台解决 | 商户未开通接口权限 | 请联系负责配置的相关人员，前往申请此接口权限 |
| APPID不存在，请联系管理员检查APPID是否正确 | 参数中缺少APPID | 请联系负责配置的相关人员，检查APPID是否正确 |
| MCHID不存在，请联系管理员检查MCHID是否正确 | 参数中缺少MCHID | 请联系负责配置的相关人员，检查MCHID是否正确 |
| 签名错误，请联系管理员检查配置 | 参数签名结果不正确 | 请联系负责配置的相关人员，检查签名参数和方法是否都符合签名算法要求 |
| 参数值与原请求需一致，请联系管理员确认参数问题 | 参数格式有误或者未按规则上传 | 请联系负责配置的相关人员，检查系统配置与微信提供的信息是否一致 |
| 账号余额不足 | 用户账号余额不足 | 账号余额不足，请充值或更换支付卡后再支付 |
| 商户订单已支付 | 商户订单已支付，无需重复操作 | 订单已支付完成，无需更多操作 |
| 订单已关闭 | 当前订单已关闭，无法支付 | 当前订单已超时自动关闭，需要重新申请下单支付 |
| 系统超时，请重新尝试 | 微信响应超时 | 请使用同样方法重新尝试 |
| APPID和MCHID不匹配，请联系管理员检查相关配置 | APPID和MCHID不匹配 | 请联系负责配置的相关人员，确认APPID和MCHID是否匹配 |
| 缺少参数，请联系管理员检查配置	缺少必要的请 | 缺少必要的请求参数 | 请联系负责配置的相关人员，检查参数是否齐全 |
| 订单重复提交 | 同一笔交易不能多次提交 | 请联系负责配置的相关人员，核实商户订单号是否重复提交 |
| XML格式错误 | XML格式错误 | 请联系负责配置的相关人员，检查XML参数格式是否正确 |
| 未使用POST传递传参 | 未使用post传递参数 | 请联系负责配置的相关人员，检查请求参数是否通过post方法提交 |
| POST数据不能为空 | post数据不能为空 | 请联系负责配置的相关人员，检查post数据是否为空 |
| 未使用UTF-8编码格式 | 未使用指定编码格式 | 请联系负责配置的相关人员，使用UTF-8编码格式 |
