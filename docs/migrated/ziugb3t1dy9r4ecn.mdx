## 年假管理

**场景实现对员工年假自动化管理**

**🔗**[**安装方案**](https://qingflow.com/center/template/detail/8e3da49a?type=3&tab=2&name=%E6%9C%80%E4%BD%B3%E5%AE%9E%E8%B7%B5)

### 第一部分 业务流程

#### 业务逻辑

![image.png](https://cdn.nlark.com/yuque/0/2021/png/21727618/1629872292510-7c07dae3-fcfe-46c2-b93c-6344ff6d86a2.png)

1. **年假基础表**-录入不同工龄对应的年假信息
2. **员工信息表**-录入员工信息并通过流程外Q-Robot更新数据功能每年自动计算员工年假，实现所有员工年假数据自动化管理
3. **年假管理表**-将新一年员工年假数据自动更新至员工信息表
4. **年假申请表**-员工可自主提交申请年假，系统自动更新剩余年假

#### 年假管理表

##### 表单设计

| 标题 | 使用字段 | 子字段 | 配置说明 |
| --- | --- | --- | --- |
| 员工姓名 | 成员 | - | 【可选范围】-【工作区所有成员】 |
| 入职日期 | 日期 | - | 【默认内容】-【自定义】 |
| 原工龄 | 数字 | - | 【默认内容】-【自定义】 |
| 当前工龄 | 数字 | - | 【默认内容】-【通过公式计算】 |
| 本年年假 | 数字 | - | 【默认内容】-【关联已有数据】-【年假基础表】-【年假】筛选条件：\{工龄\}==\{当前工龄\} |

【员工姓名】【入职日期】【原工龄】字段内容从应用「员工信息表」中添加过来，只需添加字段，没有其他设置

