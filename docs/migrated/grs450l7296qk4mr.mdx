## 场景/问题描述

在企业需要员工录入表单数据，其中表格默认5行，当下拉选择为符合时，第4行第5行描述内容字段不允许为空

## 思路逻辑

代码块进行校验判断第4行第5行下拉选择为符合时，描述内容字段是否为空，为空输出该行描述内容为空，并用多行文本接收（表单可隐藏），然后提交校验来判断多行文本是否为空，为空通过，不为空不允许通过。

```javascript
const result = qf_field.{表格$$16378B9B2$$}

let output = "";

// 处理第4行和第5行
const row4 = result[3];
const row5 = result[4];

// 判断第4行
if (row4.field_151461171 === "符合") {
  if (row4.field_151450611 === "" || row4.field_151450611 === null) {
    output += "第四行描述字段内容为空\n";
  }
}

// 判断第5行
if (row5.field_151461171 === "符合") {
  if (row5.field_151450611 === "" || row5.field_151450611 === null) {
    output += "第五行描述字段内容为空\n";
  }
}
qf_output={output}

```
