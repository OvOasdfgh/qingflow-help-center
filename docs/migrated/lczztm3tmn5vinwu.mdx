## 一、方案介绍

##### 1、简介

涵盖资产入库、领用、归还、转交、报修、盘点等各项资产相关操作，提供了全方位的资产管理方式；全面记录了资产的整条生命周期。

![image.png](https://cdn.nlark.com/yuque/0/2023/png/38812530/1699437073790-7a1abbf2-3f21-4e17-93d2-d408bfd68e0e.png)

##### 2、业务痛点&解决方案

| **业务痛点** | **解决方案** |
| --- | --- |
| **固资管理流程乱**传统固定资产管理采用人工记录的方式，多以纸质资料留存和流转，效率低下、更新困难且容易出错 | **智能化**资产全流程闭环管理数字化，智能化；轻松构建完备的资产数据库；数字化实现关键环节，加速企业落地资产管理系统。**规范性**贵重资产一物一码线上管理，线下溯源；加快处理领用/转交/归还的效率。**协同性**企业微信/钉钉/飞书资产领用更方便。**可视化**基于轻析自助式报表开发功能，使管理人员实施了解资产状况清晰呈现资产库存；快速掌握资产状况；全面呈现资产状况/耗材库存。 |
| **耗材管控力度弱**很多公司不重视耗材（低值易耗品）的管理，领用混乱、供应不及时现象频发，加大企业支出。 |  |
| **资产状态追溯难**资产管理经常涉及到转交、报修、报废等环节，缺少数字化管理手段就造成资产状态追溯困难、变更不及时的情况。 |  |
| **资产盘点效率低**资产盘点工作量巨大，传统人工+Excel的盘点模式不仅速度慢，而且极易出现错盘漏盘现象，资产盘点效率亟待提升。 |  |

## 一、公司资产如何流转？

`员工-领用资产``员工-归还资产``员工-管理资产``管理人员-管理资产`

##### 1、`员工` 领用资产

> 员工入职或需更换资产时，可选择需要领用的资产，并提交一条领用记录

![屏幕录制2023-11-10 10.51.40.gif](https://cdn.nlark.com/yuque/0/2023/gif/38812530/1699584875599-2d033c7f-3e47-4bd1-98dc-3e1732d7f2ec.gif)

##### 2、`员工` 归还资产

> 当员工离职或需要更换资产时，需要先将已领用的资产进行归还

![屏幕录制2023-11-10 10.56.30.gif](https://cdn.nlark.com/yuque/0/2023/gif/38812530/1699585247549-ac117297-827b-45b8-85c6-7e6d4b6332d9.gif)

##### 3、`员工` 报修资产

> 当成员发现资产丢失/需维修时，需要提交一条 资产异常工单

① 资产：又称「固定资产」，通常是比较贵重、使用期限较长的物品，需要一一跟踪记录，且每年会定期盘点，如办公桌、电脑、打印机等

② 耗材：多指低值的易耗品，如抽纸、水性笔、A4纸等

③ 盘点：企业通常每隔一段时间，对仓库中的物品进行清点，核对账上记录与实际库存量是否一致，以便准确掌握库存数量。一般分临时和定期盘点

④ 可领用的资产：当资产无领用人，且非报废、维修状态时，资产可被员工领用
