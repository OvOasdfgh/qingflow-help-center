### 功能简介

Q-Database可以实现数据库数据同步到轻流应用中，结合轻流流程引擎、表单引擎实现复杂业务的集成。

### 功能效果

数据库数据（view）——>轻流（应用）

（11）接收数据解析

选择对应字段，绑定对应列名，即可完成映射

支持的字段即校验规则如下

| 字段类型 | 赋值规则 | 接收数据解析 | 数据标识位 |
| --- | --- | --- | --- |
| 申请人 | 纯文本按照email匹配当前工作区用户,不过滤申请人范围，申请人未设置rule,则设置为匿名用户 | ✅ | ✅ |
| 1:单行文字 | 纯文本，不做格式校验 | ✅ | ✅ |
| 2:多行文字 | 纯文本，不做格式校验 | ✅ | ✅ |
| 3:数字 | 纯文本，不做格式校验 | ✅ | ✅ |
| 4:链接 | 纯文本，不做格式校验 | ✅ | ✅ |
| 5:日期 | 如果解析值可以转换成日期对象，则统一转换成’yy-mm-dd-hh:mm’格式，非法日期字符串则赋空值 | ✅ | ✅ |
| 6:起止时间 | ‘~’符号分割，分割后解析规则同日期字段，如果有一个值无法解析，则整个答案赋空值 | ✅ | ✅ |
| 7:手机 | 纯文本，不做格式校验 | ✅ | ✅ |
| 8:邮箱 | 纯文本，不做格式校验 | ✅ | ✅ |
| 9:单项选择 | 按照选项内容匹配，不存在且允许选择\[其他\]选项,则向其他选项赋值，否则赋空值，选项重名则选择第一个 | ✅ | ✅ |
| 10:下拉选择 | 按照选项内容匹配，不存在且允许选择\[其他\]选项,则向其他选项赋值，否则赋空值，选项重名则选择第一个 | ✅ | ✅ |
| 11:多项选择 | 按照选项内容匹配，不存在且允许选择\[其他\]选项,则向其他选项赋值，否则赋空值。 | ✅ | ✅ |
| 12:图片选择 | 根据\[文本显示值\]匹配，无匹配则赋空值 | ✅ | ✅ |
| 13:上传附件 | 支持，传文件/资源的url | ✅ | ❌ |
| 14:地址字段 | 支持 | ✅ | ❌ |
| 15:描述文字 | 过滤 | ❌ | ❌ |
| 16:富文本 | 过滤 | ❌ | ❌ |
| 17:段落 | 过滤 | ❌ | ❌ |
| 18:表格 | 过滤 | ❌ | ❌ |
| 19:定位 | 过滤 | ❌ | ❌ |
| 20:数据关联 | 纯文本，不做格式校验 | ✅ | ✅ |
| 21:成员字段 | 纯文本按照\[email\]查询当前工作区用户，不存在则赋空值 | ✅ | ✅ |
| 22:部门字段 | 纯文本按照\[部门名称\]查询当前工作去部门，重名部门则都赋值，不存在则赋空值 | ✅ | ✅ |
| 23:q-linker | 过滤 | ❌ | ❌ |
| 24:文字识别 | 支持，传文件/资源的url | ✅ | ❌ |

（12）同步处理

数据同步相关，可以选择是只「添加新数据」，还是要「更新已有数据」，「删除未同步数据」

![文档图片](https://cdn.nlark.com/yuque/0/2026/png/43099917/1768876927524-69f78ed6-ab18-43ac-b612-eaf731eda9df.png)

（13）数据标识位

通过数据标识位去识别是否是同一条数据。才能实现（12）的同步处理

![文档图片](https://cdn.nlark.com/yuque/0/2026/png/43099917/1768876927760-d2d40cc1-4443-4450-a35c-0bf0f4b3edb8.png)

待拉取数据的「数据标识位」字段值若为空值，会导致拉取失败。

待拉取数据的「数据标识位」字段值前面若有空格，会导致重复添加数据。

> 数据标识位个数限制在5个以内标识位类型：单行文本、数字、日期、时间、电话、邮箱

（14）异常通知

前置条件：专有云环境、开通Q-Database插件
可选择是否开启异常通知，开启时拉取数据失败/异常时对指定成员发送消息提醒

![文档图片](https://cdn.nlark.com/yuque/0/2026/png/43099917/1768876927708-8e8693c1-9cfd-4a04-bf89-e403a99f7b0f.png)

可以设置在拉取数据失败/异常时需要通知的成员，部门或角色
![文档图片](https://cdn.nlark.com/yuque/0/2026/png/43099917/1768876928309-fce195c8-076f-4d2c-bec7-3b9971a8a7b6.png)
同时还能选择提醒方式和异常通知频率限制
提醒方式有 站内信提醒 和 邮件提醒 两种
频率限制如下图所示

![文档图片](https://cdn.nlark.com/yuque/0/2026/png/43099917/1768876928513-86d2775b-30e0-41ab-aec0-dee45d3972ed.png)

至少设置一个通知人、且至少选择一个通知方式时发送提醒

当Q-Database执行失败时，就会根据勾选情况发送站内信/邮件给对应提醒人。
邮件提醒示例：您的应用「Q-Databse示例应用」在（具体时间） 触发的Q-Database「具体操作」执行失败，“查看日志”（实为跳转链接）
站内信提醒示例：您的应用「Q-Databse示例应用」在（具体时间） 触发的Q-Database「具体操作」执行失败。“查看日志”（实为跳转链接）
