该接口用于获取在通讯录中的外部组织信息。

---

#### 权限说明

限专有轻流可用。「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有通讯录的权限。

#### 路径参数

无

#### 请求

**请求方式：GET**

**请求地址：**[https://自有域名/openApi/external/dept/get/\{deptId\}](https://xn--eqrt2gz0rng0a/openApi/manager/sub)

**请求头（header）**

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| `accessToken` | string | 是 | 可在【插件中心】-【openAPI】查询每个工作区的accessToken，token没有时限，除非手动重置 |

**REST参数**

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| deptId | string | 是 | ​<br /> |

#### 返回

**返回体 **

| 参数 | 类型 | 是否必含 | 说明 |
| --- | --- | --- | --- |
| errCode | int | 是 | 错误代码 |
| errMsg | string | 是 | 错误信息 |
| result | object | 是 | 返回对象信息 |
| name | string | 是 | 名字 |
| id | long | 是 | 外部id |
| ordinal | long | 是 | 顺序 |
