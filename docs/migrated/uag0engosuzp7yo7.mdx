## 功能简介

户可在插件中心设置Q-Linker模板，并设置\[变量\]和\[变量默认值\]。模板设置后可在本工作区所有应用的Q-Linker字段编辑时使用，使用时绑定该模板以及模板变量即可。

### 使用限制

1. 此功能属于企业版功能，仅企业版用户可以使用
2. 插件中心开启后可用

### 设置步骤

#### 模版配置

- 插件中心->第三方连接->Q-Linker处。

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-09/jnrSEUXXDM6qWIx5afe56BuCOzozNwX4_.png)

Q-Linker模板配置与Q-Linker的配置基本一致，区别在于模板可以创建\[变量\]，\[变量\]可在所有输入参数的地方使用

每个变量可以设置默认值，默认值会在\[表单编辑 -> Q-Linker配置 -> 变量绑定\]没有绑定该\[变量\]的时候生效。

以【实时汇率换算】案例为例，（如果你在全局配置>创建变量>fromCode填入默认值，则表单编辑>Q\_Linker配置>绑定变量下的fromCode就可以不做配置；）

上图是美元（USD）和澳币（AUD）之间的汇率换算；

如果你想实现其他币种之间的汇率换算，你只需要修改上图的fromCode（需要被换算的币种）/toCode（目标币种）就行。

## 注意事项

全局配置时，如果变量被删除，但是插入变量的位置没有删除，会在构建http请求的时候插入null。

若在编辑应用时，没有为全局配置过的变量赋值，在构建http请求的时候会插入全局配置的默认值（若没有设置默认值，则插入空值）。
