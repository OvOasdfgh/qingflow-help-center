## 1 功能简介

关于盖章，你是否遇到过一下问题：

- 相关合同/文件要给不同的部门盖章时，流程繁琐，还经常找不到人，时间都浪费在路上？
- 企业跨地区的合同/文件签署还需要快递，耗时长，拖慢整条供应链/项目进度，干着急？

用轻流的电子签章可以让你实现在线上业务流程中进行盖章，无论随时随地进行高效盖章，所有签署的文件与纸质盖章文件一样，具有法律效应！

## 2 设置步骤

### 2.1 提交电子签章开通申请

在【插件中心-电子签章】中，点击“申请使用”，下载文件并按要求填写以下信息后，

- 企业名称
- 企业授权人信息
- 企业盖章
- 企业授权人签名

https://qingflow.com/center/plugin/detail/18

这里的企业授权人也是**签章唯一管理人**，相关企业认证和签章管理也只有该授权人有权操作哦～

![文档图片](https://hc.qingflow.com/wp-content/uploads/2019/09/%E7%94%B5%E5%AD%90%E7%AD%BE%E7%AB%A0%E5%BC%80%E9%80%9A.gif)

待填写完毕后，上传扫描件提交审核即可。

### 2.2 签章管理员进行个人认证

电子签章使用审批通过后，签章管理员（即《电子签章申请表》中的企业授权人）前往【个人中心-认证中心】中进行个人实名认证。

![文档图片](https://hc.qingflow.com/wp-content/uploads/2019/09/%E4%B8%AA%E4%BA%BA%E8%AE%A4%E8%AF%81%E4%BF%A1%E6%81%AF.2019-09-02-17_33_53.gif)

### 2.3 签章管理员进行企业认证

**签章管理员**点击插件中心的「进行企业认证」，然后在新打开的认证页中，提交相关企业信息，并点击完成企业认证后，返回插件中心，点击确认“完成企业认证”即可

![文档图片](https://hc.qingflow.com/wp-content/uploads/2019/09/%E7%94%B5%E5%AD%90%E7%AD%BE%E7%AB%A0-%E4%BC%81%E4%B8%9A%E8%AE%A4%E8%AF%81.2019-09-02-17_13_57.gif)

### 2.4 设置进行实名认证的成员

如果需要将签章给其他成员使用的话，需要先设置进行实名认证的成员，这样成员就能收到一条实名认证通知，并前往进行实名认证。等成员实名认证完成后，就可以把签章授权给成员使用啦！

![文档图片](https://hc.qingflow.com/wp-content/uploads/2019/09/%E8%AE%BE%E7%BD%AE%E5%AE%9E%E5%90%8D.2019-09-02-17_26_19.gif)

### 2.5 添加签章&授权使用

在【电子签章-签章管理】点击“添加签章”，上传签章图片，并设置签章名称，

以及将签章授权给已实名的成员使用，比如，把“人事章”授权给人事总监，将“财务章”授权给财务总监使用等。

![文档图片](https://hc.qingflow.com/wp-content/uploads/2019/09/%E6%B7%BB%E5%8A%A0%E4%BA%BA.2019-09-02-17_40_27-1.gif)

### 2.6 在审批节点中配置电子签章

在进行签章审批的审批节点上，**设置签章使用人为节点负责人**，然后开启“签章审批”功能，添加需要进行盖章的附件字段，并**选择该附件字段需要盖的章**，设置完后发布即可。

![文档图片](https://hc.qingflow.com/wp-content/uploads/2019/09/%E7%9B%96%E7%AB%A0%E8%8A%82%E7%82%B9.2019-09-02-18_06_12.gif)

注：该节点中所设置的所有附件字段的所有文件，都必须盖章后才能通过节点

这样数据到达该节点时，节点负责人就会收到一条待办，打开待办后，点击“盖章”，然后就可以选择某附件后进行盖章。若附件中含有多个文件还能同时打开，一起盖章～

![文档图片](https://hc.qingflow.com/wp-content/uploads/2019/09/%E7%AD%BE%E7%BD%B2.2019-09-02-19_28_56.gif)

盖章完毕后，点击盖章完成，并完成意愿认证即可～

### 3 收费相关

电子签章以完成一个文件盖章作为最小收费单位。即每对一个文件盖章，就会按照使用一次电子签章进行收费。其中，单个文件内不限制文件页数和盖章数量

| 可开通的版本 | 基础版及以上版本 |  |
| --- | --- | --- |
| 付费即赠送 | 1次企业身份认证，不限制次数的个人实名认证，2次签署 |  |
| 购买规则 | 可签次数/年 | 费用 |
| 500套餐 | 500 | 2500元/年 |
| 1000套餐 | 1000 | 5000元/年 |
| 2000套餐 | 2000 | 8000元/年 |
| 5000套餐 | 5000 | 15000元/年 |

特别说明：专有轻流客户如果自行购买的E签保官方服务，可以在部署的时候配置为自己购买的服务，配置好以后可正常使用！
