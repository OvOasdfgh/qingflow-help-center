### 二、获取access\_token

#### 1、postman测试

1. 接口说明：用户获取调用聚水潭OpenApi的凭证token，授权后超过30天不使用，token会失效，需要重新进行授权
2. 接口地址：[https://connect.oalite.com/api/jst/accessToken](https://connect.oalite.com/api/return)
3. 请求方式：GET
4. 请求头（Header）：无
5. 请求参数（查询参数）：

| ​参数 | 是否必填 | 说明 |
| --- | --- | --- |
| username | 是 | 聚水潭账号 |

- 请求示例

```bash
curl --location 'https://connect.oalite.com/api/jst/accessToken?username=1*848021***'
```

- 响应示例

```json
{
    "errCode": 0,
    "data": {
        "access_token": "eb8d3cffcf4b4590aefc44e640906600"
    },
    "errMsg": null
}
```

![image.png](https://cdn.nlark.com/yuque/0/2023/png/28884377/1693560895766-e795a14f-c28e-4cd2-8833-6dc655acab86.png)

### 三、以查询聚水潭采购单为例

对应的接口文档：[https://openweb.jushuitan.com/dev-doc?docType=6&docId=26](https://openweb.jushuitan.com/dev-doc?docType=6&docId=26)

#### 准备工作：

##### 1、进行聚水潭参数加签操作

1. 接口说明：用户调用聚水潭需要进行参数加签，包含时间戳，token等参数；该接口对加签进行了封装，返回内容可以直接用于调用聚水潭openApi接口
2. 接口地址：[https://connect.oalite.com/api/jst/signature](about:blank)
3. 请求方式：POST
4. 请求头（Header）：无
5. 请求参数（查询参数）：

| ​参数 | 是否必填 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 鉴权接口获得的token |

1. 请求体：根据请求的聚水潭接口的请求体确定

1. 以聚水潭采购单查询中的请求示例为例

1. 实际业务场景可以根据接口文档的请求参数做具体调整

![image.png](https://cdn.nlark.com/yuque/0/2023/png/28884377/1693563002438-333e4591-2730-4c93-93a3-627c22f9ce81.png)

1. 请求示例：以请求聚水潭采购单查询接口为例

```json

--header 'Content-Type: application/json' \
--data '{"so_ids":[],"page_index":1,"modified_begin":"2023-08-10","modified_end":"2023-08-16","page_size":30,"po_ids":[]}'
```
