调用该接口，获取单条数据的流程日志

---

### **权限说明**

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有对应应用的权限。

### 请求

**请求方式：GET**

**请求地址：**https://api.qingflow.com/\{appKey\}/\{applyId\}/workflowNodeRecord（公有云版本）

请求地址中:appKey和applyId为需要替换的变量，根据实际获取值更新，示例如下：

```javascript
GET https://api.qingflow.com/123456/123456/workflowNodeRecord
```

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com//\{appKey\}/\{applyId\}/workflowNodeRecord](https://api.ding.qingflow.com/:applyId/audit)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/\{appKey\}/\{applyId\}/workflowNodeRecord

#### **参数说明(路径参数)**

| **参数** | **必须** | **说明** |
| --- | --- | --- |
| appKey | 是 | 应用 id，获取方式详见[基本概念介绍](https://exiao.yuque.com/ixwxsb/bgzs0e/cl59vxilcqdkmq1h) |
| applyId | 是 | 数据的id，获取方式参考：基本概念介绍 |

#### **参数说明(查询参数)**

| **参数** | **必须** | **说明** |
| --- | --- | --- |
| pageNum | 是 | 数据页码 |
| pageSize | 是 | 数据页数 |

#### **请求头（Header）**

| **参数** | **必填** | **说明** |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看基本概念介绍 |
