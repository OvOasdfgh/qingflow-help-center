#### DeepSeek API 使用文档

欢迎使用 DeepSeek API！以下是详细的接口使用文档，帮助您快速了解和使用我们的服务。

---

##### 1. 概述

DeepSeek API 提供了多种功能，如文本生成、文本补全、对话交互和内容安全检测。这些功能基于先进的大语言模型，支持多种语言和场景。

---

##### 2. 功能概述

- **文本生成**：根据输入生成文本。
- **文本补全**：根据上下文补全文本。
- **对话交互**：支持自然对话。
- **内容安全**：检测敏感内容。

---

##### 3. 快速上手

###### 3.1 接口地址

```http
POST https://api.deepseek.com/v1/chat/completions
```

###### 3.2 请求格式

```json
{
  "messages": [
    {
      "role": "system",
      "content": "您是一个AI助手，以自然的方式回答问题。"
    },
    {
      "role": "user",
      "content": "今天天气如何？"
    }
  ],
  "model": "deepseek-chat",
  "temperature": 0.7,
  "top_p": 0.9,
  "max_tokens": 1000,
  "stream": false
}
```

###### 3.3 返回格式

```json
{
  "id": "chatcmpl-xxxxxxxxxxxx",
  "object": "chat.completion",
  "created": 1677667200,
  "model": " "model": "deepseek-chat",
  "messages": [
    {
      "role": "assistant",
      "content": "今天天气晴朗..."
    }
  ],
  "usage": {
    "prompt_tokens": 10,
    "completion_tokens": 20,
    "total_tokens": 30
  }
}
```

---

##### 4. 请求参数

###### 4.1 必选参数

- **messages**：消息列表，包含role（system/user/assistant）和content。
- **model**：模型名称，如 deepseek-chat。

###### 4.2 可选参数

- **temperature**：控制生成随机性，0-1之间，默认0.7。
- **top\_p**：控制生成多样性，0-1之间，默认0.9。
- **max\_tokens**：最大生成token数，默认1000。
- **stream**：是否流式返回，默认false。

---

##### 5. 返回结果

- **id**：响应ID。
- **object**：对象类型。
- **created**：时间戳。
- **model**：使用模型。
- **messages**：assistant的消息。
- **usage**：token统计。

---

##### 6. 错误码

| 错误码 | 描述 |
| --- | --- |
| 400 | 错误请求 |
| 401 | 未授权 |
| 403 | 禁止访问 |
| 404 | 资源未找到 |
| 429 | 请求过多 |
| 500 | 服务器错误 |

---

##### 7. 使用示例

###### 7.1 Python 示例

```python
import requests

url = "https://api.deepseek.com/v1/chat/completions"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer YOUR_API_KEY"
}

data = {
    "messages": [
        {"role": "system", "content": "您是一个AI助手。"},
        {"role": "user", "content": "今天天气如何？"}
    ],
    "model": "deepseek-chat"
}

response = requests.post(url, headers=headers, json=data)
print(response.json())
```

###### 7.2 JavaScript 示例

```javascript
const options = {
  method: 'POST',
  url: 'https://api.deepseek.com/v1/chat/completions',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_API_KEY'
  },
  data: {
    messages: [
      { role: 'system', content: '您是一个AI助手。' },
      { role: 'user', content: '今天天气如何？' }
    ],
    model: 'deepseek-chat'
  }
};

axios(options).then(response => console.log(response.data));
```
