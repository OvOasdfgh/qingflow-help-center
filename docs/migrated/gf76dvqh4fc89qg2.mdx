## 应用场景

产品介绍：

旺店通是一款专门为电商量身定做的电商ERP系统软件,致力于提供专业的电子商务ERP解决方案,能全面覆盖线上电商、网店以及线下实体店进销存管理及wms仓储管理系统等

官网：[https://www.wangdian.cn/](https://www.wangdian.cn/)

API文档：[https://open.wangdian.cn/qyb/open/apidoc](https://open.wangdian.cn/qyb/open/apidoc)

实现目标：

通过轻流应用表单实现与旺店通（企业版）进行对接

Ps:

1、目前批量获取数据暂时只能存放在表格中并且只能获取部分数据，体验上会有点不好。

不过后续产品QS主动支持代码块处理即可实现定时轮训获取。如果不想要放在表格中，可以采用定制开发来实现

2、部分接口暂时无法通过轻流实现，原因是由于数组中需要嵌套数组，但可以使用代码块进行数据处理，望知晓，例如：创建原始订单（[https://open.wangdian.cn/qyb/open/apidoc/doc?path=trade\_push.php](https://open.wangdian.cn/qyb/open/apidoc/doc?path=trade_push.php)）

#### 2、代码块实现

以文档所举为示例，其中timestamp计算规则：北京时间1970-01-01 08:00:00起至现在的总秒数，10位int值,旺店通企业版API服务端允许请求最大时间误差为5min，date.timezone = Asia/Shanghai。

```javascript
const { differenceInSeconds, parse } = require('date-fns');
const crypto = require('crypto');

// 通过当前时间和起始时间计算总秒数
function calculateTotalSeconds() {
  const startTime = parse('1970-01-01 08:00:00', 'yyyy-MM-dd HH:mm:ss', new Date(), { timeZone: 'Asia/Shanghai' });
  const currentTime = new Date();
  const seconds = differenceInSeconds(currentTime, startTime);
  return seconds;
}
// 输出总秒数时间戳
const totalSeconds = calculateTotalSeconds();

// 请求参数
const params = {
  appkey: 'test2-xx',
  page_no: 0,
  end_time: '2016-08-01 13:00:00',
  start_time: '2016-08-01 12:00:00',
  page_size: 40,
  sid: 'test2',
  timestamp: totalSeconds,
};

// 第一步：参数排序
const sortedParams = Object.keys(params).sort().reduce((acc, key) => Object.assign(acc, { [key]: params[key] }), {});

// 第二步：处理每个参数
const processedParams = Object.keys(sortedParams).map((key) => {
  let value = sortedParams[key].toString();
  let length = Buffer.byteLength(value, 'utf8').toString().padStart(4, '0');
  let processedValue = `${length}-${value}`;
  return `${Buffer.byteLength(key, 'utf8').toString().padStart(2, '0')}-${key}:${processedValue};`;
});

// 第三步：计算 sign
const appsecret = '12345';
const signString = processedParams.join('');
const index = signString.indexOf('09-timestamp'); // 获取 "09-timestamp" 的索引位置
const semicolonIndex = signString.indexOf(';', index); // 获取在 "09-timestamp" 后面的分号的索引位置
const result = signString.slice(0, semicolonIndex) + signString.slice(semicolonIndex + 1); // 切割字符串，并删除找到的分号
const sign = crypto.createHash('md5').update(`${result}${appsecret}`).digest('hex');

// 添加 sign 参数
params.sign = sign;

qf_output={params}
```
