获取工作区子管理员配置情况

---

### **权限说明**

仅「超管accessToken」拥有调用权限。（权限组accessToken无法调用）

### 请求

**请求方式：**GET

**请求地址：**https://api.qingflow.com/manager/sub（公有云版本）

钉钉版本：[https://api.ding.qingflow.com/manager/sub](https://api.ding.qingflow.com/manager/sub)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/manager/sub

#### **2.1 参数说明(路径参数)：**

无

#### **2.2 参数说明(查询参数)：**

无

#### **2.3 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

#### **2.4 请求体（Body）**

无

#### **2.5 请求体示例**

无

### 返回

#### 3.1 返回体

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| errCode | string | 是 | 错误码 |
| errMsg | string | 是 | 错误描述 |
| result | object | 是 |  |
| subManagers | \[array\] | 是 | 子管理员配置 |
| subManagerId | string | 是 | 子管理员id |
| submanagerName | string | 是 | 子管理员名称 |

| userName | string | 是 | 用户名称 |
| departs | array |  | 部门id集合 |
| deptId | number | 是 | 部门id |
| deptName | string | 是 | 部门名称 |
| roles | array |  | 角色id集合 |
| roleId | number | 是 | 角色id |
| roleName | string | 是 | 角色名称 |
| beingSubDepart | boolean | 是 | 是否包含子部门 |
| appAuthConfig | object | 是 | 应用权限配置 |
| beingAuthApp | boolean | 是 | 应用权限配置 |
| beingEditApp | boolean | 是 | 应用权限是否开启 |
| beingAddApp | boolean | 是 | 应用编辑权限 |
| beingDelApp | boolean | 是 | 删除应用权限 |

| apps | array | 是 | appKey 应用唯一标识 |
| appKey | string | 是 | 应用key |
| appName | string | 是 | 应用名称 |
| dashs | array |  | 门户唯一标识 |

| tags | array | 是 | 应用包id |

| tagName | string | 是 | 应用包名称 |
| authContactConfig | object | 是 | 通讯录权限配置 |
| beingAuthContact | boolean | 是 | 通讯录权限 |
| qingStoreAuthConfig | object | 是 |  |
| beingUseSolution | boolean | 是 | 解决方案是否开启 |
