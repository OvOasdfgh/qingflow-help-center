### 1 功能概述

流程审批作为轻流平台的高频场景，企业在各个应用中积累了很多流程相关的历史数据。本次「时效分析」的统计范围，主要是针对「填写、审批」这一类人工节点的流程数据，可以帮助企业对流转效率、绩效考核等业务诉求提供数据参考。

该板块以系统默认仪表盘的形式，提供了一套业务数据的统计看板，降低了管理者/搭建者搭建报表的成本，同时通过数据导出为统计数据的深度挖掘提供可能性。另外，除了支持应用内的时效分析，本次特别增加了管理后台入口，可直接筛选查看某个应用的时效分析。

不同于历史版本中对流程数据的精简概览、无法对流程的流程人效详尽分析，新版本中支持的统计数据如下：

1. 对已设置「超时、预警」的审批节点，可查看预警/超时汇总数据、具体节点的超时明细
2. 具体流程的汇总统计，包括总指标、近期发起/处理个数、近期案例的处理时长
3. 某月份的流程统计数据、节点在该月份的处理情况，包括人员/部门排名，处理结果的分布
4. 若对流程的时效有更深、更多的需求，支持全部案例的汇总和明细，可筛选或导出案例明细，进行数据的进一步处理和分析

### 2 功能入口

流程时效分析功能界面可通过以下路径进入：

1. **应用内入口**：在轻流的**应用页面**，选择目标应用。进入应用后，点击**数据管理**，选择**时效分析。**

![1.gif](https://cdn.nlark.com/yuque/0/2025/gif/2056184/1740451672504-1227451f-7ced-4040-a547-8590e165342d.gif)

1. **管理后台入口**：在轻流的**管理后台**，选择**时效分析**。需选中一个应用，查看该应用的时效分析数据。

![2.gif](https://cdn.nlark.com/yuque/0/2025/gif/2056184/1740451738740-f1284bbd-0d17-4a0e-924a-74e4334c4d2e.gif)

### 3 名词解释

| **字段名称** | **定义** |
| --- | --- |
| **流程** | 每个应用可配置一个标准的流程规则，应用中手动填写、自动生成或批量导入的每一条数据，都会按照同一套规则进行流转。 |
| **节点** | 一个流程中，可配置多个节点，目前轻流主要支持人工节点（填写、审批）、逻辑节点（分支）、自动化（QRobot、发消息）节点 3 个类型。 |
| **案例** | 应用如果配置了流程，当有一条新的数据产生时（手动填写或自动生成），同时新增了一个「案例」，案例的流转规则以「流程设置」为准，流转情况则以实际的「数据」为准。一条数据与一个案例是一一对应的关系。一个应用内，有多个数据、多个案例。 |
| **步骤** | 一个案例，在流程流转过程中会产生多个步骤，步骤的核心是对某个案例处于某个节点是的统计情况，每个步骤开始于上一个步骤结束时间，结束于当前步骤的操作时间。处理一个步骤，即对某个步骤进行了「通过/回退/拒绝」等处理。 |
| 超时统计 | 当前应用中，开启了「预警或超时」设置的全部节点。 |
| 超时预警率 | 案例中步骤触发了节点的「超时预警」且「处于当前节点未被处理」的步骤数占本应用「途径该节点」所有步骤的百分比。 |
| 超时率 | 案例中步骤触发了节点的「超时」且「处于当前节点未被处理」的步骤数占本应用「途径该节点」所有步骤的百分比。 |
| 案例状态 | 进行中：案例尚未完成，仍在处理中。已通过：案例已成功完成。已拒绝：案例被拒绝或终止。 |
| 案例处理时长 | 案例从开始到结束的总时长。若案例仍在进行中，则计算从开始时间到当前时间的时长。 |
| 节点平均处理时长 | 所有途径该节点且已被处理的步骤的平均处理时长，计算公式为：步骤结束时间 - 步骤开始时间。 |
| 超时节点个数 | 当前案例中触发了「已超时」的节点个数。 |
| 步骤处理时长 | 步骤已结束：步骤结束时间 - 步骤开始时间。步骤未结束：当前时间 - 步骤开始时间。 |
| 是否超时 | 若该步骤触发了「节点超时」，则显示为「是」。若未触发，则显示为「否」。若节点未设置超时，则显示为「-」。 |

### 4 功能介绍

#### 4.1 超时统计

- 若流程中的审批节点设置了「超时或预警」，则在时效分析中可查看具体的预警率、超时率的统计指标
- 超时统计的统计范围，按节点划分，分为「截止至昨天未被处理的步骤（部分）」和「截止至昨天所有步骤（全部）」2 个维度
- 每个节点，可查看当前节点的配置信息，以及所有触发了「超时」的案例、步骤明细

#### 4.2 案例统计

- 可查看当前应用内的流程统计概览，包括平均处理时长、发起总数等
- 可查看近期一段时间内，案例处理个数、处理时长的时间走势图
- 对所有进行中的案例，可查看处于不同节点的分布情况
- 可查看某个节点的历史处理时长统计情况

#### 4.3 节点统计

- 支持按月查看流程的统计情况，包括当月内案例发起的人员、部门排名，当月具体节点被处理的平均处理时长
- 针对具体节点，可查看当前节点当月被处理的实际情况分布、节点处理的人员、处理时长排名

### 4 注意事项

1. 统计范围：由于「案例、步骤」为新的数据标识id，**「时效分析」仅对该服务上线之后的新发起的数据生效**。公有云环境上线时间为 2025.02.28。除案例明细、步骤明细、超时明细为实时数据外，其他的统计指标，均为截止至昨天的数据
2. 支持版本：专有云仅支持 7.0.0及以上版本
3. 限时免费：目前免费版本每个工作区可开启 1 个应用的「时效分析」。付费版本（含专有轻流）中每个工作区可手动开启 10 个应用的「时效分析」功能
4. 历史数据：时效分析上线之前发起的历史数据，功能入口仍为「数据管理/概览」
