删除成员

---

### **权限说明**

仅专有轻流支持；

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有通讯录权限。

### 请求

**请求方式：**DELETE

**请求地址：**专有轻流：[https://自有域名/openApi/user/:userId](https://xn--eqrt2gz0rng0a/openApi/user/:userId)

> 请求地址中:userId为需要替换的变量，根据实际获取值更新，示例如下：

```javascript
DELETE https://abcd.qingflow.com/openApi/user/888888
```

#### **2.1 参数说明(路径参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| userId | 是 | 用户ID，获取方式参考：基本概念介绍 |

#### **2.2 参数说明(查询参数)：**

无

#### **2.3 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

#### **2.4 请求体（Body）**

无

#### **2.5 请求体示例**

无

### 返回

#### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| result | 是 | object | 返回结果 |
| userId | 是 | istring | 用户ID |

#### 3.2 返回体示例

```json
{
	"errCode": 0,
	"errMsg": "ok",
	"result": {
		  "userId": "888888"
	  	}
}
```
