## 配置过程

### 表单和流程设计（方法一）

#### A应用

主表单：销售单号填入

表格：商品名称、销售地区、销售数量填入

![image.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662692340205-379680b9-1383-4682-a4e2-c85b3942a0a2.png)

Q-Robot添加销售单号到B应用，在B应用中创建一条数据。

![image.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662694654362-7ab0c1d4-a174-4d55-8e72-b79640a2aaaa.png)

Q-Robot拆分表格行数据到中间应用，只传入销售单号和商品名称。

![image.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662694668299-083075b2-bc2d-4bfc-b70a-35b196adc193.png)

#### 中间应用

主表单：销售单号、商品名称自动传入

销售数量自动关联

关联A应用的“销售数量”，筛选同一销售单号和商品名称，聚合方式求和

去重校验自动关联

关联当前应用即中间应用的“商品名称”，筛选同一销售单号和商品名称，聚合方式计数

若结果不为空，那就出现了重复。

​

![image.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662692449337-e3bc8058-b634-4057-99f7-0032cf5e1760.png)

![image.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662692470261-6938ab75-cd9a-4b57-bf77-27db302be6af.png)

因销售数量和去重校验，不是通过Q-Robot自动传入的数据，因此需要开启提交重新计算。

去重校验字段，需要设置提交校验：ISEMPTY(去重校验) 仅当为空时，才允许通过。

![截屏2022-09-09 上午11.38.20.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662694762232-8a2e7e3d-d5e7-4edb-84ac-7ffbc949d0ef.png)

数据提交后，Q-Robot更新，实现添加表格行到B应用（商品名称、销售数量）

### 代码块和公式（方法二）

#### 代码块去重

```javascript
var tableA = qf_field.{A$$79665CAD$$};
for(var i =0 ;i< tableA.length ;i++){
for(var j = i+1 ; j< tableA.length ; j++){
if(tableA[i].field_78431747 == tableA[j].field_78431747){
tableA.splice(j,1);
 j--;
}
}
}
qf_output = {tableA : tableA}
```

​

注：qf\_field.\{A$$79665CAD$$\}需要手动更改为应用的A表格字段；field\_78431747是A表格子字段ID（需要去重的字段ID），需要根据运行结果得到数据后，手动更改为应用内的字段代码。
