## 一、简介

### 1.1 功能简介

条件格式支持用户根据自定义的筛选条件，对满足条件的数据应用特定的样式（如颜色标记）。通过可视化高亮的方式，帮助用户快速识别重点信息或异常数据，提升数据洞察效率。

> 在轻析中，只有汇总表、明细表和指标看板支持设置条件格式单个字段的条件格式上限为20条

### 1.2 使用场景

适用于需要对数据进行标记显示的场景，例如异常气温的强调显示、对产地相同商品的统一标记等

## 二、设置步骤

### 2.1 功能入口

以汇总表为例，点击报表功能界面中条件格式右侧的按钮，即可进入条件格式的设置页面

![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1754029969218-ba973503-9c4d-4c72-9070-e22d9825994f.png)

### 2.2 功能设置步骤

#### 2.2.1 添加条件格式

点击添加字段按钮，选择一个字段作为条件格式筛选的目标字段，需要注意的是，筛选字段的范围仅限于报表中已经添加的 **维度字段** 和 **指标字段**。

这样，用户可以根据维度或指标的数据值设置条件格式，从而高亮显示符合特定标准的数据。

![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1754030003650-e38e8104-d5a0-4c7b-b4c1-b67d8a2cd22e.png)

#### 2.2.2 选择判断符

判断符用于设置筛选逻辑，判断某一字段的值是否符合特定条件，从而确定数据是否应当被筛选出来。不同字段类型所支持的判断符种类也会有所不同。字段类型与判断符的匹配关系见附录。

> 附录一 条件格式字段与判断符的匹配关系

![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1754032394906-0c392ccd-b1d5-46d3-960e-daff0f9dbf4a.png)

#### 2.2.3 输入条件内容

**条件内容**指的是你设定的筛选判断中，与字段值进行比较的**目标值**，是判断数据是否满足筛选条件的关键依据。不同类型的字段所允许填写的条件内容是不同的。

> 附录二 字段与条件内容的匹配关系

#### 2.2.4 添加多个条件格式

点击字段条件格式区域右侧的加号，可以针对该字段增加条件格式，实现多个条件格式的共同筛选

⚠️注意

当字段设置了多个条件格式时，**排在最上方的条件格式优先级最高**，其余条件格式的优先级从上至下依次递减。可以通过拖拽条件格式更改优先级排序

例如，设置两个条件格式，条件格式1用红色标记大于400的数据，条件格式2用橙色标记大于400的数据，由于条件格式1在上方，优先级更高，所以大于400的数据被标红而不是被标橙

![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1754031652674-ee3de5f9-6211-4df5-ad81-42b027040269.png)

#### 2.2.5 删除条件格式

方式一：点击字段条件格式区域右侧的减号，可以删除某个字段的某一个条件格式
![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1754031676654-e4bcb968-5f0f-4ed6-a488-39feb777dd03.png)

方式二：点击条件格式区域右上角的垃圾桶图标，能够删除某个字段的所有条件格式设置

![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1754031716276-a8333f87-a719-4a21-b7ac-5f649001efa8.png)

方式三：点击报表界面条件格式区域右侧的垃圾桶图标，能够删除某个字段的所有条件格式设置

![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1754031785994-7f25ea18-996e-4158-a930-0361917e04ca.png)

#### 2.2.6 显示效果设置

点击条件格式区域右侧字母样式的按钮，可以调整单元格的背景颜色和文字颜色，更改筛选后的显示效果

![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1754031830958-9c330dea-e48d-456d-9e26-6212d6975718.png)

| **判断符** | **支持字段** | **判断符释义** |
| --- | --- | --- |
| 等于 | 所有字段 | 当字段的内容与输入内容相等时，满足条件 |
| 不等于 | 所有字段 | 当字段的内容与输入内容不同时，满足条件 |
| 包含 | 文本类字段起止时间字段成员字段 | 文本类字段：字段中包含所有输入内容的文本时，满足条件起止时间字段：字段中的时间范围大于等于输入内容中的时间范围时，满足条件成员字段：字段中包含所有筛选内容的成员时，满足条件 |
| 不包含 | 文本类字段起止时间字段成员字段 | 文本类字段：字段中不包含所有输入内容的文本时，满足条件起止时间字段：字段中的时间范围小于输入内容中时间范围或二者时间范围部分重合时，满足条件成员字段：字段中的成员不包含所有输入内容中的成员时，满足条件 |
| 属于 | 文本类字段成员字段日期字段起止时间字段 | 文本类字段：输入内容的文本包含字段所有的文本时，满足条件成员字段：输入内容的成员包含字段的所有成员时，满足条件日期字段：输入内容的时间范围小于字段中的日期时间，满足条件时间段字段：输入内容的时间范围大于等于字段的时间范围时满足条件 |
| 不属于 | 文本类字段成员字段日期字段起止时间字段 | 文本类字段：输入内容的文本不包含字段的所有文本时，满足条件成员字段：输入内容中的成员不包含所有字段的成员时，满足条件日期字段：输入内容的时间范围不包含字段的日期时，满足条件起止时间字段：输入内容的时间段大于字段的时间段，或二者只有部分重合时，满足条件 |
| 大于 | 数字字段日期字段起止时间字段 | 数字字段：字段的值大于输入的值时，满足条件日期字段：字段的日期在输入日期之后时，满足条件起止时间字段：字段的开始日期在输入的日期之后时，满足条件 |
| 大于等于 | 数字字段日期字段起止时间字段 | 数字字段：字段的值大于等于输入的值时，满足条件日期字段：字段的日期是输入日期当天或之后时，满足条件时间段字段：字段的开始日期与输入的日期相同时，满足条件 |
| 小于 | 数字字段日期字段起止时间字段 | 数字字段：字段的值小于输入的值时，满足条件日期字段：字段的日期在输入日期之前时，满足条件起止时间字段：字段时间段的结束日期在输入日期之前时，满足条件 |
| 小于等于 | 数字字段日期字段起止时间字段 | 数字字段：字段的值小于等于输入的值时，满足条件日期字段：字段的日期是输入日期当天或之前时，满足条件起止时间字段：字段时间段的结束日期是输入日期之前或当天时，满足条件 |
| 等于任意一个 | 文本类字段数字字段 | 可以添加多个筛选值文本类字段：当字段的内容与其中一个筛选值相等时，满足条件数字字段：当字段的内容与其中一个筛选值相等时，满足条件 |
| 不等于任意一个 | 文本类字段数字字段 | 可以添加多个筛选值文本类字段：当字段的内容与每一个筛选值都不相等时，满足条件数字字段：当字段的内容与每一个筛选值都不相等时，满足条件 |
| 为空值 | 所有字段 | 字段内容为空时，满足条件 |
| 不为空值 | 所有字段 | 字段内容不为空时，满足条件 |
| 动态范围 | 日期字段 | 选择一个时间段，当字段的日期在该时间段内时，满足条件支持可选内容：今日、昨日、本周、上周、本月、上月、今年、去年、近7天、近30天、近90天 |
| 从属 | 成员字段 | 可以按照部门和角色筛选人员，当字段中的人员属于所选择的部门或者角色时，满足条件 |
| 不从属 | 成员字段 | 可以按照部门和角色筛选人员，当字段中的人员不属于所选择的部门或者角色时，满足条件 |
| 小于，小于 | 数字字段 | 设置一个选值范围A&lt;目标数据 |
