调用本接口，直连mysql，sqlserver，oracle类型数据库

### 权限说明

调用本接口前，确保您购买过（或已经申请试用）我们的数据库接口。

否则请联系轻流技术支持。

### 请求

请求方式：post

#### 数据库操接口地址

接口请求路径：[https://connect.oalite.com/api/database/XXXXX](https://connect.oalite.com/api/database/XXXXX)

（XXXXX为数据库类型，可填写mysql / sqlserver / oracle，请依据数据库类型选择相应地址）

示例：

```json
POST https://connect.oalite.com/api/database/mysql
```

**请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证 |

### **请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| url | 是 | \[array\] | 数据库地址 |
| port | 是 | string | 端口号 |
| dbName | 是 | string | 数据库名称 |
| username | 是 | string | 用户名 |
| password | 是 | \[array\] | 密码 |
| sqlType | 是 | \[array\] | sql类型 只支持：select/update/insert |
| sql | 是 | \[array\] | sql语句 |

请求示例：

```latex
{
    "url":"111.22.33.444",
    "port":"1234",
    "dbName":"xxxx",
    "username":"xxxx",
    "password":"xxxxxx",
    "sqlType":"select",
    "sql":"select * from staff_data"
}
```

### 返回

#### 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| code | 是 | int | 错误码，非0表示失败 |
| data | 是 | \[array\] | 数据内容 |
