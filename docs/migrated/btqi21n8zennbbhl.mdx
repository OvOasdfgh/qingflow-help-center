增加超级管理员

---

## **权限说明**仅专有轻流支持

仅专有轻流支持；

仅「超管accessToken」拥有调用权限。（权限组accessToken无法调用）

## 请求

**请求方式：**POST

**请求地址：**[https://自有域名/openApi/manager/super](https://xn--eqrt2gz0rng0a/openApi/manager/super)

```javascript
POST https://xxx.qingflow.com/openApi/manager/super
```

#### **2.1 参数说明(路径参数)：**

无

#### **2.2 参数说明(查询参数)：**

无

#### **2.3 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

#### **2.4 请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| managerUserIds | 是 | \[array\] | 设置成管理员的userId列表 |

#### **2.5 请求体示例**

```json
{
		"managerUserIds": [
		    "283360",
		    "833342"
        ]
}
```

## 返回

#### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| result | 是 | object | 返回结果 |
| resultAmount | 是 | int | 返回结果的数量 |

#### 3.2 返回体示例

```json
{
	"errCode": 0,
	"errMsg": "ok",
	"result": {
		  "resultAmount": 10,
		  "resultFormat": "json"
		}
}
```
