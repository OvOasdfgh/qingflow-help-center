## 1.无代码

### 1.1 【安全】附件/公开链接功能使用确认

管理后台新增「允许使用公开链接」选项与「允许使用「附件上传」字段」选项，提高使用安全性

可用版本：免费版，全平台

[管理后台](https://help.qingflow.com/help-docs?type=nocode&docId=3276840c643cbc4e0004590f715b87a5&parentId=null)

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-12/MyBtDK3ro9ebZx1zT_xtAs0HWc1Zwsa-_.png)

### 1.2 首页左侧栏固定的应用包取消上限限制

功能简介：专有轻流取消了菜单项创建的数量限制

可用版本：专有轻流，全平台

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-12/tqn4yWx8Q-ONYZhFdx0c9d-NUYChQO9D_.png)

### 1.3 流程外Q-Robot支持表格子字段更新时触发

功能简介：Q-Robot（高级版）支持在表格子字段更新时触发

可用版本：团队版及以上版本，全平台

[流程外Q-Robot（高级版）](https://help.qingflow.com/help-docs?type=nocode&docId=7e2dc5fb642000300006509930afd1dd&parentId=null)

### 1.4 优化海外客户（AWS部署）在邮件和短信服务方面的体验

功能简介：支持专有轻流客户用SMTP服务发送流程内Q-Robot邮件

可用版本：专有轻流，全平台

### 1.5 【按钮】数据详情按钮支持根据条件显示/隐藏

功能简介：可以设置位于数据详情页的「主按钮」与「更多按钮」，便于对数据详情页进行自定义操作

可用版本：全版本，全平台

[视图](https://help.qingflow.com/help-docs?type=nocode&docId=734898c06458ae420000213855efc4f1&parentId=null)

### 1.6 【子管理员】拓展插件权限

子管理员增加了轻商城权限中的「拓展插件」权限，提升子管理员权限范围

可用版本：团队版及以上版本，全平台

[子管理员](https://help.qingflow.com/help-docs?type=nocode&docId=c793fce96426a9bb0011a9060e5d1ac5&parentId=null)
