## 场景/问题描述

当进行商品出库的时候，在表格中关联出当前库存时，在下一行录入相同数据时，库存数量并不会进行实时更新，导致无法用表格进行录入。

## 思路逻辑

通过代码块来进行实现表格出库，对于当前库存的实时计算。使得录入新行时，直接显示最新的库存数量

    const key = item.field_160008422;
