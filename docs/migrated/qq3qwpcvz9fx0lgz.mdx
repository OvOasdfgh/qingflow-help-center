### 1.聚合函数

聚合函数用于对数据进行分组后汇总计算。此处的“分组”依据由图表中所设置的**维度字段**决定，即图表中作为分组依据的维度字段会自动应用到聚合函数中，无需在函数内部指定。

#### **SUM\_AGG(数字1)**

**说明：** 对分组后的数据求和。
**示例：SUM\_AGG(金额）**→ 汇总每个维度组合内的销售金额总和。如下图所示，报表的维度为客户名称，SUM\_AGG(金额)会自动按照客户姓名对所有数据分组，并计算组内销售金额的总和。
![image.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1754286407250-7e9c6af4-d52a-48c3-84e4-bdb97b32db5f.png)

#### **AVG\_AGG(数字1)**

**说明：** 根据报表的维度进行分组，汇总一组内数据求平均值。

**示例：** AVG\_AGG(销售数量)，求每一组销售数量的平均值。

#### **MAX\_AGG(数字1）**

**说明：** 根据报表的维度进行分组，汇总一组内数据求最大值。

**示例：** MAX\_AGG(销售数量)，求每一组销售数量的最大值。

#### **MIN\_AGG(数字1)**

**说明：** 根据报表的维度进行分组，汇总一组内数据求最小值。

**示例：** MIN\_AGG(销售数量)，求每一组销售数量的最小值。

#### **COUNT\_AGG(X)**

**说明：** 根据报表的维度字段进行分组，对分组后所有有效数据的条数进行计算，空值不进行计算。

**示例：** COUNT\_AGG(商品名称)，对每一组的商品名称进行计数。

#### **COUNTDISTINCT\_AGG(X)**

**说明：** 根据报表的维度进行分组，对分组后所有有效的不同数据的条数进行计算，空值不进行计算。

**示例：** COUNTDISTINCT\_AGG(商品名称)，对每一组内不相同的商品名称进行计数。

#### **COUNTIF\_AGG（表达式）**

**说明：** 根据报表的维度进行分组，对分组后所有满足条件的条数进行计算，空值不参与计算。

**示例：** COUNTIF\_AGG（销售数量>5000)，对每一组中销售数量大于5000的计算条数。

#### 1.1注意：

1.公式的「数字1」为必填项，没有填写，则会触发错误提示；例如：SUM\_AGG()
2. 填入参数非数字，则会触发错误提示；例如：SUM\_AGG(商品名称)
3. 参数上限1个，配置2个或以上的字段，会触发错误提示；例如：SUM\_AGG(销售数量，本次发货数量)
4. 函数表达式运算符有且仅允许正确【+-\*/()】，否则会触发错误提示；
5. 聚合函数和非聚合函数共同使用时，会触发错误提示；例如：

```plain
SUM_AGG(销售数量)+SUM(本次发货数量)
```

### 2.其他函数

#### **NUM(文本)**

**说明：** 将「文本」转化为数字格式。

**示例：** NUM("123456")，返回数字“123456”。

#### 2.1注意：

1.公式的「文本」必填，没有填写，则会触发错误提示；
2. 字段类型为文本类型，如果不能正确函数表达式，则会触发错误提示；
3. 配置2个或以上的参数，会触发错误提示；
4. 聚合函数和非聚合函数共同使用时，会触发错误提示；
