### 介绍

极速数据平台为企业、个人开发者提供各类生活数据API。

### 鉴权信息

**操作步骤：**

1、**获取appkey;**

点击头像，进入会员管理中心，查看/更换appkey；

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/e7-M4I7dk6j6hXwinOh_5L4AIYa0Vno5_.png)

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/3t_98uRWJZmYOSDs261Szqp96OVl3W--_.png)

2、**进入轻商城-连接中心，选择连接器“极速数据”，点击“配置”进入并填写你的专属appkey完成配置。**

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/vZl6FlVR9BOCN8LFV0h0GplgUlRtfZ5E_.png)

### 事件信息

| 事件 | 描述 |
| --- | --- |
| 智能问答 | 智能问答机器人，上知天文，下知地理。 |
| 手机号码归属地 | 全国移动、联通、电信等手机号码归属地查询，数据量有数百万，更新及时、准确度高。 |
| IP查询 | 提供全国数百万IP的归属地、运营商类型查询，定期更新。 |
| 手机号码归属地 | 全国移动、联通、电信等手机号码归属地查询，数据量有数百万，更新及时、准确度高。 |
| 区号查询 | 提供全国30多个省市的区号查询，国际区号查询等。 |

### 配置演示

#### 事件案例：手机号码归属地查询

**配置步骤：**

1、创建一个应用，并按照连接中心的参数要求添加表单字段；（变量为需要手动输入的内容，别名对应所有你想要获取的信息）

2、插入Q-Linker字段并将其配置模式改为「使用连接中心模版」，具体配置如图，完成后点击保存；
