认证方式有两种：简单身份认证/签名认证，详细介绍如下：

5、配置JSON Path：

- **Result Format**: JSON
- **Json Path: **

- $.msg
- $.name
- $.idCard

注意：别名是将用于数据关联对JSON Path对应数据的调取,不可重复
