调用本接口，更新部门信息

---

### **权限说明**

仅支持专有轻流。

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有通讯录权限。

### 请求

**请求方式：**POST

**请求地址：**http(s)://xxx.xx(自有域名)/openApi/department/:deptId

> 请求地址中:deptId为需要替换的变量，根据实际获取值更新，示例如下：

```javascript
POST https://ncbd.qingflow.com/openApi/department/123456
```

#### **参数说明(路径参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| deptId | 是 | 部门id，可通过文档接口获取 |

#### **参数说明(查询参数)：**

#### **请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

#### **请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| deptId | 是 | int | 部门id，不可更改 |
| name | 是 | string | 部门名称 |
| parentId |  | int | 父部门id |
| deptLeader |  | array | 部门主管的userId |
| ordinal |  | int | 同级部门（同个父部门）中的顺序值，取值范围为0-2^30 |

#### **请求体示例**

```json
{
    "deptId":123456,
    "name":"产品2部",
    "parentId":2263,
    "deptLeader":["9054"]
}
```

### 返回

#### 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations |  |  | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| deptId | 是 | int | 部门id |

#### 返回体示例

```json
{
    "errCode": 0,
    "errMsg": null,
    "questionRelations": [],
    "result": {
        "deptId": 123456
    }
}
```

### 注意事项

- 平台型轻流（企微、飞书、钉钉版本）的同步部门不支持更新
