## 无代码

### 1.1 【表单】**定位字段支持范围限制和导航唤起**

本次更新针对考勤打卡和签到业务，新增定位字段自定义功能，支持自定义打卡定位中心点、限制打卡范围及地图搜索，移动端定位地址可点击跳转至手机三方导航，提升用户体验与业务管理效率。

#### 1.1.1 功能入口

创建应用后，进入表单编辑，点击「定位字段」即可。

![image.png](https://cdn.nlark.com/yuque/0/2025/png/2056184/1736843153010-1137e832-a219-465e-a19c-eea929510af3.png)

手机端打开表单默认自动获取位置，请求定位并将信息填充至定位字段；若取消自动获取，需手动点击获取定位信息。

#### 1.1.2 限制定位范围

![image.png](https://cdn.nlark.com/yuque/0/2025/png/2056184/1736843355854-82277ce3-2d74-448d-9b52-ffb317b86a0c.png)

限制定位范围功能默认不勾选，点击“编辑定位范围”可弹出设置页面，如下图所示。

定位中心上限为20个，超限会提示“定位中心已达上限，无法新增”；定位范围必填。

因部分浏览器限制，自动定位精度可能仅到当前城市，但“精准搜索定位”不受影响。

![image.png](https://cdn.nlark.com/yuque/0/2025/png/2056184/1736843487221-a3ced9e2-aeed-4682-ad4d-0f0d46da7e2c.png)

#### 1.1.3 显示经纬度坐标

默认不勾选,勾选后在移动端显示定位的经纬度坐标信息。

![image.png](https://cdn.nlark.com/yuque/0/2025/png/2056184/1736843703268-bc84812e-9409-4d02-a933-13abf9e7301f.png)

#### 1.1.4 移动端定位支持搜索

用户选择定位时，支持模糊搜索，在匹配的下拉列表中选择具体的定位信息。

![image.png](https://cdn.nlark.com/yuque/0/2025/png/2056184/1736846747954-1a040c39-b57f-48d6-9f82-a89d78e803ac.png) ![image.png](https://cdn.nlark.com/yuque/0/2025/png/2056184/1736847063155-969e0123-ce5b-44d7-80f9-1ab1275d28e7.png)

### 1.2【视图】视图支持复制

视图复制功能支持用户通过复制现有视图，迅速生成与原视图配置相同的新视图，大幅减少重复配置时间，有效提升了搭建者及用户配置视图效率。

#### 1.2.1 功能入口

点击视图下拉按钮，在弹出的菜单栏中点击「复制视图」按钮。
![image.png](https://cdn.nlark.com/yuque/0/2025/png/2056184/1736836096990-63948548-03f1-4db1-b715-f3da0ccc48de.png)

系统会自动创建一个名为“副本-”+原视图名称的新视图，并自动跳转至其编辑页面，以便用户进行后续配置。

![image.png](https://cdn.nlark.com/yuque/0/2025/png/2056184/1736836112604-6c9ad3f4-8772-45f9-a784-9733fed67d43.png)

配置完成后效果如下：

![image.png](https://cdn.nlark.com/yuque/0/2025/png/2056184/1736836138518-747cb5b2-9c41-4e1b-9bb6-6eb01b3eff15.png)

### 1.4 工作区清理

本次更新聚焦公有云工作区清理，专为降低资源消耗、优化体验。针对公有云的免费及试用客户，若其工作区超3个月无访问登录，系统将于当天00:00自动封存，数据保留。您可购买服务自动解封，或管理员角色登录轻流提交恢复申请。

#### 1.4.1 回收范围

| **环境类型** | **仅面向公有云** |  |  |
| --- | --- | --- | --- |
| **客户类型** | 免费客户 | 超过3个月无任何访问登录行为 | ✔️回收 |
| 试用客户 |  |  |  |
| **回收处理方式** | 对符合上述条件的工作区统一进行【封存】处理，数据保留，可申请启用 |  |  |
| **申请启用** | 购买后自动解除【封存】状态客户（管理员）登录轻流提交【恢复申请】 |  |  |
