## 无代码

### 1.1【表单】富文本字段功能扩展

为进一步覆盖复杂业务场景，满足用户对富文本字段的格式要求。对富文本组件功能进行了优化，优化范围如下

1.支持使用自定义字体包

![文档图片](https://cdn.nlark.com/yuque/0/2024/png/43099917/1718257166285-80696842-ec90-4311-ba6e-5329273bb87b.png)

支持在客户部署时引入字体库，作为富文本字段的字体来源

注：跨环境进行应用的导入导出时。若工作区无该字体包，则更改为默认字体。

2.支持选择字号

![文档图片](https://cdn.nlark.com/yuque/0/2024/png/43099917/1718257166206-50c22579-4a07-435d-9755-e1c49570cb31.png)

3.支持选择行距

![文档图片](https://cdn.nlark.com/yuque/0/2024/png/43099917/1718257166171-6f9c5055-a9a9-49fb-a723-3c02d52b54e2.png)
