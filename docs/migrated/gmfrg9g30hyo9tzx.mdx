安全性比较高的网站都不允许嵌入，只能根据实际情况操作，让客户以实际表现为准，限制不确定性。因为链接组件的本质是个iframe，有些网站限制了iframe的嵌套，我们无法控制，也无法知道哪些网站有限制。

- 可以F12进行查看具体报错信息，例如有该报错就是加了限制：Refused to display 'https://www.jd.com/' in a frame because it set 'X-Frame-Options' to 'sameorigin'。sameorigin的意思就是需要访问来源和域名一致，现在是在qingflow.com里访问的京东，肯定不是sameorigin，所以被拒绝了。
- 链接组件仅支持https,不支持http
