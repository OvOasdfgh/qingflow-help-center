## 1.预期上线时间

为方便用户获取和查看轻流系统中指定应用的数据，轻流计划对**OPEN API 分页参数限制变更**进行变更。以下内容**公有云、企业微信版本**将在12月21日（钉钉版本于12月27日）上线，**专有轻流**预计将在6.0.0版本上线。

## 2.变更事项

### 2.1 OPEN API分页接口参数限制

#### 更新前

轻流所有OPEN API分页接口中，pageSize参数传值无限制。

#### 更新后

轻流所有OPEN API分页接口中，pageSize参数上限为200，如传值大于200，则按200每页返回数据。

### 2.2 获取应用数据接口分页返回逻辑变更

本内容曾在11.29日发过公告，上线后因其他原因回滚重发。

#### 更新前

「获取应用数据接口」中pageNum参数传入超大值，也仍然返回最后一页的数据。

#### 更新后

pageNum参数传入超大值时，result数组中为空。
