## 功能简介

在数据列表中，根据实际场景选择视图查看形式，轻流暂时支持「精简视图」和「详细视图」两种模式。

## 功能入口

【待办事项 / 已办事项 / 抄送事项 / 我发起的 / 全部数据】列表——【精简视图/详细视图】
![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-07/vIgh0BMoqQSUocgYhGICAjRxJzAgYXvb_.png)

## 视图切换选择

### 3.1 精简视图

在「精简视图」模式下，在数据列表中隐藏表格子字段的内容

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-07/vcbD4bAOTROiBiWdHNBCEDKl-T3By9lJ_.png)

### 3.2 详细视图

在「详细视图」模式下，在数据列表中展开显示表格子字段的内容

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-07/94AbIVdPzsP23C-K_cNgqQYsGprGEjSr_.png)
