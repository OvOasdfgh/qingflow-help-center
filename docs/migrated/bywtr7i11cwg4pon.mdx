![SDR配图.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694682371028-4f700032-6762-40a0-8420-0579641f6c55.png)

## 1.方案介绍

### 1.1.方案简介

轻流设备巡检，覆盖设备巡检业务流程中设备档案、点检巡检、设备维修、设备保养、备件追踪等板块。

支持一物一码，一台手机就能查看设备档案，发起巡检、保养、报修，全流程覆盖，随时监控；高效点检巡检，自定义提醒功能，确保工作有效执行，不被遗忘。

适用于生产车间、建筑施工、石油化工、物业门店等设备巡检场景。

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1695015956616-cb2c5a74-407f-40f3-8d53-db83a8a52e75.png)

### 1.2.业务痛点&解决方案

| **业务痛点** | **解决方案** |
| --- | --- |
| **维修效率低**传统电话报修和纸质工单，维修过程难监督；设备档案信息不同步，维保人员无法提前做好维修准备工作。 | **规范化**规范巡检、保养计划，日历化巡检、保养任务，自动提醒负责人，规避假巡检、重检漏检；自定义维修流程，工单及时流转，响应时间减少；工单记录备件入库与领用数量，追踪备件去向。**无纸化**一个设备一个二维码，移动端扫码识别，实时查看设备档案，快速发起巡检、保养、报修。**可视化数据分析**基于轻析自助式报表开发能力，帮助管理层实时了解整体维保情况；人员考核、决策分析与管理优化，均有据可依。 |
| **巡检不规范**巡检工作量大，重检漏检；巡检结果无法实时共享和查询。 |  |
| **保养不及时**保养计划庞大，实施困难；设备实际产量不乐观。 |  |
| **管理难考核**工单记录杂乱，流程不规范，考核无数据依据；维保人员积极性不高。 |  |

## 2.使用说明

### 2.1.基础数据维护

在正式投入使用前，管理员需要通过[批量导入](https://help.qingflow.com/help-docs?type=nocode&docId=9df4ce03642154190000e3190ba4f126&parentId=)或单个新增，维护好基础数据，便于后续使用过程中数据的关联获取（模板中已提供部分示例数据，管理员可根据实际情况重新维护）

基础数据包括：供应商信息、仓库信息、设备类型、设备状态、时间计划、故障原因、故障类别

### 2.3.设备巡检

#### 2.3.1.巡检方案

巡检人员可在「个人数据看板」中点击「巡检方案」，或在「设备巡检方案」中点击「发起新的」，新增设备巡检方案，选择设备类型与巡检频次，并在巡检明细中录入巡检项目与检查方法

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694586591153-f9af00de-7834-45f4-83bc-9708d64c6d96.png)

#### 2.3.2.发起巡检

##### 1)扫码发起

巡检人员可扫描设备标识牌上的二维码，查看设备档案并发起巡检

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694577202443-c4fc3884-c788-40c5-b32b-cb013c97e511.png)![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694575996568-3c594452-7a45-44e2-bd4f-2f8a82ae2b0b.png)

##### 2)待检日历

巡检人员可在移动端进入「个人数据看板」>>「今日待检日历」，打开待检设备数据，查看设备档案并发起巡检

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694576895243-9e70e831-e9b1-4372-ac46-74e5fa091aa9.png)![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694576947731-3aa8f076-d628-4f7d-b8b7-3efd05ada75e.png)![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694577036365-a3083b0f-bdba-4026-a257-7bf93368d79e.png)

##### 3)直接发起

巡检人员可在移动端进入「个人数据看板」>>「操作入口」，点击「设备巡检单」直接发起

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694577410457-be4f6b4a-02c2-4745-9343-02cb3368b3a3.png)

#### 2.3.3.填写巡检记录

巡检人员发起巡检后确认设备信息，确认无误后定位获取当前位置并拍照上传巡检图片，根据巡检方案填写巡检项目是否正常，填写最终巡检结果与设备状态，当巡检结果为异常时，巡检人员拍照上传故障图片并填写故障描述，最后确认下次巡检人员与时间

巡检单提交后，将自动更新设备档案中的设备状态与下次巡检计划

![填写巡检.gif](https://cdn.nlark.com/yuque/0/2023/gif/21388903/1694577777542-5922f541-91af-47ec-875d-675ece24f188.gif)

#### 2.3.4.巡检提醒

根据巡检计划定时向巡检人员推送巡检提醒

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694585433465-2335f2d3-5732-4f9f-9a23-92763613d2fa.png)

### 2.4.设备报修与维修

#### 2.4.1.发起报修

##### 1)自动报修

当巡检结果为异常时，将自动生成报修单

##### 2)扫码报修

巡检/保养人员可扫描设备标识牌上的二维码，查看设备档案后发起报修，填写故障情况

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694577202443-c4fc3884-c788-40c5-b32b-cb013c97e511.png)![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694584135164-cb232709-e79b-4fc9-a6dc-c8a9a63879e7.png)

##### 3)直接报修

巡检/保养人员可在移动端进入「个人数据看板」>>「操作入口」，点击「设备保养单」直接发起，选择报修设备并填写故障情况

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694584261526-bf58d46c-07de-4b45-b683-46a3b3d38ab3.png)![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694584530092-630571f8-4ab5-4bdb-84fa-0122c566b6a3.png)

报修后将自动更新设备档案中的设备状态

#### 2.4.2.维修任务派工

报修后工单自动流转至派工人员，收到待办提醒后填写故障等级和故障类别，并选择维修负责人

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694584920543-30bc60d3-2813-4b69-9437-c40d992a519e.png)![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694587832868-7a5efeea-9d82-44bc-8b82-d5e619cc017f.png)

#### 2.4.3.维修任务处理

派工后工单流转至维修负责人，收到维修待办后进行维修，填写维修结果、故障原因、维修情况说明

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694587726011-ecf443e0-0567-4748-8172-a76bf3db151b.png)![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694587930299-305768b3-8a70-44eb-bd27-67c409de841d.png)

#### 2.4.4.维修结果确认

报修人员在维修完成后收到验收待办提醒，对维修结果进行确认，如确认仍存在异常，可直接将流程驳回至“维修任务处理”，再次进行维修，如确认设备正常或无法修复，填写设备状态后提交验收结果

验收通过后将自动更新设备档案中的设备状态

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694588453974-4187df55-f3b7-4fb4-852c-83a9dbbb4d76.png)![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694588495799-ce8dd6ea-cbd3-4591-8ec9-2e86818f4947.png)

### 2.5.设备保养

#### 2.5.1.保养方案

保养人员可在「个人数据看板」中点击「保养方案」，或在「设备保养方案」中点击「发起新的」，新增设备保养方案，选择设备类型、保养等级与保养频次，并在保养明细中录入保养内容与要求

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694588672897-041d1c2d-16a1-4d3c-aa96-1676b2ae0d85.png)

#### 2.5.2.发起保养

##### 1)扫码发起

保养人员可扫描设备标识牌上的二维码，查看设备档案并发起保养

##### 2)待保养日历

保养人员可在移动端进入「个人数据看板」>>「今日待保养日历」，打开待保养设备数据，查看设备档案并发起保养

##### 3)直接发起

保养人员可在移动端进入「个人数据看板」>>「操作入口」，点击「设备保养单」直接发起

#### 2.5.3.填写保养记录

保养人员发起保养后确认设备信息，确认无误后定位获取当前位置并拍照上传保养图片，根据保养方案依次勾选是否完成，并确认下次保养人员与时间

保养单提交后，将自动更新设备档案中的近期保养情况与下次巡检计划

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694589118533-d99a3d82-af16-44e4-970c-a2680d7d4681.png)

#### 2.5.4.保养提醒

根据保养计划定时向保养人员推送保养提醒

### 2.6.备件管理

#### 2.6.1.备件信息维护

库存管理员可在「备件信息库」中[批量导入](https://help.qingflow.com/help-docs?type=nocode&docId=9df4ce03642154190000e3190ba4f126&parentId=)或单个新增备件信息

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1694589410787-4150ae26-5bde-4571-aa60-1b5bc908a66b.png)

#### 2.6.2.备件领用

保养/维修人员扫描设备标识牌上的二维码，确认设备信息后点击「更换备件」，填写领用目的、领用备件与领用数量
