删除子管理员

---

### **权限说明**

仅支持专有轻流；

仅「超管accessToken」拥有调用权限。（权限组accessToken无法调用）

### 请求

**请求方式：**DELETE

**请求地址：**[https://自有域名/openApi/manager/sub](https://xn--eqrt2gz0rng0a/openApi/manager/sub)

#### **2.1 参数说明(路径参数)：**

无

#### **2.2 参数说明(查询参数)：**

无

#### **2.3 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

#### **2.4 请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| subManagerIds | 是 | array | subManagerId集合 |

#### **2.5 请求体示例**

```json
{
    "subManagerIds":[]
}
```

### 返回

#### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| result | 是 | object |  |
| subManagerIds | 是 | array | 删除的子管理员id集 |

#### 3.2 返回体示例

```json
{
    "errCode": 0,
    "errMsg": null,
    "questionRelations": [],
    "result": {
        "subManagerIds": []
    }
}
```
