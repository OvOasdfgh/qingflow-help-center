## 一、简介

### 1.1 功能简介

统计报表支持将数据以**可视化图表**的方式展示，帮助用户直观**分析业务数据**，提升**数据理解和决策效率**。

### 1.2 使用场景

适用于所有需要数据处理、数据分析、数据展示的场景，如销售分析、客户管理、运营监控、财务报表等。

### 1.3 效果展示

如下图所示，以 **饼图** 的形式展示了各个渠道获取客户的占比情况，便于直观了解不同渠道的贡献比例。

### 1.4 名词解释

| **名词** | **功能简介** | **适用图表** |
| --- | --- | --- |
| 数据源 | 数据源即数据可视化的数据来源，支持使用轻流表单或者数据集作为报表的数据源 | 所有图表 |
| 维度 | 维度是指分析数据时所依据的分类角度或观察视角。例如你想知道各个城市的销售情况，“城市”就是分析维度。 | 所有图表 |
| 指标 | 指标是维度下数据的具体量化结果，通常是数值型的，是用来衡量、比较、分析的关键数据。例如，在按照“城市”这个维度分析的前提下，“销售额”就是指标，它能反映每个城市的销售表现。 | 所有图表 |
| 数据筛选 | 通过特定的条件来筛选数据，从而在图表中只显示满足条件的数据。 | 所有图表 |
| 数据显示 | 设置仅显示图表的前 N 条数据。 | 除「地图」以外的所有图表类型 |
| 条件格式 | 可通过自定义条件对数据进行筛选，并为符合条件的数据设置颜色显示。可以更加直观地突出重点数据，提升图表的可读性与分析效率。 | 汇总表明细表指标卡 |
| 汇总行/列 | 可新增汇总行或汇总列，对每行或每列的数据以求和、平均值、最大值或最小值的形式进行自动聚合计算，有助于对比、总结和决策分析 | 汇总表 |
| 辅助线 | 支持根据不同的计算规则（如平均值、最大值、固定数值等）生成辅助线，用于对图表中的数据进行参照或对比分析，帮助用户快速识别数据趋势和关键节点。 | 条形图柱状图折线图散点图组合图 |
| 数据导出 | 报表支持将当前可视化展示的数据导出为 Excel 文件，方便线下查看、存档或进一步分析处理。 | 汇总表明细表 |
| 查看原始数据 | 支持查看生成图表所基于的「原始数据明细」，帮助用户快速定位数据来源和分析过程，提升数据透明度和可追溯性。 | 除「明细表」以外的所有图表类型 |
| 地图显示范围 | 地图显示范围支持全国、省级、市级展示。 | 地图 |
| 地图钻取 | 通过点击地图中存在数据的子区域，可自动以该区域为地图轮廓，向下钻取至更细一级的地理单位（如从省→市，再到区县），便于逐层分析数据。 | 地图 |

## 二、功能设置步骤

### 2.1 新建报表入口

方式一：进入轻析的「统计报表」界面，点击「新建报表」按钮

![演示文稿3\_01.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1753082863000-5389f0be-8294-4eaa-beb4-1f09c458899e.png)

方式二：在数据集界面，找到目标数据集卡片，进入卡片右上角的「更多」按钮，点击「分析」即可直接新建报表。在此入口新建的报表无需选择数据源，默认以当前数据集为报表的数据来源

![演示文稿3\_02.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1753082878268-4fec01e0-c30a-4a38-a10f-dceba8a5ea8d.png)

方式三：进入「应用」界面，点击右上角的「报表」按钮，选择「创建报表」。在此入口新建的报表无需选择数据源，默认以当前应用的数据为报表的数据来源

![演示文稿3\_03.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1753082940792-17ed6893-f65d-49d1-be60-55734a43515f.png)

### 2.2 报表搭建步骤

#### 2.2.1 报表属性

点击新建报表后，在弹窗中可设置报表的报表的属性，包括报表的名称、数据源和可见范围

![截屏2025-07-21 15.30.29.png](https://cdn.nlark.com/yuque/0/2025/png/43099917/1753083074291-9a76e5ea-6965-4010-931f-9ed99cf30eb5.png)

##### 填写报表名称

在新建报表的弹窗中为报表命名，可以区分不同报表，方便报表的查找和定位

##### 选择数据源

新建统计报表时选择的数据源是指数据可视化分析的数据来源，支持选择轻流的应用或者轻析数据集作为数据源。

> 如果希望将 轻析数据源中添加的 Excel 表格或数据库表 作为数据分析的来源，需要先将其 转化为数据集的形式。在数据集编辑画布中将数据源直接与输出节点相连，可在不改变数据源的前提下将其生成为数据集。

##### 设置可见范围

设置哪些成员能够查看该报表，可以选择部分可见或所有人可见两个选项。

- 部分可见

- 成员可见

- 全部成员可见：该工作区全部成员可见
- 指定成员可见：点击下方加号可选择工作区内具体的成员、部门或角色可见

- 外部用户可见

- 全部用户可见：该工作区所有的外部用户可见
- 指定用户可见：点击下方加号可选择具体的外部用户或外部组织可见

- 所有人可见：所有获得报表链接的人都能看到报表

#### 2.2.2 报表搭建

点击新建报表，填写弹窗中的基础属性，点击完成，即可进入报表搭建的页面。

##### 选择报表类型

新建报表后，可以在报表编辑界面的右上角选择需要的图表类型。不同的不同的图表类型适用于不同类型的数据和分析目的。

> 图表类型说明：

![文档图片](https://cdn.nlark.com/yuque/0/2025/gif/43099917/1753069248005-7db6d02b-f860-4ef7-ab64-2dcb8a8ee8d5.gif)

##### 选择分析维度和指标

- 维度：维度是指分析数据时所依据的分类角度或观察视角。
- 指标：指标是维度下数据的具体量化结果，通常是数值型的，是用来衡量、比较、分析的关键数据。

通过拖拽的方式，将 **维度字段** 或 **指标字段** 拖拽至图表的对应区域，即可完成数据分析。

如图所示，选择图表类型为 **柱状图**，将「地址」字段拖入**维度区域**，将「销售总金额」字段拖入**指标区域**，
即可生成一个 **展示不同地址销售额对比** 的柱状图。

![选择维度和指标.gif](https://cdn.nlark.com/yuque/0/2025/gif/43099917/1753086307740-08e33b4f-8f35-49a1-984f-4cfa6ca7cc09.gif)

##### 维度和指标设置

可对图表的维度和指标进行如下设置

| 维度/指标 | 功能 |
| --- | --- |
| 维度 | 显示名称；排列方式；日期格式（日期字段）；汇总方式（地址字段） |
| 指标 | 显示名称；排列方式；显示格式；汇总方式 |
