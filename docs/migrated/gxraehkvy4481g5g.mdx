### **权限说明**

仅支持专有轻流；

仅「超管accessToken」可以调用。

### 请求

**请求方式：**GET

**请求地址：**[https://xxx.xxxxx.com/openApi/delegate](https://xxx.xxxxx.com/openApi/delegate)

##### **2.1 参数说明(路径参数)：**

无

##### **2.2 参数说明(查询参数)：**

| 参数 | 类型 | 必须 | 说明 |
| --- | --- | --- | --- |
| pageNum | int | 是 | 页码 |
| pageSize | int | 是 | 每页数量 |
| type | int | 是 | 委托类型；1:委托任务，2:受委托任务 |
| userId | string | 是 | 用户id |

##### **2.3 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

##### **2.4 请求体（Body）**

无

##### **2.5 请求体示例**

无
