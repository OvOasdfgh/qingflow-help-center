## 2. 方案介绍

### 2.1. 方案简介

轻流进销存管理解决方案，多方面覆盖批发零售行业业务流程中销售管理、产品管理、采购管理、库存管理、客户管理等八大板块，无需IT人员支持，即可自由定义工作全流程，易上手、可落地。

能够实时查看当前产品库存，自动生成各供应商、客户的应收应付报表，分摊产品相关的仓储费、运费等杂项费用，还可以随时随地查看各产品的利润产出。

![image.png](https://cdn.nlark.com/yuque/0/2022/png/21388903/1670296379891-6e90d6b2-3120-4677-93af-8ddd49aa551d.png)

### 2.2. 行业痛点及解决方案

| **痛点** | **解决方案** |
| --- | --- |
| **采购不合理**客户需求和现有库存信息不连通，盲目采购，不是积压库存就是库存不足，无法做到合理采购 | **可视化数据分析**基于轻流多类型多维度报表能力，实时监控业务动态，库存管理更及时**财务成本控制**追本溯源，详尽记录在线订单，自动生成供应商或客户的应收应付报表，分摊产品相关的杂项费用，如仓储费、运费等，实时查看各产品的利润支出**移动端协作**通过电脑端、手机端，轻松解决多终端业务管理需求，随时随地进行业务处理，实时查看相关数据，轻松移动办公**灵活自定义**覆盖各类场景，满足个性需求，支持订单/打印模板/流程自定义 |
| **进货不及时**低库存时无预警，无法及时补货，导致库存不足工作无法正常开展 |  |
| **系统陈旧**面对日益增长的业务需求，原有系统支撑乏力，只能解决部分业务问题，且无法在手机端使用，不能有效实现移动办公 |  |
| **信息孤岛**销售、仓储、财务等业务板块数据手动统计效率低，且无法实时打通，管理人员无法及时看到业务全貌 |  |

### 2.5. 名词解释

| **名词** | **解释** |
| --- | --- |
| 进销存 | 进销存是指企业管理过程中采购(进)->入库(存)->销售(销)的动态管理过程 |
| 移动加权平均法 | 企业按实际成本进行材料明细分类核算时，以各批材料收入数量和上批结余材料数量为权数，计算材料平均单位成本的一种方法。采用这种计价方法，每购进一批材料需重新计算一次加权平均单价，据以作为领用材料的单位成本。通过移动加权平均法计算出来的产品成本比较均衡和准确 |
| 库存调拨 | 不同仓库之间的货物相互调配，解决高库存或低库存的问题 |
| 库存盘点 | 为了精确的计算当月和当年的营运状况，以月/年为周期清点公司内的货物，以便对仓储货品的收发结存等活动进行有效控制，保证仓储货品完好无损、账实相符，确保业务正常进行，规范公司货物的盘点作业 |
| 库存费用分摊 | 发生采购的过程中，可能会产生一些特殊费用如运费、装卸费等等，需要将以上费用分摊至库存成本中 |
| 其他出库 | 除了销售出库、退货出库、调拨出库等，其他特殊原因产生的出库 |
| 其他入库 | 除了采购入库、退货入库、调拨入库等，其他特殊原因产生的入库 |
