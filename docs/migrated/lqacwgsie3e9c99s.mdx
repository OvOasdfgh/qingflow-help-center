调用该接口，处理单条数据

---

### **权限说明**

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有对应应用的权限。

### 请求

**请求方式：**POST

**请求地址：**https://api.qingflow.com/\{appKey\}/\{applyId\}/audit（公有云版本）

> 请求地址中:applyId为需要替换的变量，根据实际获取值更新，示例如下：

```javascript
POST https://api.qingflow.com/123456/123456/audit
```

**其他版本请求地址：**

钉钉版本：https://api.ding.qingflow.com/\{appKey\}/\{applyId\}/audit

专有轻流：http(s)://xxx.xx(自有域名)/openApi/\{appKey\}/\{applyId\}/audit

#### **参数说明(路径参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| appKey | ​<br /> | 数据的id，获取方式参考：[基本概念介绍](https://exiao.yuque.com/ixwxsb/bgzs0e/cl59vxilcqdkmq1h) |
| applyId | 是 | 数据的id，获取方式参考：[基本概念介绍](https://exiao.yuque.com/ixwxsb/bgzs0e/cl59vxilcqdkmq1h) |

#### **参数说明(查询参数)：**

无

#### **请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |
| userId | 是 | 要处理节点的负责人的外部用户ID，获取方式参考：基本概念介绍 |

#### **请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| auditResult | 是 | string | 处理结果，可能的值为：1 \[int\] 提交处理 2 \[int\] 通过 3 \[int\] 拒绝 5 \[int\] 发起申请/申请人草稿提交 6 \[int\] 申请人完善申请并提交 7 \[int\] 抄送 |
| auditNodeId | 是 | number | 执行处理的处理节点id，可通过调用【获取单条数据的流程日志】接口获取 |
| auditFeedback |  | string | 处理反馈内容 |
| answers |  | array-object | 只有审批通过和拒绝时可以传此参数 |
| queId | 是 | ​<br /> | 字段ID |
| queTitle |  | string | 字段名称 |
| queType | 是 | ​<br /> | 字段类型 |
| values |  | array-object | 字段的值，表格字段以外的字段类型必填 |
| xxx |  | ​<br /> | ​<br /> |
| tableValues |  | array-string | 表格类型字段必填 |

#### **请求体示例**

```json
{
    "auditResult": "1",
    "auditNodeId": "执行处理的处理节点id",
    "auditFeedback": "处理反馈内容",
    "answers": [{
        "queId": "",
        "queTitle": "",
        "queType": "",
        "values": [{
            "xxx": ""
        }],
        "tableValues": [""]
    }]
}
```

### 返回

#### 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| result | 是 | boolean | 返回为true：成功 |

#### 返回体示例

```json
{
	"errCode": 0,
	"errMsg": "ok",
	"result": "ture"
}
```
