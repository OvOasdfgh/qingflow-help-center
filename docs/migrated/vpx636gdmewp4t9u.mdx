调用本接口，获取应用包基本信息

---

### **权限说明**

仅「超管accessToken」拥有调用权限。（权限组accessToken无法调用）

### 请求

**请求方式：**GET

**请求地址：**https://api.qingflow.com/tag（公有云版本）

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/tag](https://api.ding.qingflow.com/tag)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/tag

##### **参数说明(查询参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| tagId |  | 应用包id，不填则查询工作区内所有应用包详细信息 |
| pageSize | 是 | 每页数据条数 |
| pageNum | 是 | 请求页码 |

**请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

### 返回

##### 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations | 是 | array | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| pageNum | 是 | int | 请求页码 |
| pageSize | 是 | int | 每页数据条数 |
| resultAmount | 是 | int | 总数据条数 |
| pageAmount | 是 | int | 总页数 |
| result | 是 | array |  |
| tagId | 是 | int | 应用包id |
| tagName | 是 |  | 应用包名称 |
| tagAuth | 是 | int | 应用包的可见权限, 1-2分别代表：工作区可查看、指定用户可见 |
| authMembers |  | object | 指定用户可见的时候，可见的用户列表 |
| users |  | array | 用户列表 |
| userId |  | string | 用户id |
| userName |  | string | 用户昵称 |
| depts |  | array | 部门列表 |
| deptId |  | int | 部门id |
| deptName |  | string | 部门名称 |
| roles |  | array | 角色列表 |
| roleId |  | int | 角色id |
| roleName |  | string | 角色名称 |
| creator | 是 | object | 应用包创建者 |
| userId | 是 | string | 应用包创建者的userid |
| nickName | 是 | string | 应用包创建者的昵称 |
| headImg | 是 | string | 应用包创建者的头像 |
| createTime | 是 | string | 应用包的创建时间 |
| tagIcon | 是 | string | 应用包的图标 |
| appList | 是 | array | 应用列表（包含未发布状态应用） |
| appKey |  | string | 应用id |
| appName |  | string | 应用名称 |
| dashList | 是 | array | 门户列表（包含未发布状态门户） |
| dashKey |  | string | 门户id |
| dashName |  | string | 门户名称 |
