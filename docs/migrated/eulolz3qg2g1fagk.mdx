## 场景一.表格行不填or全填

表格内3个字段：A，B，C；需求实现必须不填或全填，如果只填写1项或2项，那么不允许提交。

### 思路逻辑

步骤一：表格行添加“校验字段”（单行文本）

目的是用于检查表格行是否满足条件

![截屏2022-09-05 下午5.05.25.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662368852209-f76f9264-7305-4591-8d77-58c3290ceb96.png)

步骤二：校验字段的公式设置

逻辑 条件1-全部为空，或者 条件2-全部不为空。

OR(

AND( ISEMPTY(表格·A), ISEMPTY(表格·B), ISEMPTY(表格·C) ),

AND( NOT(ISEMPTY(表格·A)), NOT(ISEMPTY(表格·B)), NOT(ISEMPTY(表格·C)) )

)

![截屏2022-09-05 下午5.09.03.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662368960995-188ac04d-7fb7-4bfe-b58f-a95442ffe26f.png)

步骤三：在添加流程，申请人节点，配置字段提交校验。

使用SEARCH函数判断校验字段是否包含“false”，当等于0时，则不包含false。文案自定义设置。

SEARCH("false",表格·校验字段)==0

#### ![截屏2022-09-05 下午5.10.42.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662369088976-c8518049-0ac9-48e1-b740-8b10e513a61c.png)

仅当不填/全填，校验为通过ture，否则为false

![截屏2022-09-05 下午5.14.47.png](https://cdn.nlark.com/yuque/0/2022/png/27174367/1662369318358-f89a8c32-9167-4d6b-8ec3-d6c879c394c7.png)

步骤四：设置字段隐藏和提交重新计算

字段隐藏为空值，需要开启重新计算，才可以在提交数据时计算出正确的值。
