## 无代码

### 1.1【导出】可选择是否导出QR、Webhook日志

流程日志记录了数据的操作记录、流程动向、以及操作反馈等信息，可以帮助节点负责人了解数据历史动态。在导出轻流应用数据时，您可以选择是否导出每条数据的流程日志，勾选「同时导出流程日志」后，数据的流程日志会和数据一起导出。

**此次更新** ，在「同时导出流程日志」选项下，**增加一个子项：导出Q-Robot、Webhook流程日志** 。

适用场景：应用内数据量大，且流程日志内有较多Q-Robot、Webhook操作，**增加子选项后，不需要这部分信息的用户，可以选择不导出冗余信息** 。需要这部分信息的用户，则可以选择导出，**减少因导出数据量庞大，导致服务器资源占用过多，影响用户使用的情况。**

可用版本：全版本，全平台

需要注意的是：

- 勾选了「同时导出流程日志」，才出现「导出Q-Robot、Webhook流程日志」，且默认为不被选中状态；
- 若勾选了「同时导出流程日志」，但没有勾选「导出Q-Robot、Webhook流程日志」，那么导出的数据中，流程日志部分没有Q-Robot、Webhook的流程节点信息，包括流程外Q-Robot。

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-09-26/eIZ2oir-umhsF9mtEsqLo0c1hJdJsrxD_.png)

### 1.2【体验优化】门户宫格-链接图标支持直接选择系统图标

宫格组件是工作区内外的快捷入口的容器，您可以将宫格内设置工作区的应用、应用包、门户的快捷入口，也可以在宫格内放置外部链接来满足不同场景下的页面查看需求。当您添加外部链接进入宫格时，您可以自主配置该快捷入口的标题、链接、打开方式和显示图标。

**此次更新** ，在设置外部链接的显示图标时，除了使用系统默认、上传自定义的图标，**新增直接调用系统图标的选项** 。

适用场景：使用宫格链接来源时，在没有合适的icon图片时，**能便捷地使用自定义icon，设置统一的、符合业务场景的系统入口，提升系统美观度。**

可用版本：全版本，全平台

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-09-26/ZuWSiQCTTDAivN9Gh4GN3GK0WYg60OQp_.png)

### 1.3【密码】“非自行注册”的账号的初始密码置空

**此次更新，** **对账号安全进行了加固** 。通过单点登录、接口登录的方式首次登录轻流的用户，密码为空，首次登录时无法通过账号密码登录系统。在个人中心补充密码后，可使用账号和密码登录。此功能仅对上线后的新用户生效。

可用版本：全版本，全平台

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-09-26/1aHQZM3fWK1CVpocTQSWFDh7x6yfqJeb_.png)

### 1.4【个人中心】“安全信息”功能的判断逻辑

**此次更新，对账号安全进行了加固。** 当用户在个人中心的安全信息补充或修改密码、邮箱或手机号时，需进行身份验证。以单点登录方式首次进入工作区的用户，若想使用账号密码登录，可在【个人中心-安全信息】中补充密码。若专有轻流客户未购买邮件或短信服务，邮箱或手机号验证的功能将不可用。

可用版本：全版本，全平台。但功能表现会因环境中是否配置了邮件、短信服务而有差异

## 轻代码

### 2.1【提醒推送】支持选择工作区全部应用

**提醒推送用于将工作区表单的\[事件信息\]通过http请求推送到轻流外部系统。** 您可以使用提醒推送，当应用状态/流程/数据的信息变动时，在自己的其它系统中收到提醒，直接点击链接跳转至轻流处理，方便、快捷。该功能可在【轻商城-拓展插件-提醒推送】进行全局配置。

**此次更新** ，支持用户选择消息推送的范围，在【自定义范围】的基础上，**新增【全部应用】的选项** 。

适用场景：当工作区每个应用包基本都需要推送的情况下，**新增【全部应用】的选项，支持动态新增的应用包/应用自动加入通知范围，可有效减少管理人员手动调整通知范围的重复性工作** 。

可用版本：全版本，全平台

【自定义范围】：默认勾选自定义范围，点击「添加推送范围」，选择应用（包）。

- 只有勾选的应用（包）才会推送，不包括新增的部分
- 被勾选的应用（包）应用删除后如果被恢复，提醒推送会恢复

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-09-26/Qz58dn1DQuR2mmAidZt3ZxIYAPJI59Ii_.png)

【全部应用】：手动勾选全部应用，工作区全部应用都在推送范围内

- 需要注意的是，**全部应用包含动态新增的应用包/应用** ，不包含被删除的应用
- 删除的应用如果被恢复，提醒推送会恢复

## 轻析

### 3.1 数据集报表支持门户中手动更新

数据集的数据支持手动更新和自动更新，但是数据集报表在门户中的数据更新只能依靠数据集的自动更新，不利于用户实时查看最新数据。

**此次更新** ，门户中的【轻析报表组件】针对数据源为“数据集”的报表，**新增按钮「** **显示数据更新信息」和** **「更新数据」** 。

需要注意的是：

- 当数据来源为数据集，且用户有该数据集使用权限，展示「更新数据」按钮；来源轻流应用，则不显示该按钮
- 点击「更新数据」按钮 = 点击数据集的「手动更新」按钮，此处的更新频率与数据集的「手动更新】保持一致
![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-09-26/HPg6LG19e7oNT1on9dta-HIxwTvWtXnw_.png)

可用版本：全版本，全平台

### 3.2【体验优化】汇总方式支持选择最新/最旧数据

**此次更新，支持汇总方式选择最新/最旧数据** ，不同情况下的可选情况有所区别：

- 除明细表外，对所有指标字段中的汇总方式新增最新数据、最旧数据选项，汇总结果受所选数据源中的日期字段影响
- 所选数据源中仅包含单个日期字段时，无需承载次级选项，可直接选择最新/旧数据

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-09-26/okiTagoFnazaVmAwXDikYAqePpCXFAgk_.png)

- 所选数据源中包含多个日期字段时，在选择最新/旧数据时需增加次级选项，汇总结果受所选的时间字段影响

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-09-26/YvUJPY74JXcUDrBe7cfFTTilO1H7Jqq6_.png)

- 所选数据源中无日期字段时，在选择汇总方式时隐藏最新/旧数据

可用版本：全版本，全平台

### 3.3【体验优化】轴显示文字优化

**此次更新** ，条形图、柱状图、折线图、散点图、组合图X轴标签，**新增「显示规则」配置项** 。

1.支持配置默认显示规则：即线上目前表现，随着屏宽减小，轴标签文字过多放不下时间隔显示（隐藏部分）

2.支持配置智能显示规则：随着屏宽减小，轴标签文字过多放不下时进行旋转，最大旋转角度为顺时针45度
