## 场景描述

问题：报表数据能否根据指标字段进行筛选？

答案：不能够依据指标字段来筛选。

​

**需求**

拿进销存举例：当前库存（指标）= 0 时，希望报表数据筛选中，能够去除该行数据。

## 思路流程

方案是单独设计库存管理应用，用于设计体现“商品库存”报表。

即每种商品自始至终就只有一条数据。在制作报表时，当前库存字段作为列，再增加筛选条件：

当前库存 > 0 即可。

​

本场景在出入库基础上实现，**请先学习出入库的系统搭建逻辑与方法：**[基础出入库](https://qingflow.com/dashboard/28d66ded/view)、[更多库存管理内容](https://qingflow.com/dashboard/3fdabdd7/view)
