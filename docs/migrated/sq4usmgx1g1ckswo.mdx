您可在这里查看接口的具体更新（新增、优化、废除等）情况，如有任何问题，请联系我们。

#### 版本7.1.2

新增：

新增了OpenAPI功能，支持对轻流中附件的URL进行重新加签，以便于企业版客户在其他系统中便捷地使轻流附件URL。

#### 版本7.1.1

新增：

支持上传单个文件接口，该接口用于向存储服务上传文件，仅支持上传单个且大小限制 50M 以内的单个文件。

#### 版本5.3.1

新增:
登出接口：调用本接口，实现对通过【登录接口】登录系统的用户的登出操作

#### 版本5.2.7

更新：
\[OPENAPI\]获取单条数据的详细信息接口返回应用信息新增两个参数：

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| appKey | 是 | string | 应用key |
| appName | 是 | string | 应用名称 |

#### 版本5.2.5

更新：
创建成员接口：为了提高系统安全性，通过该接口创建用户（这里指调用接口前该邮箱在对应环境内无账户）情况下，初始密码更改为空值

#### 版本5.2.0

新增：
通过邮箱或手机号查询成员userld接口查询单个部门详情接口

更新：
更新成员接口：优化superiorld参数逻辑，不传该参数不会更新成员直属主管；传空值会清空直属主管

#### 版本4.5.8

新增：
单条数据重新指派接口

#### 版本4.4.8

优化：

更新部门接口：

增加ordinal参数，可以修改指定部门在父部门下同级部门中的排序。

增加ordinal参数，可以创建部门，同时定义其在父部门下同级部门中的排序。

获取部门列表：

返回体增加ordinal参数，可以获取指定部门下所有部门（包括递归）的顺序值。
