## 场景/问题描述

客户需要快速将人员和日期范围生成对应的表格行，例如多成员和日期段8-1至8-3，写入表格得到——张三 8-1；张三 8-2 ；李四 8-1；李四 8-2 。以此得以在业务中，需要繁琐写入信息的地方可以一键生成想要的表格模板，得以在实际业务中简化操作~

通过代码块输出想要的结构

### 代码块

```javascript
var beginDate = qf_field.{开始日期$$618897CE$$};
var endDate = qf_field.{结束日期$$618897C0$$};
var dateArray = [];

// 将日期字符串转换为日期对象
var currentDate = new Date(beginDate);
var targetDate = new Date(endDate);

// 循环遍历日期范围内的每一天
while (currentDate <= targetDate) {
  // 获取当前日期的字符串表示
  var dateString = currentDate.toISOString().split('T')[0];

  // 将日期添加到数组对象中
  dateArray.push({ "Date": dateString });

  // 增加一天
  currentDate.setDate(currentDate.getDate() + 1);
}

var menber = qf_field.{成员$$618897DC$$};
//输出最后结果的数组
var result = [];

menber.forEach(menberItem => {
  dateArray.forEach(dateItem => {
    result.push({ "menber": menberItem, "Date": dateItem["Date"] });
  });
});

// 输出最终结果
qf_output = {result : result}
```
