调用本接口，更新应用包信息

---

### **权限说明**

仅「超管accessToken」拥有调用权限。（权限组accessToken无法调用）

### 请求

**请求方式：**POST

**请求地址：**https://api.qingflow.com/tag/update（公有云版本）

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/tag/update](https://api.ding.qingflow.com/tag/update)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/tag/update

##### **2.1 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

##### **2.2 请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| tagId | 是 | int | 应用包id |
| tagName |  | string | 应用包名称（1-100字符）可含空格 |
| tagAuth |  | int | 可见权限：1：工作区可查看（默认值） 2: 指定用户可见 |
| authMembers |  | object | tagAuth为2时填写，默认为（超/系统）管理员可见；tagAuth为1时填写无效 |
| userIds |  | \[array\] | 用户id列表 |
| deptIds |  | \[array\] | 部门id列表 |
| roleIds |  | \[array\] | 角色id列表 |
| includeSubDeparts |  | boolean | 是否动态包含已选部门下的子部门，默认true |
| tagIcon |  | string | 应用包图标，格式为链接或指定格式字符串（如下）默认值"\{"icon":null,"iconColor":"qing-orange","iconName":null\}"（应用包首字+橙色底） |

##### **2.3 请求体示例**

```json
{
    "tagid": 12484,
    "tagName": "new tag",
    "tagAuth": "2",
	  "authMembers": {
        "userIds": ["8935"，"7883"],
        "deptIds": [3572],
        "roleIds": [],
        "includeSubDeparts": true
    },
    "tagIcon":{"icon":null,"iconColor":"qingorange","iconName":null}
}
```

### 返回

##### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations |  |  | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| tagId |  | int | 应用包id |

##### 3.2 返回体示例

```json
{
	"errCode": 0,
	"errMsg": "ok",
	"result": {
			"tagId": 10637,
		}
}
```

### 注意事项

1、请求参数中，dashIcon参数为应用包的图标，支持传入图片链接

- 默认为橙色+首字，值为：\{"icon":null,"iconColor":"qing-orange","iconName":null\}，效果如图：

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-09/ZJi9ooQi2edAunq3ID5QVvJ_G3eWt9Xq_.png)

- 图标底色（iconColor）/组件（iconName）可选值可参考

2、应用包名称不可更新为空字符串，否则将被更改为默认名称：未命名应用包
