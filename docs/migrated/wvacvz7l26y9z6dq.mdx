## 1.方案介绍

### 1.1方案简介

本模板主要帮助企业解决日常的费用报销、请款支付、预算控制、预算调整审核、备用金管理等业务场景，实时查看当前预算使用情况、自动生成各部门费用数据报表，助力企业实现费控数据化，为企业降本增效。

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1699427883488-40d6e750-8d27-46c5-9c6c-db990d9f3405.png)

### 1.2业务痛点及解决方案

| **业务痛点** | **解决方案** |
| --- | --- |
| **审批流程长**繁琐冗长的审批流程，给员工带来不好的工作体验。 | **提升规范化**规范备用金、预算限额设置；周期付款自动提醒，避免遗忘。**审批协同更高效**自定义费用报销、费用付款流程，生成流程待办，缩短审批流程，提升效率。**数据分析可视化**自动生成财务流水、可视化呈现，企业财务情况实时掌握；部门预算限制、备用金限制调整均有据可依；减轻财务负担，大幅提高财务人员工作效率。 |
| **工作效率低**财务需要筛选、核对、验真发票，机械劳动多。 |  |
| **信息同步慢**财务流水不能实时同步，成本控制调整不够敏捷。 |  |
| **统计分析难**手动汇总数据易出错，管理者难以作出正确决策。 |  |

## 2.核心模块及亮点

### 2.1预算管理

支持根据年份、月份、部门等多维度组合，设置与管控预算；

支持及时灵活调整预算，并生成调整记录，易追溯；

多维度报表统计分析预算总额、已用预算、可用预算、预算调整，支撑管理层决策。

### 2.2费用报销

实时关联部门可用预算，合理管控每笔报销；

支持选择是否抵扣备用金，流程自动流转，无需再次发起核销备用金申请，简化员工报销流程。

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1699950975100-c2bc3b0d-5943-45fa-9fcf-9e824a709bef.png)

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1699952507124-7537fa97-14c2-4352-8788-a506728cd743.png)

### 2.3费用付款

支持周期性付款，付款日前自动提醒，有效规避遗漏付款行为；

申请自动流转至财务，发送待办提醒，付款后智能提醒申请人，减少沟通成本，提升审批效率。

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1699952798506-9b40eb78-f14e-43a0-9243-ae520c9c47ef.png)

### 2.4备用金管理

支持多维度设置备用金申请限制，自动统计备用金申请情况；

核销申请自动关联待核销金额，财务确认核销到账金额。

### 2.5数据分析

可视化图表直观展现预算、报销、备用金相关数据，一目了然；

多角度分析报销数据，为管理层调整公司预算或备用金提供有力决策依据。

## 3.操作说明

### 3.1数据看板

#### 3.1.1预算数据分析

在「数据看板」>>「预算数据分析」查看预算分析报表，如总预算、已用预算、公司预算趋势图、部门总预算统计，门户中配置筛选组件，可快速查询相关数据，同时配有宫格组件，财务人员可直接发起预算设置或调整数据

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1699431011886-3169a153-8913-4d7b-9845-5794dad00210.png)

#### 3.1.2费用报销分析

在「数据看板」>>「费用报销分析」查看费用报销统计情况，如累计报销、累计付款、各部门总报销对比、费用种类对比、报销一览表，门户中配置筛选组件，方便查询具体数据，同时配有宫格组件，财务人员可快速发起或查看相关数据

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21388903/1699431107272-286b147c-908d-4762-a3d8-a1831d0c2018.png)

#### 3.1.3个人数据分析

员工在「数据看板」>>「个人数据分析」查看个人数据，包含个人备用金概览及个人报销总览，门户中配有宫格组件，员工可直接发起申请数据

![image.png](https://cdn.nlark.com/yuque/0/2023/png/38812530/1699257235512-e0ded438-602e-4f7c-8edc-1182d55adb0b.png)

### 3.2基础信息

财务可通过批量导入或单个新增录入基础数据，便于后续使用过程中数据的关联获取（模板中已提供部分示例数据，可根据实际情况重新维护）

基础数据包括：费用设置、账户信息、备用金限制、周期设置

![image.png](https://cdn.nlark.com/yuque/0/2023/png/38812530/1699265589079-d6ea3913-88aa-4c58-856d-7c81319626ea.png)

### 3.3预算管理

#### 3.3.1部门预算设置表

财务在「预算管理」>>「部门预算设置表」点击「发起新的」新增预算信息，按照年月设置各个部门的预算金额，设置完成后预算信息自动新增在「DB-费用核算基础表」应用中

![image.png](https://cdn.nlark.com/yuque/0/2023/png/38812530/1699240527816-2d602fc9-6ac4-4c30-83c3-12489e4eec7b.png)

#### 3.3.2部门预算调整表

财务在「预算管理」>>「部门预算调整表」中点击「发起新的」新增预算调整信息，选择部门、年月后，自动关联该部门当前剩余预算金额，财务填写调整的金额数（正为增、负为减），调整后预算调整信息自动新增在「DB-费用核算基础表」中

![image.png](https://cdn.nlark.com/yuque/0/2023/png/38812530/1699240611002-5b598c58-9641-4dc4-82ef-51168cee2e66.png)

### 3.4备用金（借款）管理

#### 3.4.1备用金申请

员工在「备用金管理」>>「备用金申请」中点击「发起新的」发起备用金申请，自动关联当前员工已申请备用金，如本次申请备用金与已申请备用金相加金额超出备用金限制，则无法提交

发起申请后，该申请自动流转至财务人员对其审核确认，付款确认后，备用金申请信息自动新增在「DB-费用核算基础表」中

![image.png](https://cdn.nlark.com/yuque/0/2023/png/38812530/1699241961842-66917e34-7c03-4cfb-b88a-84a6f3cf2ca9.png)

#### 3.4.2备用金核销

员工在「备用金管理」>>「备用金核销」中，点击「发起新的」发起备用金核销申请，自动计算核销须退回金额；

发起申请后，财务人员收到待办提醒对其进行确认，确认无误后备用金核销完成，「DB-费用核算基础表」及「备用金申请」中对应备用金状态自动更新为“已核销”。

（若员工申请报销时，选择报销金额抵扣备用金，且核销该备用金，则自动发起备用金核销申请，员工需先补充核销申请信息，该申请再流转至财务进行审核）

![image.png](https://cdn.nlark.com/yuque/0/2023/png/38812530/1699243724007-db3dc017-9983-4021-8dda-7baaa37c5165.png)

### 3.5费用管理

#### 3.5.1费用报销申请

员工在「费用管理」>>「费用报销申请」中，点击「发起新的」新增费用报销申请，财务收到待办提醒进行审核，审核通过则费用报销完成；

当员工选择报销金额抵扣备用金，即字段“是否抵扣备用金”为“是”，填写抵扣备用金信息与抵扣金额，提交后备用金抵用信息与报销信息自动新增在「DB-费用核算基础表」中，若选择核销相关抵扣备用金，自动发起备用金核销申请

当字段“是否抵扣备用金”为“否”，则报销信息自动新增在「DB-费用核算基础表」中

![image.png](https://cdn.nlark.com/yuque/0/2023/png/38812530/1699259284773-43c08cc2-1641-4878-9e94-af07fd6a34c6.png)

#### 3.5.2费用付款申请

员工在「费用管理」>>「费用付款申请」中点击「发起新的」发起费用付款申请；

若付款申请为周期费用（设置周期费用后将周期性自动发起付款申请），请款人收到待办补充付款申请信息；

发起或补充申请后，数据流转至财务人员对申请进行审核，审核通过后，费用付款信息自动新增在「DB-费用核算基础表」中

![image.png](https://cdn.nlark.com/yuque/0/2023/png/38812530/1699259801482-f6ca30af-847e-4ca9-8b3d-d168ceeb3653.png)
