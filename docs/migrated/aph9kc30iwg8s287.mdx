该接口用于向存储服务上传文件。

---

#### 权限说明

仅专有轻流可调用。「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有数据权限。

#### 请求

**请求方式：**POST（**HTTPS**）

**请求地址：**http(s)://xxx.xx(自有域名)/openApi/upload/file

**请求头（header）**

| 参数 | 是否必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| `accessToken` | 是 | string | 调用接口凭证 |

**​**

**请求体（body）**

| 参数 | 是否必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| `file` | 是 | file | 上传文件，单个文件、50MB以内。大于50MB文件，将会返回错误码<br /> |
| `fileName` | 是 | string | 文件名称，带后缀，和上传时的文件名称一致 |

#### 返回

**返回体**

| 参数 | 是否必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| `errCode` | 是 | int | 错误码，非 0 代表失败 |
| `errMsg` | 是 | string | 错误码说明 |
| `result` | ​<br /> | ​<br /> | ​<br /> |
| `fileName` | 是 | string | 文件名称 |
| `fileUri` | 是 | string | 文件地址，uri 为带匿名签名的uri，地址过期时间为 24 小时 |

​

**返回体示例**

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "result":{
    "fileName": "FILE_NAME",
    "fileUri": "FILE_URL"
  }
}

```
