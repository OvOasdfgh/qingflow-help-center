轻流是一款多功能的企业级工作流程自动化平台。核心功能包括但不限于：

| 功能类别 | 功能名称 | 描述 | 优点 |
| --- | --- | --- | --- |
| 核心功能 | 表单 | 快速创建自定义表单以收集和组织业务数据。 | 易于使用，多种数据类型支持，无需编程知识。 |
| 流程 | 设计工作流程图，自动化审批和协作过程。 | 提高效率，确保一致性，减少手工操作。 |  |
| 数据 | 存储和管理所有通过表单收集的数据。 | 一站式数据管理，简化数据筛选、排序和分析。 |  |
| 报表 | 生成定制的数据视图和图表以洞察业务性能和趋势。 | 支持决策制定，自定义报表，实时数据更新。 |  |
| 门户 | 提供交互式页面用于访问工作流程、报表和其他工具。 | 一站式访问，提高用户体验。 |  |
| Q-Robot | 自动化机器人工具，模拟人工操作和集成外部系统。 | 简化流程自动化，无需复杂API集成。 |  |
| OpenAPI | 使用API与第三方应用进行集成和自动化数据交换。 | 提供了程序化控制和扩展性，实现了高级自定义集成。 |  |
| 扩展功能 | 自定义打印模板 | 创建特定格式的文档模板并打印。 | 提升制作效率，保证文档格式统一和专业。 |
| 自定义按钮 | 添加操作按钮至页面以执行特定的脚本或流程。 | 高度灵活和可定制，简化用户操作。 |  |
| 插件 | 通过内置或第三方插件扩展轻流平台的功能。 | 功能丰富，适应多样的业务场景。 |  |
| 连接器 | 连接轻流与外部系统和服务，如CRM、ERP等。 | 实现跨系统的数据同步和自动化，提升协作能力。 |  |
