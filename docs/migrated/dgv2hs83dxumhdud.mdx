## 场景/问题描述

比如需要调用重新指派申请人接口就需要对应成员的userid（只适合获取单个成员的ID）

## 思路逻辑

使用Q-linker调用接口获取，可以调用有关获取成员的接口

## 配置过程

### Q- Linker实现

#### 方法一

- 通过获取工作区全部成员接口
- 对应接口文档：[https://help.qingflow.com/help-docs?type=qingCode&docId=704de8fa6428f55b00034a922410c9bb&parentId=](https://help.qingflow.com/help-docs?type=qingCode&docId=704de8fa6428f55b00034a922410c9bb&parentId=)

![image.png](https://cdn.nlark.com/yuque/0/2023/png/28884377/1692244271705-b2190f2e-38b1-4bd5-9ffe-d088d26078b5.png)

##### URL

https://api.qingflow.com/user（以公有云为例）

##### Param

pagesize：建议写大点（比通讯录人数多即可，因为Q-linker并不支持分页）

pagenum:1（默认）

##### header

accessToken：

轻商城——拓展插件——openAPI获取

##### json path解析

$.result.result\[?(@.email== '成员')\].userId

#### 方法二

- 通过邮箱或者手机号获取成员ID
- 接口文档：[https://help.qingflow.com/help-docs?type=qingCode&docId=97331e4564e2d58101db4aea2f1a6519&parentId=](https://help.qingflow.com/help-docs?type=qingCode&docId=97331e4564e2d58101db4aea2f1a6519&parentId=)

```bash
curl --location 'https://api.qingflow.com/user/getId?email=june1790812261%40163.com' \
--header 'accessToken: d866db1d-79ca-42c5-9e9c-0b1ce21135d2' \
--header 'Cookie: JSESSIONID=A2D6C486F566FAE11FFCDAB18DBCCA2B'
```
