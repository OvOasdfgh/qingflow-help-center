调用本接口，删除应用包

---

### **权限说明**

仅「超管accessToken」拥有调用权限。（权限组accessToken无法调用）

### 请求

**请求方式：**DELETE

**请求地址：**https://api.qingflow.com/tag（公有云版本）

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/tag](https://api.ding.qingflow.com/tag)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/tag

##### **2.1 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

##### **2.2 请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| clearAll |  | Boolean | 是否一起删除其中的应用/门户/分组true：全部删除false：仅删除应用包（默认值） |
| tagIds | 是 | array | 需要删除的应用包id |

##### **2.3 请求体示例**

```json
{
    "clearAll":true,
	"tagIds":[372732,384849]
}
```

### 返回

##### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations | 是 | array | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| tagIds | 是 | array | 删除成功的应用包id |

##### 3.2 返回体示例

```json
{
	"errCode": 0,
	"errMsg": "ok",
	"result": {
			"tagIds": [372732,384849]
		}
}
```

##### 3.3 错误码相关

[错误码相关](https://help.qingflow.com/help-docs?type=qingCode&docId=0122a5876425b78206cbe436426dca23&parentId=)

### 注意事项

1、本接口支持批量删除应用包，但仅返回删除成功的应用包id

（若接口报错表示所有应用包均未删除成功）

2、若clearAll参数传false，应用包中的应用将不被删除，为「无所属应用包」状态，您仍然可以在工作区内搜索到对应应用。
