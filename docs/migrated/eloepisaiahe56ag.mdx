调用本接口，创建应用包（空白应用包、解决方案）

---

### **权限说明**

仅「超管accessToken」拥有调用权限。（权限组accessToken无法调用）

### 请求

**请求方式：**POST

**请求地址：**https://api.qingflow.com/tag（公有云版本）

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/tag](https://api.ding.qingflow.com/tag)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/tag

##### **2.1 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

##### **2.2 请求体（Body）**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| userId |  | string | 应用包的创建人userid（必须为工作区系统管理员），不填默认为工作区创建者 |
| type |  | int | 0:空白应用包（默认值）1:解决方案 |
| solutionKey |  | string | 解决方案ID |
| includeData |  | Boolean | 是否包含示例数据（type为1时有效，非必填，默认值为true） |
| tagName |  | string | 应用包名称（1-100字符，可含空格） |
| tagAuth |  | int | 可见权限1：工作区可查看（默认值）2: 指定用户可见 |
| authMembers |  | object |  |
| userIds |  | array | 用户id列表 |
| deptIds |  | array | 部门id列表 |
| roleIds |  | array | 角色id列表 |
| includeSubDeparts |  | Boolean | 是否动态包含已选部门下的子部门，默认true |
| tagIcon |  | string | 应用包图标，格式为链接或指定格式字符串（如下）默认值"\{"icon":null,"iconColor":"qing-orange","iconName":null\}"（应用包首字+橙色底） |

##### **2.3 请求体示例**

```json
{
   "type":1,
   "solutionKey":"947f2d1a",
   "tagName":"nihao",
   "tagAuth":2,
   "authMembers":{
       "userIds":[9054]
   }

}
```

### 返回

##### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations | 是 |  | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| tagId |  | int | 应用包ID |

##### 3.2 返回体示例

```json
{
	"errCode": 0,
	"errMsg": "ok",
	"questionRelations":[],
	"result": {
			"tagId":473843
		  }
}
```

[错误码相关](https://help.qingflow.com/help-docs?type=qingCode&docId=0122a5876425b78206cbe436426dca23&parentId=)
