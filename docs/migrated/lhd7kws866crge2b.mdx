## 场景描述

例如我有产品明细表如下图

我希望可以在另一个应用产品表格中实现根据产品分类自动引用产品明细的数据

![image.png](https://cdn.nlark.com/yuque/0/2023/png/28884377/1691639627154-c3e30920-4482-4474-98f6-d9698f8172f3.png)

## 解决思路

可以通过使用代码块来实现或者使用q-linker来实现。

具体看实际场景采用，如果是手动发起数据两者都可以采用，但是如果是通过QR添加数据发起数据，那么就需要使用Q-linker来进行提交重计算。

## 配置过程

### 代码块实现

#### 代码与测试

- 代码注释

- key：对应表单中产品分类字段
- URL：需要换成对应的获取应用数据接口的URL，具体看[帮助文档](https://help.qingflow.com/help-docs?type=qingCode&docId=fc8e64656428ea3a06fe9b406b9b7be9&parentId=)

async function processPage(apiUrl, pageNum, queries) {
  const postData = {
    pageSize: pageSize.toString(), 
    pageNum: pageNum.toString(),
    queries: queries
  };

  const response = await axios.post(apiUrl, postData, { headers });
  return response.data.result;
}

async function processAllPages(apiUrl, queries, extractQueIds) {
  const firstPageData = await processPage(apiUrl, 1, queries);
  let totalPages = firstPageData.pageAmount;

  const promises = [];

  for (let pageNum = 2; pageNum <= totalPages; pageNum++) {
    promises.push(processPage(apiUrl, pageNum, queries));
  }

  const responses = await Promise.all(promises);
  const reslist = extractData(firstPageData, extractQueIds);

  responses.forEach((data) => {
    const extractedData = extractData(data, extractQueIds);
    reslist.push(...extractedData);
  });

  return reslist;
}

function extractData(response, queIds) {
  const result = response.result;
  const res_list = [];

  result.forEach((value) => {
    const res_msg = {};

    value.answers.forEach((v) => {
      const queId = v.queId;
      const queTitle = v.queTitle;

      if (queIds.includes(queId)) {
        const values = v.values;
        const dataValue = values[0].dataValue;
        res_msg[queTitle] = dataValue;
      }
    });

    res_list.push(res_msg);
  });

  return res_list;
}

#### 表单字段配置

需要再加一个字段来进行输出产品分类，因为如果直接将单项选择的产品分类作为字段插入进body中的话，当自动触发q-linker的话，就会返回全部内容。

所以加了单行文字字段来进行判断输出，如果单项选择没有选择内容就输出空格，有选择就输出本身。这样就避免自动触发输出全部内容了
