## 场景/功能描述

表格附件，经常用于记录不同任务的信息。每一行对应一个任务，而每个任务可能包含不同数量和类型的附件。由于附件内容分散且查看不方便，如果将每个任务的附件整合到一个字段中，那么就可以更方便地查看和管理任务及其附件信息了。

### 代码块配置

```javascript
var table = 插入表格字段;
qf_output = {table:table}
```

上传任意附件，并点按测试，解析得到数据和字段代码

表格：table

表格·附件：field\_144831959（请勿照搬，以获取到的为准）![image.png](https://cdn.nlark.com/yuque/0/2023/png/27174367/1690783095504-484286cf-03c7-4c6d-94cc-346f23ae9611.png)

```javascript
var table = 插入表格字段;
var result = table[0].粘贴上表格·附件的字段代码;
for(var i =0;i<table.length-1;i++){
  result = result.concat(table[i+1].粘贴上表格·附件的字段代码);
}
qf_output = {result:result};
```

## 实现效果

利用“代码块”功能可以整合附件到一个字段中，用户能够更便捷地查看和管理任务及其附件信息，无需逐个查看每个附件。这样的功能实现能够提高任务管理的效率和用户体验，使得用户能够更轻松地查看和管理任务及其附件信息。
