## 问题描述

PC端可以打开的某条数据，但是手机端一直显示加载中，是为什么呢？

示例：

![image.png](https://cdn.nlark.com/yuque/0/2021/png/536585/1617086595900-b842ce8a-dee0-4248-bbb0-08a4461b6784.png)

## 排查方法

大概率是因为有个别日期字段的值非法导致（不代表所有情况）

需要仔细检查所有日期字段的值，是否有invalid value 、0、汉字、2021/01/01（正确分割符为 - ）等情况，

如果出现这种情况，请帮助客户修正数据，并找到触发这种问题的原因

比如说导入时excel中的日期字段有非法的数据，OpenApi导入了非法的数据，公式计算计算出非法的数据等

如果经过仔细检查没有发现以上所属情况，请联系研发人员分析
