## 1. 无代码

### 1.1 【体验优化】应用编辑、收藏等功能外置

「编辑应用」功能入口变为外置扳手图标；「数据管理」功能入口位于应用顶部导航栏右侧；其它应用相关操作的功能入口位于应用名称右侧的「···」内；视图按钮与视图列表按钮均位于数据展示页顶部的工具栏右侧

可用版本：全版本，全平台

![文档图片](https://7465-test-1g4eic6e66c1202d-1309122329.tcb.qcloud.la/6.7/5.29%E5%8A%9F%E8%83%BD%E6%9B%B4%E6%96%B0%E6%97%A5%E5%BF%97/1.png?sign=a6cd31bd43d09bcdbdf04e94c0b8d6d2&t=1686133213)

### 1.2 【流程】超时和流程外Q-Robot支持法定工作日

支持以法定工作日为单位计算流程超时、流程外Q-Robot的触发时间，避免在法定节假日收到提醒而造成打扰的情况

可用版本：公有云版本，全平台

![文档图片](https://7465-test-1g4eic6e66c1202d-1309122329.tcb.qcloud.la/6.7/5.29%E5%8A%9F%E8%83%BD%E6%9B%B4%E6%96%B0%E6%97%A5%E5%BF%97/2.gif?sign=29e12b5b283e445f57c25a89ea757da9&t=1686133233)

![文档图片](https://7465-test-1g4eic6e66c1202d-1309122329.tcb.qcloud.la/6.7/5.29%E5%8A%9F%E8%83%BD%E6%9B%B4%E6%96%B0%E6%97%A5%E5%BF%97/3.gif?sign=e436e3d6fd6dc58c95f657e73c361726&t=1686133255)

### 1.3 【流程】催办按钮配置支持关闭

申请人节点新增「允许催办」按钮，可以设置是否允许申请人对流程中的审批节点进行催办

可用版本：全版本，全平台

![文档图片](https://7465-test-1g4eic6e66c1202d-1309122329.tcb.qcloud.la/6.7/5.29%E5%8A%9F%E8%83%BD%E6%9B%B4%E6%96%B0%E6%97%A5%E5%BF%97/4.gif?sign=f368a160c466165ff8e8d320e7340839&t=1686133274)

### 1.4 【工作区】语言设置自适应

「管理后台」-「基本信息」中的「外链语言」功能下架。非登录状态下，轻流系统显示语言与用户浏览器设置的语言保持一致。当邮件的收件人为工作区以外的人员时，邮件的语言显示为「中英双语」版本

可用版本：全版本，全平台

![文档图片](https://7465-test-1g4eic6e66c1202d-1309122329.tcb.qcloud.la/6.7/5.29%E5%8A%9F%E8%83%BD%E6%9B%B4%E6%96%B0%E6%97%A5%E5%BF%97/5.png?sign=4f278e40ca0c1a208550279ef23e1934&t=1686133284)

## 2. 轻析

### 2.1 【体验优化】指标看板优化

可以对指标看板中卡片的边框颜色、背景颜色进行更改；也可以选择是否显示维度字段的名称，对维度字段的字号和文字颜色进行更改

可用版本：全版本，全平台

![文档图片](https://7465-test-1g4eic6e66c1202d-1309122329.tcb.qcloud.la/6.7/5.29%E5%8A%9F%E8%83%BD%E6%9B%B4%E6%96%B0%E6%97%A5%E5%BF%97/6.png?sign=0325064913c571f761d3a89b5968acf6&t=1686133315)

### 2.2 明细表支持自助筛选

可以在查看明细表时对表头字段进行筛选

可用版本：全版本，全平台
