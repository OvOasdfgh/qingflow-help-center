## 应用场景

通过轻流应用表单实现与金蝶云星空进行对接

目前接口支持：

1. 暂存：draft ：不会触发金蝶数据校验
2. 保存：save ：会触发金蝶的数据校验，保存失败
3. 提交：submit：提交数据
4. 审核：audit ：审批
5. 反审核：un\_audit
6. 查看：view：查看单条数据详细信息
7. 下推：push:下推数据
8. 单据查询：executeBillQuery ：返回某一张表单的所有数据（可筛选）
9. 财务报表查询：getSysReportData：查询金蝶财务报表数据

ps:

公有云环境下，连接金蝶需要确保所连接的金蝶可以在外网环境下访问，否则无法进行连接。

私有化环境下，需要部署对应的连接器，然后根据运维提供的访问地址进行对接金蝶。

### 一、进行第三方登录授权操作

具体金蝶授权文档：

[https://vip.kingdee.com/knowledge/specialDetail/229961573895771136?category=229963554177453824&id=298030366575393024&productLineId=1](https://vip.kingdee.com/knowledge/specialDetail/229961573895771136?category=229963554177453824&id=298030366575393024&productLineId=1)

需要获取到的参数：

- dcId：数据中心ID（帐套ID）
- appId：应用ID
- appSecret：应用密钥
- username：集成用户
- serverUrl：k3cloud服务地址，需要后缀/k3cloud，公有云8.1版本以上可以不用传值即可
- lcId：默认值2052

### 二、获取access\_token

请求头（Header）

| ​参数 | 是否必填 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 企业版客户需要试用请联系轻流技术支持申请token，试用token可以调用500次接口购买企业版客户，首次有10000次使用额度，后续使用完可联系客户成功人员进行增购。专有云/私有化客户，运维会单独提供token进行使用。 |

### 三、查询金蝶的单据数据

1. 接口说明：用户调用金蝶各种类型的单据查询接口
2. 接口地址：

1. 公有云接口地址：https://connect.oalite.com/api/k3cloudApi/executeBillQuery
2. 私有化/专有云接口地址：https://xxxx.xxxx.xxx/k3cloudApi/executeBillQuery

1. 请求方式：POST
2. 请求头（Header）：accessToken
3. 请求体（body）：

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| params |  | object |  |
| formId | 是 | string | 业务对象表单Id |
| fieldKeys | 是 | string | 需查询的字段key集合，字符串类型，格式："key1,key2,..."（必录）注（查询单据体内码,需加单据体Key和下划线,如：FEntryKey\_FEntryId） |
| filterString | 是 | string | 过滤条件，如："FDATE>='2022-10-01' AND (FStatus='4' OR FStatus='3')" |
| orderString | 是 | string | 排序字段，字符串类型（非必录） |
| topRowCount | 是 | int | 返回总行数，整型（非必录），默认为0 |
| startRow | 是 | int | 开始行索引，整型（非必录），默认为0 |
| limit | 是 | int | 最大行数，整型，默认为0，不能超过10000（非必录） |
| userInfo |  | object | 用户信息 |
| dcId | 是 | string | 数据中心ID（账套ID） |
| appId | 是 | string | 应用ID |
| appSecret | 是 | string | 应用密钥 |
| username | 是 | string | 集成用户 |
| serverUrl | 是 | string | k3cloud服务地址，需要后缀/k3cloud |
| lcId | 是 | int | 默认值2052 |
