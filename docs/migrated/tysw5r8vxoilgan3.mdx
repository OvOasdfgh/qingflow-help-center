调用本接口，获取部门列表

---

### **权限说明**

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有通讯录权限。

### 请求

**请求方式：**GET

**请求地址：**https://api.qingflow.com/department（公有云版本）

> 示例如下：

```javascript
GET https://api.qingflow.com/department
```

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/department](https://api.ding.qingflow.com/department)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/department

#### **2.1 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

#### **2.2 参数说明(查询参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| deptId |  | 部门id，可查询该部门及其所有子部门信息（包括递归） |

### 返回

#### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations |  |  | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| department |  | array |  |
| deptId |  | string | 部门id |
| deptLeader |  | array | 部门主管的userId |
| name |  | string | 部门名称 |
| optionId |  | int |  |
| parentId |  | int | 父部门id |
| ordinal |  | int | 同级部门（同个父部门）中的顺序值 |

#### 3.2 返回体示例

```json
{
    "errCode": 0,
    "errMsg": null,
    "questionRelations": [],
    "result": {
        "department": [
            {
                "deptId": 133579,
                "deptLeader": [],
                "name": "某部门",
                "optionId": 133579,
                "parentId": null
            },          
            {
                "deptId": 149337,
                "deptLeader": [],
                "name": "1111",
                "optionId": 149337,
                "parentId": 133579
            },           
        ]
    }
}
```

### 注意事项

1、企微版本公有云工作区，部门名称（name参数）返回值为deptId
