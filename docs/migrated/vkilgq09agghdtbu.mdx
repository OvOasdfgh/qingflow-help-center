调用本接口，删除应用。

---

### **权限说明**

「超管accessToken」和「权限组accessToken」都可以调用，「权限组accessToken」须具有对应应用的删除权限。

### 请求

**请求方式：**DELETE

**请求地址：**https://api.qingflow.com/app/APPKEY（公有云版本）

> 请求地址中APPKEY为需要替换的变量，根据实际获取值更新，示例如下：

```javascript
DELETE https://api.qingflow.com/app/fea8744
```

**其他版本请求地址：**

钉钉版本：[https://api.ding.qingflow.com/app/faea1906](https://api.ding.qingflow.com/app/faea1906)

专有轻流：http(s)://xxx.xx(自有域名)/openApi/app/faea1906

##### **2.1 参数说明(路径参数)：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| appKey | 是 | 需要删除的应用ID，获取方式参考基本概念介绍——appKey |

##### **2.2 请求头（Header）**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 调用接口凭证。获取方法请查看“文档” |

### 返回

##### 3.1 返回体

| 参数 | 必含 | 类型 | 说明 |
| --- | --- | --- | --- |
| errCode | 是 | int | 错误码，非0表示失败 |
| errMsg | 是 | string | 错误描述 |
| questionRelations | 是 |  | 关联的设置，这里没用 |
| result | 是 | object | 返回结果 |
| appKey | 是 | string | 应用ID |

##### 3.2 返回体示例

```json
{
    "errCode": 0,
    "errMsg": null,
    "questionRelations": [],
    "result": {
        "appKey": "fea8744"
    }
}
```
