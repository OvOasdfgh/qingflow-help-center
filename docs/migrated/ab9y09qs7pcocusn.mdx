## 1 功能介绍

### 1.1 功能简介

“关联已有数据”是表单部分字段的**高级配置项**。选定字段后，通过配置关联应用及关联字段，可直接**调用其他应用已录入的****最新****数据**，实现跨应用的数据连接。

注：子管理员配置关联已有数据时，必须拥有目标应用的数据权限，才能关联到。

### 1.2 使用场景

例如，在填写「调岗申请」时，输入“员工ID”，系统自动关联出「员工信息」中的“员工姓名”、“入职时间”和“工作年限”。

## 2 设置步骤

### 2.1 功能入口

进入应用编辑界面，在表单设计页面，点击字段，可在右侧的字段配置面板，看到功能入口。

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21683170/1699249626238-033e943b-5c4e-4482-b33d-682c72ce2625.png)

![image.png](https://cdn.nlark.com/yuque/0/2023/png/21683170/1699249656855-5fa69169-a87d-409b-93a7-4105d6ad9c94.png)

### 2.2 配置方式

想要在应用「调岗申请」中，输入“员工ID”，调用「员工信息」中相匹配的员工信息。

1.选择【单行文字】字段，修改【标题】为“员工姓名”；

2.选择默认内容为【关联已有数据】并设置：关联应用为「员工信息」，关联字段为“员工姓名”。

3.设置筛选条件，将关联应用中的满足条件的字段最新值，返回到当前应用的字段中：当「员工信息」中有“员工ID”的值，与「调岗申请」中输入的“员工ID”相等，返回该员工ID对应的“员工姓名”。

注：若满足条件的值有多个，系统默认取最新值。

## 3 注意事项

1）“关联已有数据”现支持的字段类型整理如下，**特殊字段仅支持同类型数据互相关联**：

| 支持配置「关联已有数据」的表单字段 | 对应可选择的关联字段 |
| --- | --- |
| 单行文字 | **表单字段：**单行文字、多行文字、数字、链接、日期、起止时间、电话、邮箱、单项选择、下拉选择、多项选择、图片选择、地址、数据关联、成员、部门**系统字段：**编号、申请人、申请时间、更新时间、当前流程状态 |
| 多行文字 | **表单字段：**单行文字、多行文字、数字、链接、日期、起止时间、电话、邮箱、单项选择、下拉选择、多项选择、图片选择、地址、数据关联、成员、部门**系统字段：**编号、申请人、申请时间、更新时间、当前流程状态 |
| 数字 | 数字 |
| 日期 | **表单字段：**日期**系统字段：**申请时间、更新时间 |
| 邮箱 | 邮箱 |
| 电话 | 电话 |
| 数字 | 数字 |
| 单项选择 | 单项选择、下拉选择、单行文字、数据关联 |
| 下拉选择 | 单项选择、下拉选择、单行文字、数据关联 |
| 多项选择 | 多项选择、单项选择、下拉选择 |
| 附件上传 | 附件上传 |
| 地址 | 地址 |
| 链接 | 链接 |
| 成员 | 成员、申请人 |
| 部门 | 部门 |
| 表格 | 表格 |
| 表格子字段 | 取决于表格子字段类型，关联规则一致（表格字段除外） |

2）当表格需配置关联已有数据时，需对表格的每一“子字段”配置关联规则，详见：[关联已有表格](https://exiao.yuque.com/ixwxsb/bgzs0e/rqt54vp7rbp8szds)

3）若满足条件的值有多个，系统默认取最新值。
![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-07-04/F2NOHX2aoRgSrG5LArV74aeqAXpPpbj0_.png)
例如：员工信息表中有3个同名同姓的员工，工作年限分别为4年、3年和1年，1年为最新数据。

若输入员工姓名，设置筛选条件为“员工姓名”相等，关联员工的工作年限，则关联到的最新数据为“1”，不符合实际情况；员工ID是每个员工独有的身份标识，通过员工ID绑定员工信息可以避免此类问题。

4）“关联已有数据”与“数据关联”字段的区别： [数据关联](https://exiao.yuque.com/ixwxsb/bgzs0e/kdxy02mbt6cqcvrx)

|  | **关联已有数据** | **数据关联** |
| --- | --- | --- |
| 类型 | 表单部分字段的配置项 | 表单字段 |
| 关联范围 | 满足一定条件的最新数据 | 某一字段的所有数据 |
| 拓展设置 | - | 排序、聚合、自定义按钮 |
