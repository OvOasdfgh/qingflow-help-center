## 应用场景

通过轻流应用表单实现与数据库（Mysql、SQL server、Oracle）进行对接

ps:

公有云环境下，连接数据库需要确保所连接的数据库可以在外网环境下访问，否则无法进行连接。

私有化环境下，需要部署对应的连接器，然后根据运维提供的访问地址进行对接数据库。

### 一、获取连接数据库基础信息

需要获取到的参数：

- url：数据库地址
- port：端口号
- dbName：数据库名称
- username：用户名
- password：密码

如何找数据库的IP地址以及端口号：

这里是本地环境的数据库，可以配置内网穿透（或者其他方式）来进行打通，使得外网可以连接数据库

[如何配置服务器的sqlserver可以通过外网访问](https://www.u72.net/IT/show-76421.html)

点击电脑左下方的“开始”->“Microsoft SQL Server2005”->“配置工具”->“SQL Server Configuration Manager”-> “展开网络配置” -->点击“MYSQLSERVER协议” -->双击“TCP/IP” -->选择“IP地址”就能看到端口号了

### 二、获取access\_token

- 请求头（Header）

| ​参数 | 是否必填 | 说明 |
| --- | --- | --- |
| accessToken | 是 | 企业版客户需要试用请联系轻流技术支持申请token，试用token可以调用500次接口购买企业版客户，首次有10000次使用额度，后续使用完可联系客户成功人员进行增购。专有云/私有化客户，运维会单独提供token进行使用。 |

### 三、查询数据库表数据（select）

1. 接口说明：用户调用数据库地址进行查询数据库表数据
2. 接口地址：

1. 公有云地址:  https://connect.oalite.com/api/database/XXXXX
2. 私有化/专有云: https://xxxxx.xxxx.xxx/database/XXXXX
3. （XXXXX为数据库类型，可填写mysql / sqlserver / oracle，请依据数据库类型选择相应地址）

1. 请求方式：POST
2. 请求头（Header）：accessToken
3. 请求体（body）：

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| url | 是 | string | 数据库地址 |
| port | 是 | string | 端口号 |
| dbName | 是 | string | 数据库名称 |
| username | 是 | string | 用户名 |
| password | 是 | string | 密码 |
| sqlType | 是 | string | sql类型 只支持：select/update/insert |
| sql | 是 | string | sql语句 |

1. ​请求示例：

```json
curl --location 'https://connect.oalite.com/api/database/sqlserver' \
--header 'accessToken: 4b9ee78556c948728207***' \
--header 'Content-Type: application/json' \
--data '{
    "dbtype":"sqlserver",
    "url": "114.116.***.**",
    "port": "***",
    "dbName": "***",
    "username": "**",
    "password": "*****",
    "sqlType": "select",
    "sql": "select * from ***"
}'
```

1. 响应示例

### 四、插入数据到数据库（insert）

1. 接口说明：用户调用数据库接口进行数据插入
2. 接口地址：

1. 公有云地址:  https://connect.oalite.com/api/database/XXXXX
2. 私有化/专有云: https://xxxxx.xxxx.xxx/database/XXXXX
3. （XXXXX为数据库类型，可填写mysql / sqlserver / oracle，请依据数据库类型选择相应地址）

1. 请求方式：POST
2. 请求头（Header）：accessToken
3. 请求体（body）：

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| url | 是 | string | 数据库地址 |
| port | 是 | string | 端口号 |
| dbName | 是 | string | 数据库名称 |
| username | 是 | string | 用户名 |
| password | 是 | string | 密码 |
| sqlType | 是 | string | sql类型 只支持：select/update/insert |
| sql | 是 | string | sql语句 |

PS：如果遇到问题根据下述文档进行排查

[https://exiao.yuque.com/rlf3k1/oanb79/apa9nf48a9gzql4r?singleDoc#](https://exiao.yuque.com/rlf3k1/oanb79/apa9nf48a9gzql4r?singleDoc#) 《如何排查接口问题》

大概率失败的原因是由于SQL语句中引号加与不加的问题。具体可以在postman测试成功之后再进行轻流的配置。

如果postman测试连接数据库报错如下：

- 就是当前版本数据库TLS协议太低，需要上网下载对应版本的补丁或者更新数据库到最新版本，使得数据库TLS协议满足1.2即可

![image.png](https://cdn.nlark.com/yuque/0/2023/png/28884377/1694742431712-054c0fb5-d053-42ff-85f9-5ab134ba6073.png)

- 该报错大概率是body中参数填写有问题，导致与数据库服务器之间的通信失败。
