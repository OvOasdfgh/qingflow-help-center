### 介绍

飞书是字节跳动旗下先进协作与管理平台。

### 鉴权信息

用户可以使用飞书提供的三种访问凭证调用接口，不同的API可能会支持上述一种或多种的访问凭证（access token）作为API调用时的鉴权手段。具体可见[**飞书的API说明文档**](https://open.feishu.cn/document/ukTMukTMukTM/uMTNz4yM1MjLzUzM)。
![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/YCnJnnyt4hisfW_UIHGEauho7B6CfyJq_.png)

轻流中飞书连接器相关事需要用到自建应用的access\_token，具体获取方式如下：

##### **自建应用身份凭证获取方法**

**第一步: 获取 App ID 和 App Secret**

登录[开发者后台](https://open.feishu.cn/app/)，创建企业自建应用。进入企业自建应用详情页，获取 App ID 和 App Secret。
![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/cEHyjO-HWOQJDlqlXMI-SkzVB8KaPYBW_.png)

**第二步: 进入轻商城-连接中心中，选择连接器“飞书”，点击“配置”，并填写App ID 和 App Secret。**

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/gmg_9MKpchKxCRSa925zuA9TFgLoTujn_.png)

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-08/gL9JL9TwRQHyMotChMo2GpzvL88K1vX9_.png)

通过以上步骤，您可以完成飞书鉴权，省去每次使用连接器重新获取与填写access\_token的步骤。

##### 注意事项

1. 飞书中每个应用都有独立的id与secret。由于目前连接中心各事件无法为每个事件都配置独立的鉴权，所以使用的事件属于飞书中不同应用，那么使用事件时需要配置不同的app\_id 与app\_secret。
2. 不同的事件要求的权限不同，在使用连接器前，请确认相关事件要求的应用/用户权限并根据要求开启相应权限。开启权限方法如下（或者您可以查看[**相关文档**](https://open.feishu.cn/document/ukTMukTMukTM/uQjN3QjL0YzN04CN2cDN)）。

### 事件信息

| 事件 | 描述 |
| --- | --- |
| 获取用户基本信息 | 飞书自建应用：获取用户基本信息。 |
| 获取 tenant\_access\_token（企业自建应用） | 企业自建应用通过此接口获取 tenant\_access\_token，调用接口获取企业资源时，需要使用 tenant\_access\_token 作为授权凭证。 |
| 获取用户列表 | 以【企业自建应用】身份或【用户】身份获取用户列表。具体用户列表结果由应用/个人的通讯录权限决定 |
| 获取部门信息列表 | 以应用/用户身份获取部门信息列表。部分返回字段受到数据权限控制。 |
| 查询人员类型 | 以应用身份访问通讯录，获取员工的人员类型 |
