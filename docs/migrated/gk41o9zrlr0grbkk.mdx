### 1.简介

数据关联可关联到表格子字段，且可通过筛选关联到目标应用的表格中具体某一行

#### 1.1应用场景

- 任务派工
- 采购入库/出库
- 客户管理
- 进销存

......

### 2.设置步骤

在 **表单设计-高级字段** 中选择“**数据关联**”后，在关联设置中，选择完目标应用后，可在关联的字段中，选择到目标应用的表格子字段。

![文档图片](https://7169-qingmall-6goin5nh5aaec4fa-1304800004.tcb.qcloud.la/cloudbase-cms/upload/2023-05-07/TZncMSDprMr7jkRF1fty8qkdoD9uBWBC_.png)

如果需要关联到指定行的数据时，可继续设定筛选条件，针对表格内的行数据进行筛选。以下是数据关联在表格内外中，筛选条件可选择到的字段类型如下：

| 筛选关系 | 数据关联 | 表格·数据关联 |
| --- | --- | --- |
| 目标表单·表单字段=当前表单·表单字段 | ✅支持选择 | ✅支持选择 |
| 目标表单·表单字段=当前表单·表格子字段 | - | ✅支持选择 |
| 目标表单·表格子字段=当前表单·表单字段 | ✅支持选择 | ✅支持选择 |
| 目标表单·表格子字段=当前表单·表格子字段 | - | ✅支持选择 |

且关联到表格子字段时，在筛选条件的**目标表单字段**中，仅可选择到表单字段或与目标表格子字段在同一表格的表格子字段，不可选择其他表格的子字段

### 3.注意事项

- 当关联表格子字段时，**聚合方式-最新/最旧**的设置会失效；
- **排序设置**只对筛选出的数据生效，对表格行内容的排序不生效，且不做特殊处理
- 若字段设置了提交重计算时，将以第一个数值为准
