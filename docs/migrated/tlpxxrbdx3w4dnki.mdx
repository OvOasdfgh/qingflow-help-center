## 1、获取应用授权凭证

### 自建应用：

#### 第一步：获取App ID和App Secret并给飞书机器人设置权限

[https://open.feishu.cn/document/ukTMukTMukTM/uMTNz4yM1MjLzUzM](https://open.feishu.cn/document/ukTMukTMukTM/uMTNz4yM1MjLzUzM)

#### 第二步：获取 tenant\_access\_token

[https://open.feishu.cn/document/ukTMukTMukTM/uIjNz4iM2MjLyYzM](https://open.feishu.cn/document/ukTMukTMukTM/uIjNz4iM2MjLyYzM)

企业自建应用通过此接口获取 tenant\_access\_token，调用接口获取企业资源时，需要使用 tenant\_access\_token 作为授权凭证。

Token 有效期为 2 小时，在此期间调用该接口 token 不会改变。当 token 有效期小于 10 分的时候，再次请求获取 token 的时候，会生成一个新的 token，与此同时老的 token 依然有效。

**请求方式** ：POST

**请求地址** ：https://open.feishu.cn/open-apis/auth/v3/tenant\_access\_token/internal/
